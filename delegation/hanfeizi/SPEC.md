## 這部書是什麼

《韓非子》，戰國末韓非及其學派，現存 55 篇，本庫落地 781 段、切成 21 批。全書主張**法、術、勢三者並用**，君主憑制度與駕馭之術治國，不靠賢能與德行；並系統性否定儒墨、俠士、縱橫家與工商之民。

> **不要把同組其他法家書的判空比例搬過來當預期值。**慎子、商君書、諫逐客書已經標完，比例各不相同——判準完全一致，只是每部書、每一篇的內容落在判準的哪一側本來就不同。**韓非子的內部落差比商君書更大**，見下方「本書分成七種體例」。**尤其不要用前一批的比例推下一批。**

## 通則性閘門

法家整部在講怎麼立法、怎麼賞罰、官制怎麼設、君主怎麼駕馭臣下，**每一段都在談人**——所以「有沒有提到民、人臣、人主、賞罰、姦」完全不是判準。問：

> **這一段除了「該立什麼法／怎麼賞罰／官怎麼設、令怎麼下／君主該用什麼術駕馭臣下」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指**人是什麼樣的、人可以怎麼活、人有哪些品性、人與人之間如何**。

操作上最好用的一條分界：

> **文本有沒有自己把「人是什麼樣的」當成依據說出來？**
> 說了 → 命中。
> 只給「做 A 則得 B」的政策鏈、駕馭程序或制度條文，不解釋人為何如此 → 判空。

**這一格與兵書相反，要特別注意。**兵書拿仁義當致勝條件時判空（「將不仁則三軍不親」——那是工具不是主張）。**但法家把人性當統治依據時要命中**，差別在於：兵書那句沒有說人是什麼樣的，法家這句說了。

〈備內〉「醫善吮人之傷，含人之血，非骨肉之親也，利所加也。故輿人成輿則欲人之富貴，匠人成棺則欲人之夭死也，非輿人仁而匠人賊也，人不死則輿不售，人不死則棺不買」——它的用意百分之百是工具性的（要君主提防身邊人），但它**確實斷言了人是什麼樣的**。**工具性動機不能拿來當判空理由。**

**兩條本書專屬的提醒：**

> **一、本書列舉德目（仁義、孝悌、忠信、廉勇、慈惠）並主張它們有害或無用，那是對品格的明確主張，要命中 VII，不要因為它在罵德目就判空。**
>
> **二、本書大量用「人主／人臣／父子／夫妻」的利害計算來說明關係的本質。凡它明說某種關係的底層是什麼（「非骨肉之親也，利所加也」「父母之於子也，猶用計算之心以相待也」「人主之患在於信人」），就照它說的那一格命中（IV／III／V），不要因為它結論冷酷就判空。**

## 本書分成七種體例，判法不同——先認出你手上這一段屬於哪一種

**這比批號重要。**同一批裡可能有兩三種體例，逐段先問「這一段在做什麼」。

### A. 論說篇（命中最密的一端）

〈五蠹〉〈顯學〉〈孤憤〉〈八說〉〈六反〉〈備內〉〈亡徵〉〈詭使〉〈說疑〉〈說難〉〈難言〉〈心度〉〈忠孝〉〈飾邪〉〈人主〉〈南面〉〈和氏〉〈問田〉〈問辯〉〈奸劫弑臣〉〈安危〉〈守道〉〈大體〉〈功名〉〈初見秦〉〈存韓〉等。

**這一類通篇在論人為什麼會那樣做，預期高命中。**〈五蠹〉的上古競於道德／當今爭於氣力、古者丈夫不耕而人民少、「今有不才之子，父母怒之弗為改，鄉人譙之弗為動，師長教之弗為變」、儒俠五蠹之民——都是對人的明確斷言。

### B. 術治條文篇（判空最密的一端）

〈主道〉〈二柄〉〈揚權〉／〈揚榷〉〈有度〉〈用人〉〈八姦〉／〈八奸〉〈三守〉〈觀行〉〈定法〉〈制分〉〈飭令〉〈八經〉等。

**這一類是「君主該怎麼操作」的操作手冊，預期大量判空。**「明君無為於上，群臣竦懼乎下」「明主之所導制其臣者，二柄而已矣：刑德」「凡人臣之所道成姦者有八術：一曰在同床……」——**這些是駕馭程序與姦術分類表，不是對人的主張。**

**判空側 ＋ `formalization`**（凡有「一曰／二曰／三曰」的分類綱目、術目清單、官制條列）。

**但要逐段看，不要整章判空。**這一類的段落末尾常常轉向解釋人為何如此，**照末尾判**（同商君書〈兵守〉[2]、六韜〈農器〉）。例如〈八姦〉論「同床」時說「此人主之所惑也。托於燕處之虞，乘醉飽之時，而求其所欲」——若它只是列舉姦臣的下手處，判空；若它解釋人主為何在那個時刻失守，就命中。

### C. 儲說（經＋說）——**本書最鋒利的陷阱，六批 333 段、佔全書 43%**

〈內儲說上七術〉〈內儲說下六微〉〈外儲說左上〉〈外儲說左下〉〈外儲說右上〉〈外儲說右下〉。

**這一類每章分成兩截，判法完全不同：**

**經（章首少數幾段）**：先列術目（「七術：一曰眾端參觀，二曰必罰明威……」），再逐條給提要並附「**其說在**侏儒之夢見灶，哀公之稱『莫眾而迷』」這種指向後文故事的索引。

> **經是術目索引，不是對人的主張。預設判空 ＋ `formalization`。**「其說在 X，其患在 Y」是目錄式的交叉指引，**不要因為它提到了後面故事的人名就把故事的內容算進這一段**。

**說（章身絕大多數段）**：一則一則的故事，多以「一曰：」開頭表示同一事的異傳。

> **說要一則一則各自判，絕不可繼承經的判斷。**用敘事體閘門問：**把這一則刪掉，讀者少知道了什麼？**
> - 少知道的是「某個術怎麼操作／某個君主用了什麼手段」 → **判空**，`narrative`
> - 少知道的是「人在那個處境下會怎麼反應／某種人是什麼樣的」 → **命中**，`narrative`

實例：

- **判空的典型**：〈內儲說上〉龐敬還公大夫、戴讙詔視輼車、周主亡玉簪、衛嗣公使人為客過關市——**這些只示範「倒言反事以嘗所疑」這個術怎麼用**，人物是道具
- **命中的典型**：〈內儲說上〉子產相鄭病將死告游吉「火形嚴，故人鮮灼；水形懦，人多溺」，游吉不肯嚴形而鄭少年相率為盜——**它在解釋人為什麼對寬厚的人放肆**，命中 V 或 VII
- **命中的典型**：韓昭侯藏弊袴，侍者曰「君亦不仁矣」，昭侯曰「吾聞明主之愛一嚬一笑，嚬有為嚬，而笑有為笑」——**若你判定它只在示範「賞不妄予」這個術就判空；若你判定「明主之愛一嚬一笑」是在說一種人該怎麼自持，就命中 II 或 VII。兩種判法都可接受，`reason` 要說清楚依據哪一句。**

**這一類最大的硬撈風險：故事裡有人物、有對話、有情緒，看起來滿滿都是人。**但絕大多數故事的功能是**示範一個術**，人物只是零件。**預期這一類的判空比例明顯高於論說篇。**

### D. 說林（〈說林上〉〈說林下〉，b17／b18）

純粹的寓言與軼事彙編，沒有經，也不繫於某個術。**同樣走「把這一則刪掉，讀者少知道了什麼」閘門逐則判。**

說林比儲說更常出現「人在利害關頭的選擇」與「識人之明」，**預期命中比例高於儲說的說，但仍低於論說篇。**

### E. 難篇（〈難一〉〈難二〉〈難三〉〈難四〉〈難勢〉，b19／b20）

**這一類是兩段一組的辯難體，兩段的判法不同：**

- **前一段**：引一則史事或前人言論（晉文公問舅犯與雍季、仲尼曰……）→ 走敘事體閘門
- **後一段**（以「**或曰：**」開頭）：韓非的駁論 → **這是論說，通常在拆穿前一段的道德評價、提出人實際上是怎麼回事**，預期命中

> **「或曰」段不可判空只因為它在做邏輯反駁。**它反駁的內容多半正是「人是不是真的會那樣」——例如駁雍季「以詐遇民，偷取一時」時韓非談的是信與利對人的實際作用。**看它有沒有斷言人是什麼樣的。**

〈難勢〉特殊：它是「勢」與「賢」孰重的三方辯論（引慎到 → 或曰駁 → 復應之），**通篇在論人能不能靠自身賢能治世**，預期高命中（XI／V／VII）。

### F. 解老、喻老（b16 全批、b08 大半）

〈解老〉是逐句注解《老子》，〈喻老〉是用故事印證《老子》。

> **這一類離開了法家語境，是全書最不像法家的部分，判法不可照搬 B 類。**〈解老〉直接在論德、仁、義、禮、慾、禍福、生死、嗇、早服——**「仁者，謂其中心欣然愛人也；其喜人之有福，而惡人之有禍也」「聖人之於聲色滋味也，利於性則取之，害於性則捨之」「人有欲則計會亂……故欲利甚於憂，憂則疾生」**——這些是對人的直接主張，**預期是全書命中最密、領域最寬的一段**（VII、VI、I、XIII、X 都可能出現）。

**〈喻老〉走 D 類的敘事閘門**（扁鵲見蔡桓公、和氏之璧、宋人得璞），但每則末尾都有「故曰：……」把故事收束回一句《老子》——**收束句在講人怎麼活的，就照收束句命中。**

### G. 目錄與重出章——**這一類是來源資料的瑕疵，不是內容**

**〈韓非子全文〉18 段（b20）不是一篇文章，是全書目錄被切成的 18 段。**內容形如「韓非子卷第一初見秦第一存韓第二難言第三愛臣第四主道第五」。

> **18 段全部判 `[]`，`modes` 給 `[]` 或 `formalization`，`reason` 寫「卷目次，非正文」。不要試圖從篇名去推內容。**

**另有三組重出章，是同一篇文本在來源裡以繁簡／異體篇名重複出現：**

| 這一組 | 出現在 |
|---|---|
| 〈八奸〉4 段 ／〈八姦〉3 段 | 都在 b04 |
| 〈揚榷〉10 段 ／〈揚權〉10 段 | 分別在 b14 ／ b15 |
| 〈忠孝〉4 段 ／〈忠考〉4 段 | 都在 b14 |

> **兩邊都要照常逐段判，不要跳過、不要合併、不要在 `reason` 裡提「這是重複」。**章名逐字照抄（「八奸」就寫「八奸」，「八姦」就寫「八姦」，不要統一）。**判讀依據永遠是你眼前那一段的文字。**

**本書特別提醒的七格**：

- **V 會非常密集，這是對的，不必壓。**全書大半在論君臣、公私、權力與秩序
- **VII 預期是第二密集的一格**，因為它反覆否定德目、並主張品性由賞罰與處境決定。**不要因為它站在德性的反面就不給 VII**——判準是這一段有沒有在講品格，不是它講得對不對
- **II 預期比商君書多**：〈詭使〉〈說疑〉〈難言〉大量在論「名與實不符」——世人稱某種行為為「高」「賢」「忠」「烈士」「勇夫」而實非其實。**名與實屬於 II**
- **IV 與 III 要看清楚再給。**本書談父子夫妻的次數多，但多半是在論利害（「父母之於子也，猶用計算之心以相待也」「人主之患在於信人……夫以妻之近與子之親而猶不可信」）。**它明說了這些關係的底層是什麼，就給 IV 或 III；只是拿父子夫妻當比喻說明君臣要提防，就判空。**
- **XII 預期極少。**「天」「道」「神」「鬼」在本書多是政治或哲學語彙。〈飾邪〉整篇在論龜筴鬼神不足恃、「用時日、事鬼神、信卜筮而好祭祀者，可亡也」（〈亡徵〉）——**否定占候要命中 XI（把成敗從天挪回人），不是 XII**，這與兵家尉繚〈天官〉同一條判準。**要給 XII，得是這一段真的在處理人與超越者的關係。**〈解老〉論「鬼」「神」的幾段是例外，要單獨想過
- **X 預期少但不會是零。**全書大量出現「死」字（死罪、出死、殺戮、夭死），**那多是刑名與戰事用語，不是在談死亡本身**。但〈解老〉論「出生入死」「死生之地」、〈喻老〉扁鵲見蔡桓公、〈說林〉數則臨死抉擇是真的在談，該給就給
- **IX 要謹慎。**「苦」「勞」在本書多指勞役與處境的難堪。〈和氏〉刖足、〈難言〉列舉歷代諫者被醢被刑是真的在寫身體受害，**但要看那一段的重點是身體之苦還是進言之難**

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、編制表、器械規格、數量比例、綱目分類表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

要點：

- **`narrative` 在本書會是全庫最大宗**（儲說六批 ＋ 說林兩章 ＋ 難篇前段 ＋ 喻老），**不要因為數量大就迴避**
- **`formalization` 集中在三處**：儲說的「經」、B 類術治條文篇的「一曰／二曰」術目綱目、〈韓非子全文〉目錄。**其餘不要因為句子排成一長串就給**
- **`expression` 只給引號內的第一人稱話語**（故事中人物自述），第三人稱論述一律不算
- **`ritual` 預期為零**
- **`modes` 不要疊到三個以上**，挑主導的一到兩個。**儲說的「說」與說林幾乎都是單一個 `narrative`**

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。**本書七種體例的判空比例落差極大（術治條文與儲說的經一端，論說篇與解老另一端），不要用前面幾章的比例推後面。**
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **`reason` 裡寫的話必須在原文找得到。**不可以替原文補上它沒說的東西，也不可以用你對韓非、李斯、秦始皇或法家學派的既有知識去補。判斷依據只有你眼前這一段的文字。**尤其：儲說與說林的故事你多半聽過，不要用你記得的版本或後世的引申去判，只判眼前這幾行寫了什麼。**
4. **不要更動 `chapter` 與 `para_index`**。章名逐字照抄，**繁簡與異體都照抄不要統一**（「八奸」與「八姦」、「揚榷」與「揚權」、「忠孝」與「忠考」是四組不同的 `chapter` 值，寫錯會整批退回）。`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。
5. **不要判斷書中的政治主張對不對，也不要評價它的道德立場。**你的工作是記錄這一段在做什麼。本書主張君主猜忌臣下、否定仁義、以刑去刑，**那不影響它有沒有在說關於人的什麼**。
6. **章序不是書序，批次是按段數切的。**照你手上那一批的實際內容判，不要去猜別批有什麼，也不要因為某章被切在兩批而去推測另一半的內容。
7. 原文有訛字、異體與費解處，那是傳世本實況（「牀／床」「内／內」「䟽／疏」「爲／為」混用）。**看不懂的句子不要硬掰內容，判空並在 `reason` 說明文意不明。**

## 輸出格式

寫到 `delegation/hanfeizi/out/bNN.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b03.md",
  "rows": [
    {"chapter": "內儲說上七術", "para_index": 2, "domains": [], "modes": ["formalization"],
     "reason": "列出「觀聽不參則誠不聞」一術並以「其說在侏儒之夢見竈」指向後文故事，是術目索引不是對人的主張"},
    {"chapter": "內儲說上七術", "para_index": 20, "domains": ["V"], "modes": ["narrative"],
     "reason": "子產以火形嚴人鮮灼、水形懦人多溺告游吉，游吉不肯嚴形而鄭少年相率為盜，在解釋人為何對寬厚者放肆"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。**每批的章與段數見該批 `.md` 檔開頭的標題行，以及 `delegation/hanfeizi/MANIFEST.json`。這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，**判 `[]` 的段落也要寫 `reason`**。

## 不要做的事

- 不要改 `translations/` 底下任何檔案
- 不要跑 git 指令（commit、reset、pull、checkout、stash 一律禁止）
- 不要改 `delegation/hanfeizi/` 的輸入 `.md` 與 `MANIFEST.json`
- 只寫這次指派給你的那一個 `delegation/hanfeizi/out/bNN.json`
