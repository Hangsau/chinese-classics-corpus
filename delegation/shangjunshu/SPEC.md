## 這部書是什麼

《商君書》，託名商鞅（公孫鞅）及其後學，現存 24 篇 125 段。全書主張**農戰**（把全國人口導向耕種與作戰兩件事）、**重刑少賞**、**壹賞壹刑壹教**、**任法去私**，並明白敵視詩書禮樂與仁義孝弟（稱之為「六蝨」）。

本次切成四批：

- **b01（55 段，9 章）**：更法 8、墾令 20、農戰 8、去彊 7、壹言 3、錯法 4、戰法 2、立本 1、兵守 2
- **b02（36 段，7 章）**：靳令 5、修權 4、說民 7、算地 7、開塞 5、境內 5、弱民 3
- **b03（27 段，7 章）**：外內 3、君臣 3、禁使 2、慎法 3、定分 5、徠民 6、賞刑 5
- **b04（7 段，1 章）**：畫策 7

> **不要把同組其他法家書的判空比例搬過來當預期值。**體裁差異不是判準差異——判準完全一致，只是每部書的內容落在判準的哪一側本來就不同。**本書內部的落差也極大**：〈墾令〉20 段幾乎全是政策鏈，〈開塞〉〈算地〉〈畫策〉卻通篇在斷言人是什麼樣的。**不要用前一批的比例推下一批。**

## 通則性閘門

法家整部在講怎麼立法、怎麼賞罰、怎麼使民耕戰、官制怎麼設，**每一段都在談人**——所以「有沒有提到民、人情、賞罰」完全不是判準。問：

> **這一段除了「該立什麼法／怎麼賞罰／怎麼使民耕戰／官怎麼設、令怎麼下／名分怎麼定」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指**人是什麼樣的、人可以怎麼活、人有哪些品性、人與人之間如何**。

操作上最好用的一條分界：

> **文本有沒有自己把「人是什麼樣的」當成依據說出來？**
> 說了 → 命中。
> 只給「做 A 則得 B」的政策鏈或制度條文，不解釋人為何如此 → 判空。

**這一格與兵書相反，要特別注意。**兵書拿仁義當致勝條件時判空（「將不仁則三軍不親」——那是工具不是主張）。**但法家把人性當統治依據時要命中**，差別在於：兵書那句沒有說人是什麼樣的，法家這句說了。

〈錯法〉「人情而有好惡；故民可治也……夫人情好爵祿而惡刑罰，人君設二者以御民之志」——它的用意百分之百是工具性的（要拿來御民），但它**確實斷言了人是什麼樣的**。**工具性動機不能拿來當判空理由。**

**還有一條本書專屬的提醒：**

> **本書列舉德目並主張它們有害，那是對品格的明確主張，要命中 VII，不要因為它在罵德目就判空。**

〈靳令〉「六蝨：曰禮樂，曰詩書，曰修善，曰孝弟，曰誠信，曰貞廉，曰仁義」、〈去彊〉「國有禮有樂……有孝有弟，有廉有辯──國有十者，上無使戰，必削至亡」、〈說民〉「辯慧，亂之贊也；禮樂，淫佚之徵也；慈仁，過之母也」——這些是在**逐項否定德性的價值**，是全書對「人該是什麼樣」最強的立場宣示。

## b01 的重點

### 必須命中的段落（判空即為漏判）

- **〈更法〉[3][5]**：「愚者闇於成事，知者見於未萌。**民不可與慮始，而可與樂成**」「夫常人安於故習，學者溺於所聞」「知者作法，而愚者制焉；賢者更禮，而不肖者拘焉」——**在斷言不同的人各能理解到什麼程度** → **II** 或 **V**（可併 **XI**）
- **〈更法〉[7]**：「前世不同教，何古之法？」「治世不一道，便國不必法古」「反古者未可必非，循禮者未足多是也」——**在主張人的規範隨時代而變、不受古法束縛** → **XI**（可併 V）

### 〈墾令〉20 段——本批最大的硬撈風險，讀清楚再判

20 段每一段都是同一個模子：**一條政策槓桿 → 一串行為推論 → 「則草必墾矣」**。例如「廢逆旅，則姦偽躁心私交疑農之民不行……則必農，農則草必墾矣」。

**這是政策鏈，不是對人的主張。預期整章大量判空。**每一段都提到某一類民（惰民、庸民、姦民、辟淫游惰之民），**但只是說「這條政策一下，這類人沒飯吃就得去種田」——沒有解釋人為何如此。**

**不要因為每段都出現「民」字就整章命中；也不要因為我說它預期判空就整章不看。**逐段照閘門問。

兩段要單獨想過：

- **[11]**「重刑而連其罪，則褊急之民不鬥，很剛之民不訟，怠惰之民不游，費資之民不作，巧諛惡心之民無變也。**五民者不生於境內**」——**它按性情把人分成五類並命名**。這比其他 19 段多做了一件事。可考慮 **VII**（品性分類）；若你判定那只是列舉政策的五個受抑對象、並未主張人有這些本性，就判空。**兩種判法都可以接受，`reason` 要說清楚你依據原文哪一句。**
- **[3][14]**「民不貴學則愚，愚則無外交，無外交則勉農而不偷」「愚農不知，不好學問，則務疾農」——**明白主張讓人變愚對治理有利**。這是對「人該懂多少」的立場。可考慮 **V** 或 **XI**；也可判空，說明理由

### 會命中的典型（b01 其餘各章）

- **〈農戰〉[3]** 百姓自述心聲：「我疾農，先實公倉，收餘以事親，為上忘生而戰……倉虛，主卑，家貧，然則不如索官！」＋下官自述「我不以貨事上而求遷者，則如以狸餌鼠爾」——**原文替兩種人擬出他們自己的盤算** → **VIII**（可併 V）。**注意這幾句是引述人物口吻，mode 可考慮 `expression`**
- **〈農戰〉[5][6]** 詩書禮樂善修仁廉辯慧「國有十者，上無使守戰」＋「今一人耕，而百人食之，此其為螟螣蚼蠋亦大矣」——**否定德目與學問的價值** → **VII**（可併 VIII）
- **〈農戰〉[7]** 民見言談游士可以尊身、商賈可以富家、技藝足以餬口「民見此三者之便且利也，則必避農」——**在解釋人為什麼選擇某種生計** → **VIII**（可併 V）
- **〈去彊〉[4]**「重罰輕賞，則上愛民，民死上」「怯民使以刑必勇，勇民使以賞則死」「治國能令貧者富，富者貧」——**斷言人的勇怯貧富可被賞罰翻轉** → **XI** 或 **V**（可併 VII）
- **〈錯法〉[2]**「**人情而有好惡；故民可治也。**人君不可以不審好惡；好惡者，賞罰之本也。夫人情好爵祿而惡刑罰」——**全書最直白的人性斷言之一** → **VII** 或 **VI**（可併 V）。**必須命中**
- **〈錯法〉[4]** 離朱見秋豪而不能以明目易人、烏獲舉千鈞而不能以多力易人「夫聖人之存體性，不可以易人；然而功可得者，法之謂也」——**在斷言個人的卓越無法轉移給別人，制度才能** → **II** 或 **XI**（可併 VIII）
- **〈兵守〉[2]**：**這一段要單獨想過，是本批最細的一格。**主體是守城編制（壯男一軍／壯女一軍／老弱一軍，各自任務），那是編制表（判空側 ＋ `formalization`）。**但末段自己給出理由**：「壯男過壯女之軍，則男貴女，而姦民有從謀」「**老使壯悲，弱使強憐，悲憐在心，則使勇民更慮，而怯民不戰**」——**它在解釋情緒如何在人群中傳染並瓦解戰意**。照末尾判 → **VI**（可併 V）。若你判定編制那一半才是主體就判空，但 `reason` 要交代你怎麼處理末尾那兩句

### 判空的典型（b01）

- **〈去彊〉[1][2][5][7]**、**〈壹言〉[1][2]**、**〈立本〉[1]**：純粹的國力因果格言串（「以彊去弱者，弱」「國作壹一歲，十歲彊」「彊國知十三數：境內倉口之數，壯男壯女之數……」），**只宣告制度與國力的關係，沒有說人是什麼樣的**，判空。〈去彊〉[7] 的「十三數」清單走 `formalization`
- **〈戰法〉[1][2]**：用兵原則（逐北無過十里、論敵察眾、勝而不驕敗而不怨），判空
- **〈墾令〉大部分段落**（見上）

## b02 的重點

### 必須命中的段落（判空即為漏判）

- **〈算地〉[3]**「民之生，**饑而求食，勞而求佚，苦則索樂，辱則求榮，此民之情也**」＋盜賊「名辱而身危，猶不止者，利也」＋上世之士「苦其志意，勞其四肢，傷其五臟……非性之常，而為之者，名也」——**原文自己標明「此民之情也」，並用名與利兩件事解釋兩種相反的人生選擇** → **VIII** 或 **II**（可併 VII、VI）
- **〈算地〉[6]**「**民之性，度而取長，稱而取重，權而索利**」——直接的人性斷言 → **VII** 或 **VIII**
- **〈開塞〉[1]** 上世親親而愛私（民知其母而不知其父）→ 中世上賢而說仁 → 下世貴貴而尊官；「此三者，非事相反也，民道弊而所重易也，世事變而行道異也」——**一整套人類社會與道德如何演變的理論** → **V**＋**XI**（可考慮併 **IV**，若你判定「知其母而不知其父」「親親」那一半承重）
- **〈開塞〉[3]**「古之民樸以厚，今之民巧以偽」「夫民憂則思，思則出度；樂則淫，淫則生佚」「吾所謂刑者，義之本也；而世所謂義者，暴之道也」——**斷言人心古今不同，並重新定義義與暴** → **VII**（可併 XI、V）
- **〈說民〉[1]**「辯慧，亂之贊也；禮樂，淫佚之徵也；慈仁，過之母也；任譽，姦之鼠也」——**逐項否定德目** → **VII**（可併 V）
- **〈靳令〉[3]** 六蝨（禮樂、詩書、修善、孝弟、誠信、貞廉、仁義、非兵、羞戰）→ **VII**（可併 V）

### 會命中的典型（b02）

- **〈修權〉[3]**「凡人臣之事君也，多以主所好事君。君好法，則臣以法事君；君好言，則臣以言事君」「堯舜之位天下也，非私天下之利也，為天下位天下也」「公私之交，存亡之本也」——**在講人如何隨上位者的偏好而改變自己** → **V**（可併 VII）
- **〈修權〉[4]**「蠹眾而木折，隙大而牆壞」＋大臣爭私不顧其民、秩官之吏隱下漁民 → **V**
- **〈說民〉[2]**「用善，則民親其親；任姦，則民親其制」「以良民治，必亂至削；以姦民治，必治至彊」——**在斷言人的親附對象可以被制度改寫** → **V**（可併 VII）
- **〈說民〉[5][6]**「民勇，則賞之以其所欲；民怯，則刑之以其所惡」「民之有欲有惡也，欲有六淫，惡有四難」「民之所欲萬，而利之所出一」——**在替人的欲望與厭惡建模** → **VI** 或 **VII**（可併 V）
- **〈算地〉[5]** 談說之士資在於口、處士資在於意、勇士資在於氣、技藝之士資在於手、商賈之士資在於身——**按人靠什麼維生把人分類** → **VIII**（可併 II）
- **〈算地〉[7]**「羞辱勞苦者，民之所惡也；顯榮佚樂者，民之所務也」＋刑人有列則君子下其位、戮人衣錦食肉則小人冀其利 → **VII** 或 **V**
- **〈弱民〉[1][2]**「民弱國強，民強國弱，故有道之國，務在弱民」「政作民之所惡，民弱；政作民之所樂，民強」——**主張人民與國家的強弱是零和的**，這是對人在國家中應處什麼位置的直接立場 → **V**（可併 XI）
- **〈弱民〉[3]** 離婁見秋毫、烏獲舉千鈞「聖人之存體性也，不能以相易也」＋楚國之民齊疾而均、地非不大兵非不眾而戰不勝——**個人卓越不可轉移＋族群性描述** → **II** 或 **V**（與〈錯法〉[4] 同一組主張，判法應一致）

### 判空的典型（b02）——**〈境內第十九〉是本批最清楚的判空區**

**〈境內〉5 段是秦國軍功爵制的條文全文**：一級至大良造的爵名階梯、斬首三十三首以上盈論、五人一屯長百人一將、短兵人數配額、賜爵一級益田一頃益宅九畝、墓樹級一樹、陷隊之士面十八人。

**這是編制表與法條，判 `[]` ＋ `formalization`。**這與兵書〈王翼〉七十二人職掌表、〈武車士〉身高年齡門檻是同一型。**不要因為裡面出現「死」「黥劓」「墓」就去想 X 或 IX**——那是刑名與賞格的條目，不是在寫人的處境。

其他判空區：

- **〈算地〉[1]** 山陵什一、藪澤什一、谿谷什一、都邑什一、惡田什二、良田什四——**土地比例表**，`[]` ＋ `formalization`（**注意：〈徠民〉[1] 是同一張表，在 b03，判法應一致**）
- **〈靳令〉[1][2][4]**、**〈說民〉[3][4][7]**：以刑去刑、利出一空、五里斷者彊之類的制度因果格言串，判空
- **〈修權〉[1][2]**：法信權三者、賞厚而利刑重而必——制度原則，判空。**但〈修權〉[2] 末尾「授官予爵，不以其勞，則忠臣不進」要看你判不判它在講人的反應**

## b03 的重點

### 必須命中的段落（判空即為漏判）

- **〈定分〉[4]**「一兔走，百人逐之，非以兔也。夫賣者滿市，而盜不敢取，**由名分已定也**」「名分未定，堯舜禹湯且皆如𩤝焉而逐之；名分已定，貪盜不取」——**在解釋人為什麼爭、為什麼不爭**，且明說連堯舜在名分未定時也會爭 → **V**（可併 VII）
- **〈畫策〉見 b04**

### 會命中的典型（b03）

- **〈君臣〉[1]** 古者未有君臣上下之時民亂而不治，聖人別貴賤制爵位「民眾而姦邪生，故立法制為度量以禁之」——**一套秩序起源的敘述** → **V**（可併 XI）
- **〈君臣〉[2]**「**民之於利也，若水於下也，四旁無擇也**」「瞋目扼腕而語勇者得，垂衣裳而談說者得，遲日曠久積勞私門者得」——**斷言人趨利無所擇，並列舉三種鑽營的人** → **VII** 或 **VIII**（可併 V）
- **〈禁使〉[2]**「至治，**夫妻交友不能相為棄惡蓋非，而不害於親**，民人不能相為隱」「**利合而惡同者，父不能以問子，君不能以問臣**」「若使馬焉能言，則騶虞無所逃其惡矣」——**在推論人在什麼利害結構下才會互相揭發、什麼結構下必然互相包庇**，且明白處理夫妻、父子、朋友的關係 → **V**（可考慮併 **IV** 或 **III**，若你判定夫妻父子那一半承重）
- **〈慎法〉[1]**「世之所謂賢者，言正也；所以為言正者，**黨也**。聽其言也，則以為能；問其黨，以為然」——**在解釋「賢」這個名聲怎麼被製造出來** → **II**（可併 V）
- **〈慎法〉[2]**「民見相譽無益，相管附惡；見訾言無損，習相憎不相害也。**夫愛人者不阿，憎人者不害**」——**在講愛憎在制度下如何不再傷人** → **V**（可併 VII）
- **〈慎法〉[3]**「使民之所苦者無耕，危者無戰。二者，**孝子難以為其親，忠臣難以為其君**」「先王能令其民蹈白刃，被矢石，**其民之欲為之，非好學之，所以避害**」——**在解釋人為何肯赴死**（不是喜歡，是為了避開更大的害） → **V**（可併 VII、VIII）
- **〈外內〉[1][2]**「賞使之忘死，而威備之苦生」「民之外事，莫難於戰」「民之內事，莫苦於農」「農之用力最苦，不如商賈技巧之人」——**在陳述人覺得什麼最難最苦** → **VIII**（可併 IX，若你判定「用力最苦」那一句在講身體的負擔；**IX 這一格要謹慎，只有原文真的在寫身體受苦才給**）
- **〈徠民〉[2][4]**「**意民之情，其所欲者，田宅也**」「此必與其所欲，而不使行其所惡也」——**斷言人要的是什麼** → **VIII** 或 **V**
- **〈徠民〉[6]** 齊人東郭敞願有萬金，其徒請賙焉不與，曰「吾將以求封也」，其徒怒而去之宋——**有人物有情節的軼事，且明說「此無益於愛也，故不如與之利也」** → **VII** 或 **V**，mode 走 `narrative`
- **〈賞刑〉[3]** 晉文公斬顛頡之脊以殉，晉國之士皆懼曰「顛頡之有寵也，斷以殉，況於我乎」；周公旦殺管叔流霍叔，天下曰「**親昆仲有過不違，而況疏遠乎**」——**兩則軼事，都在講人看到什麼才會信服** → **V**（可考慮併 **IV**，若你判定「親昆仲」那一句承重），mode 走 `narrative`
- **〈賞刑〉[4]**「民之欲富貴也，**共闔棺而後止**」「是故民聞戰而相賀也；起居飲食所歌謠者，戰也」——**斷言人到死為止都在求富貴** → **VIII**（可併 X，若你判定「闔棺而後止」承重；**但這是修辭性的時間界限，不是在談死亡本身，預設不給 X**）
- **〈賞刑〉[2]**「夫固知愚，貴賤，勇怯，賢不肖，皆盡其胸臆之知，竭其股肱之力，出死而為上用也」——按天賦把人分類並主張賞可以讓每一類都盡力 → **VIII**（可併 V）

### 判空的典型（b03）

- **〈定分〉[2][3]**：置法官置吏、為之程式、尺六寸之符、左券右券木柙、禁室鍵鑰封印、天子置三法官——**法令保管與問答的行政程序全文**，`[]` ＋ `formalization`。與〈境內〉同一型
- **〈徠民〉[1]**：山陵什一、藪澤什一……良田什四——**土地比例表**，`[]` ＋ `formalization`（**與 b02〈算地〉[1] 是同一張表，判法應一致**）
- **〈徠民〉[3][5]**：三晉四世不勝秦、春違其農夏食其食秋取其刈冬凍其葆——**軍政謀畫**，判空
- **〈外內〉[3]**：邊利歸兵市利歸農則彊則富——三句制度因果，判空
- **〈君臣〉[3]**：言不中法者不聽、行不中法者不高——操作原則，判空
- **〈禁使〉[1]**：勢數之論（飛蓬遇飄風而行千里、探淵者知千仞之深縣繩之數）——**要單獨想過**。它是「靠勢不靠信、靠數不靠彊」的比喻論證，主體是治術；但「其勢難匿者，雖跖不為非焉」與 b04〈畫策〉[3] 是同一主張（**品性隨處境而變**）。若你判定那一句承重就命中 VII，否則判空並說明
- **〈賞刑〉[1][5]**：壹賞壹刑壹教的綱目宣告與收束，判空

## b04 的重點——〈畫策〉7 段

**這一章是全書思想密度最高的一章，預期命中比例遠高於〈墾令〉〈境內〉。**

### 必須命中的段落（判空即為漏判）

- **[3]**「故善治者，使跖可信，而況伯夷乎？不能治者，使伯夷可疑，而況跖乎？**勢不能為姦，雖跖可信也；勢得為姦，雖伯夷可疑也**」——**斷言品性不是人固有的，而是處境的產物**。這是全書對人最尖銳的一句 → **VII**（可併 **XI**）
- **[7]**「**仁者能仁於人，而不能使人仁；義者能愛於人，而不能使人愛。是以知仁義之不足以治天下也**」「所謂義者，為人臣忠，為人子孝，少長有禮，男女有別；非其義也，餓不苟食，死不苟生」「聖王者，不貴義而貴法」——**在界定義是什麼、並主張它不足以治天下** → **VII**（可併 V）

### 會命中的典型（b04）

- **[1]** 昊英之世／黃帝之世／神農之世的演變，「神農非高於黃帝也，然其名尊者，以適於時也」「以戰去戰，雖戰可也；以殺去殺，雖殺可也」——**歷史階段論＋對暴力正當性的主張** → **XI** 或 **V**（可併 VII）
- **[2]**「勝民之本在制民，**若冶於金，陶於土也**」「民之見戰也，**如餓狼之見肉**」＋「疆國之民，父遺其子，兄遺其弟，妻遺其夫，皆曰：『不得，無返。』」——**把人比作可鑄之材，並描寫家人如何互相驅趕上戰場** → **V**（可考慮併 **IV**，若你判定父子兄弟夫妻那一句承重）
- **[5]**「凡人主德行非出人也，知非出人也，勇力非過人也。然民雖有聖知弗敢我謀……法也」——**斷言君主並不比人強，靠的是法** → **V** 或 **II**；同段「所謂治主無忠臣，慈父無孝子」→ 可併 **IV** 或 **VII**
- **[6]**「**恃天下者，天下去之；自恃者，得天下。得天下者，先自得者也；能勝彊敵者，先自勝者也**」——**在講自恃與自勝** → **II**（可併 VII、XIII）

### 判空的典型（b04）

- **[4]**「國或重治，或重亂……民固欲戰，又不得不戰，是謂重彊」——四組定義式對舉，判空
- **[7] 前半** 黃鵠之飛有必飛之備、麒麟騄駬有必走之勢、虎豹熊羆鷙而無敵——**動物比喻**，若整段只有這些就判空；但本段末尾有上面說的仁義那一段，**照末尾判**

**本書特別提醒的五格**：

- **V 會非常密集，這是對的，不必壓。**全書大半在論君民、公私、權力與秩序
- **VII 是本書第二密集的一格**，因為它反覆否定德目、並主張品性由處境決定。**不要因為它站在德性的反面就不給 VII**——判準是這一段有沒有在講品格，不是它講得對不對
- **XII 預期掛零。**本書不談神明、不做占候、不涉祭祀。「天」「聖人」「先王」在本書是政治語彙不是宗教語彙。要給 XII，得是這一段真的在處理人與超越者的關係，`reason` 必須指得出是哪一句
- **X 預期極少。**全書大量出現「死」字（民死上、出死而為上用、罪死不赦、死不旋踵），**那全是賞罰與戰事的用語，不是在談死亡本身**。要給 X，得是這一段真的在處理死亡、衰老或失去這件事
- **IX 要謹慎。**「苦」「勞」「羞辱勞苦」在本書多指勞役與地位的難堪，不是身體受苦。〈境內〉的黥劓斷足是刑名條文。要給 IX，得是原文真的在寫身體的痛與限制

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、編制表、器械規格、數量比例、綱目分類表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

要點：

- **主導 mode 壓倒性是 `proposition`**（「A 則 B」「故 A」），其次 `prescription`
- **`formalization` 集中在三處**：〈境內〉全章（爵級表、斬首計數、賜田宅數）、〈定分〉[2][3]（法官置吏與符券程序）、〈算地〉[1] 與〈徠民〉[1]（土地比例表）。〈去彊〉[7] 的「十三數」清單也算。**其餘章節不要因為句子排成一長串就給 `formalization`**
- **`narrative` 只有幾處**：〈更法〉全章（孝公與三大夫的辯論，有人物有對話）、〈賞刑〉[3]（顛頡、周公旦）、〈徠民〉[6]（東郭敞）、〈定分〉[1][2]（公問於公孫鞅的問答）。**〈賞刑〉[2] 的湯武封賞是史事概述，有沒有情節你自己判**
- **`expression` 很少但確實存在**：〈農戰〉[3] 替百姓與下官擬的第一人稱盤算（「我疾農，先實公倉……」「我不以貨事上而求遷者……」）、〈畫策〉[2] 家人相勉的「不得，無返」。**引號內的第一人稱話語才算，第三人稱論述一律不算**
- **`ritual` 本書預期為零**
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。**本書各章的判空比例落差極大（〈墾令〉〈境內〉一端，〈開塞〉〈畫策〉另一端），不要用前面幾章的比例推後面。**
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **`reason` 裡寫的話必須在原文找得到。**不可以替原文補上它沒說的東西，也不可以用你對商鞅變法、秦國歷史或法家學派的既有知識去補。判斷依據只有你眼前這一段的文字。**尤其：不要因為知道商鞅主張嚴刑峻法就把每一段都往那上面讀，也不要因為知道他的下場而評價文本。**
4. **不要更動 `chapter` 與 `para_index`**。章名逐字照抄（含篇次，例如「更法第一」「墾令第二」「說民第五」「境內第十九」「畫策第十八」），`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。
5. **不要判斷書中的政治主張對不對，也不要評價它的道德立場。**你的工作是記錄這一段在做什麼。本書主張愚民、弱民、重刑，**那不影響它有沒有在說關於人的什麼**。
6. **章序不是書序。**b02 含〈說民第五〉〈算地第六〉〈開塞第七〉，b03 含〈徠民第十五〉〈賞刑第十七〉——**批次是按段數切的，不是按篇次**。照你手上那一批的實際內容判，不要去猜別批有什麼。
7. 原文有訛字與費解處，那是傳世本實況。**特別注意：本書多處的「軸」是「詐」的訛字**（「知軸賢能」「大軸貞信」「巧軸」「民軸生」），不是車軸；「𩤝」「瘺」等罕字亦然。**看不懂的句子不要硬掰內容，判空並在 `reason` 說明文意不明。**
