# 發包 spec：素書 段落級標註

## 你要做什麼

讀 `delegation/sushu/b01.md`，逐段判兩件事：

1. `domains`：這一段觸及哪些人生問題領域（下表 13 個 id，可以是空陣列）
2. `modes`：這一段用什麼方式說話（下表 8 個 id，可以是空陣列）

輸出寫成 `delegation/sushu/out/b01.json`，格式見文末。**全書只有這一批，6 段。**

## 這部書是什麼

《素書》，舊題黃石公撰（傳世本託名，實為宋人所傳），**格言排比體**，全書六章。本庫落地 6 段——**一章即一段**，每段就是一整章。

| `chapter` 值 | 內容 | 段數 |
|---|---|---|
| `原始章第一` | 道德仁義禮五者一體；賢人君子潛居抱道以待其時，遇與不遇 | 1 |
| `正道章第二` | 俊／豪／杰三等人各自的品格條件 | 1 |
| `求人之志章第三` | 十八條「絕嗜禁欲，所以除累」式的修身條目 | 1 |
| `本德宗道章第四` | 十五條「長莫長于博謀」式的極值排比 | 1 |
| `遵義章第五` | 四十餘條「以明示下者暗」式的行為與後果 | 1 |
| `安禮章第六` | 吉凶所由、同類相感、理身理家理國 | 1 |

> **`chapter` 欄位逐字照抄輸入檔**——`原始章第一`、`正道章第二`、`求人之志章第三`、`本德宗道章第四`、`遵義章第五`、`安禮章第六` 就是這六個字串。不要補書名、不要簡寫成「原始章」或「第一章」。改了回填時錨點對不上，整批退回。

`para_index` 在每一章內從 1 重新編號，本書每章只有 1 段，所以六段的 `para_index` **全部都是 1**，靠 `chapter` 區分。這不是錯誤，不要自己改成 1–6。

### 兩件體例事實

1. **每章末尾有「右第N章，言……」的章末小結**（如「右第一章，言道不可以無始」）。那是本子的體例，**不是獨立內容，不影響判讀，也不要因為它而判空**。
2. **本子用字混雜異體與俗字**（于／後作后／傑作杰／凶作兇／願作愿／聖作圣）。那是傳世本實況，不是訛字。`reason` 引句時逐字照抄你看到的字形。

### 反錨定（先讀這一句再往下讀）

> **不要把其他書的判空比例搬過來當預期值。**九章算術判空 99.9%、列女傳 4%、管子 24%——**體裁差異不是判準差異**。這一部該是多少，讀完再說。
>
> 但有一件事你該知道：**本書每一段都是一整章的格言集合，粒度極粗**。一段裡混著三四十條斷言是常態，**只要其中有一條說出了人是什麼樣的，這一段就命中**，不必整段都在講人。

## 一、通則性閘門

本書表面上通篇在講「君主該怎麼用人、怎麼避禍」，很容易整本讀成治術而判空。問：

> **這一段除了「該怎麼做才有利／怎麼做會出事」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

操作判準只有一句：

> **文本有沒有自己把「人是什麼樣的」當成依據或斷言說出來？**
> 說了 → 命中。
> 只給「做 A 則得 B」的政策鏈、制度條文、數量比例，不解釋人為何如此 → 判空。

**工具性動機不能拿來當判空理由。**整部書的用意百分之百是要人拿去用，只要它確實斷言了人是什麼樣的、人該成為什麼樣的，就命中。

## 二、本書最大的硬撈風險：四個詞面聯想陷阱（逐格寫死）

這四格**預期全書掛零**。它們之所以危險，是因為書裡真的出現了那些字。

### 1. X（無常·老·死·失去）——預期 0 段

- `本德宗道章第四`「**病莫病于無常**」：這裡的「無常」是**行事反覆無常**，不是世事無常、不是佛家的無常。**不給 X。**
- `本德宗道章第四`「**悲莫悲于精散**」：精神耗散，不是失去親人。**不給 X。**
- `安禮章第六`「**邦將亡者賢先避**」「與亡國同事者滅」：國家滅亡不是 X。X 要真的在談死亡、衰老、失去所愛。**不給 X。**

### 2. XII（信仰·神聖·超越）——預期 0 段

- `本德宗道章第四`「**神莫神于至誠**」：「神」是修辭上的極值，說的是至誠最靈驗，不是神聖領域。**不給 XII。**
- `安禮章第六`「福在積善，禍在積惡」「**夫人之所行，有道則吉，無道則兇……非其神圣，自然所鐘**」：這一句**明白否定了吉凶出於神聖**，把禍福歸給自然因果與人自己的行為。**這不是 XII，是 XI（自由·命運·改變）。**
  > 這一格與其他書同向：兵書尉繚〈天官〉「黃帝者，人事而已矣」、韓非〈飾邪〉「龜筴鬼神不能決勝」都判 XI 不判 XII。**做占候／訴諸神聖（可能給 XII）與否定占候／把禍福歸還給人（給 XI）是相反的兩件事，不可判反。**

### 3. IX（苦難·疾病·身體）——預期 0 段

- 「病莫病于無常」的「病」、`安禮章第六`「**足寒傷心**」「根枯枝朽」：全是比喻，沒有人在自己身體裡受苦。
  > **IX 不是「提到病或身體器官」，是「有人在自己的身體處境裡，而文本在寫那件事」。**

### 4. III（愛與親密）——預期 0 段

- `求人之志章第三`「貶酒闕色」、`遵義章第五`「**近色遠賢者惛**」「**女謁公行者亂**」：色與女謁在本書是政治風險項目，不是親密關係。**不給 III。**

## 三、必須切準的兩格

### `formalization` 不給排比條列

本書大半是條列排比（十八條、十五條、四十餘條）。**條列形式本身不是 `formalization`。**

> `formalization` 綁的是**規範被寫成可執行程序**：制度表、官職對照、數量比例、可查表的綱目分類。
> 「絕嗜禁欲，所以除累」是修身主張，「以明示下者暗」是行為與後果的斷言——**兩者都是 `prescription` 或 `proposition`，不是 `formalization`。**

**預期全書 `formalization` 為 0 段。**

### `正道章第二` 的三等分型要命中，不要當成分類表判空

「德足以懷遠……此人之俊也／行足以為儀表……此人之豪也／守職而不廢……此人之杰也」是**按人的品格分型**，不依賴任何政策槓桿。

> 分型句的分界：**不掛在政策槓桿後面的品格分型 → 命中**（同六韜〈練士〉按人想要什麼分類那一格）；**掛在「上面給什麼誘因、下面就有什麼反應」後面的 → 判空**（那是誘因反應強度，不是人的樣態）。本書屬前者。

## 事前鎖定的錨點段（回收後逐一回查原文核對）

### 必須命中（若這些段判空，代表判準用錯了）

- **`原始章第一`**：「夫欲為人之本，不可無一焉」把五者當成做人的根本；「潛居抱道，以待其時……**如其不遇，沒身而已**」說出遇與不遇不由己。
- **`正道章第二`**：俊／豪／杰三等品格分型（見上）。
- **`本德宗道章第四`**：「**安莫安于忍辱**」「**苦莫苦于多愿**」「**孤莫孤于自恃**」「**幽莫幽于貪鄙**」——直接斷言人的內在狀態從何而來。
- **`遵義章第五`**：「**貌合心離者孤**」「**自厚而薄人者棄**」「**貴而忘賤者不久**」——說出人際實況與品性後果，不只是政策鏈。
- **`安禮章第六`**：「**同志相得，同仁相憂，同惡相黨……同美相妒**」十六組同類相感，是全書對人講得最直白的一處；另「**釋己而教人者逆，正己而化人者順**」。

### 必須判空或不得出現的格（若出現，代表被硬撈了）

- **全書 `X`、`XII`、`IX`、`III` 四格為 0 段**（理由見第二節四個陷阱）。
- **全書 `formalization` 為 0 段**（理由見第三節）。
- **全書 `narrative`、`ritual`、`expression`、`worked_instance` 為 0 段**：本書無人物情節、無儀節動作時序、無第一人稱、無數字實例。`安禮章第六` 的「禮」只是篇題與德目名，沒有記任何儀節。

**本書特別提醒的格子：**

- **VII 預期是主軸**：全書骨幹是德性與品格。
- **V 次之**：君臣、上下、任賢、賞罰、國之興亡。

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、制度表、數量比例、綱目分類表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | **本書不會用到** |

預期分佈：

- `求人之志章第三` 以 `prescription` 為主（十八條都是當為句）
- `遵義章第五`、`安禮章第六`、`本德宗道章第四` 以 `proposition` 為主（A者B 的斷言鏈）
- `正道章第二` 是 `observation`（陳述三等人各是什麼樣）或 `proposition`，擇主導者
- `原始章第一` 兼 `proposition` 與 `prescription`
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**。負面結果本身是資料。
2. **一段可多標領域，但不要濫用。預設一到兩個。**本書粒度粗（一段＝一章），**允許到三個**，但要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。**四個以上一律不接受。**
3. **`reason` 裡寫的話必須在原文找得到。**不可以用你對黃石公、張良、《素書》流傳史的既有知識去補。判斷依據只有你眼前這一段的文字。
4. **不要更動 `chapter` 與 `para_index`**。章名逐字照抄，六段的 `para_index` 全部是 1。
5. **不要判斷書中的主張對不對，也不要評價它的道德立場。**
6. 原文有異體、俗字與費解處，那是傳世本實況。**看不懂的句子不要硬掰內容，判空並在 `reason` 說明文意不明。**
7. **判空之前先逐句掃一次**：本書一段內有三四十條斷言，只要其中一條說出人的樣態就命中，不要被前後大量的治術條目蓋掉。
8. **直接執行，不要先提出計畫徵求確認。**這是非互動式呼叫，你回問就等於整批白做。
9. **本次交付物就是那個 .json 檔本身。**寫完後把該檔讀回來確認存在且 rows 數為 6，然後停止。不要做任何 git 操作。
10. **你唯一可以建立或修改的檔案是 `delegation/sushu/out/b01.json`**。

## 輸出格式

寫到 `delegation/sushu/out/b01.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "正道章第二", "para_index": 1, "domains": ["VII", "VIII"], "modes": ["observation"],
     "reason": "按品格把人分成俊、豪、杰三等（「德足以懷遠」「行足以為儀表」「守職而不廢」），分型不依賴任何政策誘因，是對人的樣態的直接斷言"},
    {"chapter": "本德宗道章第四", "para_index": 1, "domains": ["VII", "VI"], "modes": ["proposition"],
     "reason": "「安莫安于忍辱」「苦莫苦于多愿」「孤莫孤于自恃」直接斷言人的內在狀態由何而來；「病莫病于無常」的無常指行事反覆，不涉死生故不給 X"}
  ]
}
```

**`rows` 必須涵蓋該批所有 6 段，一個都不能少、不能多。**章名見 `delegation/sushu/MANIFEST.json`。缺漏會整批退回。

`reason` 一句話即可，**判 `[]` 的段落也要寫 `reason`**。
