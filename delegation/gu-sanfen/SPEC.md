# 發包 spec：古三墳 段落級標註

## 你要做什麼

讀 `delegation/gu-sanfen/b01.md`（78 段，全書），逐段判兩件事：

1. `domains`：這一段觸及哪些人生問題領域（下表 13 個 id，可以是空陣列）

## 這部書是什麼（**先讀懂結構，否則會整批判錯**）

《古三墳》是北宋元豐年間出現的託古之作，自稱是《左傳》所說的「三墳」。本庫把它的 `text_role` 記為 `contested`（真偽有爭議），但**判讀時不管真偽，只判文本說了什麼**。

全書由五種截然不同的體例混成，每一種的預設答案不同：

| 章 | 段數 | 體例 | 預設 |
|---|---|---|---|
| 序 | 1 | 元豐七年得書經過的跋語 | 多半 `[]` |
| 太古河圖代姓紀 | 2 | 混沌→太始→太極→天地的生成論，以及伏羲畫卦的來歷 | **這是形上學，見下** |
| 山墳·連山易／氣墳·歸藏易／形坟·乾坤易 | 24 | **純對照表**，如「崇山君　君臣相　君民官　君物龍」 | 多半 `[]` |
| 傳（1）（2）（3） | 25 | 逐條為上面的表作註 | 見下，**三傳不一樣** |
| 天皇伏羲氏《皇策辭》／人皇神農氏政典／地皇軒轅氏政典 | 26 | 仿《尚書》的君臣訓誥與施政條目 | **多半命中，見下** |

**這部書不是志怪、不是故事集。**不要用讀神話的方式讀它。

## 逐體例的判法

### 1. 三墳的易表（24 段）——多半 `[]`

「崇山君　君臣相　君民官　君物龍　君陰后　君陽師　君兵將　君象脊」這種段落是**卦位對照表**，八個詞條並列，沒有句子。它在做的事是把八個範疇兩兩配對成一張方陣。

**這是本書最大的硬撈風險。**表裡出現了「君」「臣」「民」「后」「妻」「夫」「父」「子」這些字，看起來滿是社會關係，但這一段並沒有對這些關係說任何話——它只是在排格子。**判 `[]`。**

`modes` 給 `formalization`（把體系寫成可查表的方陣）。

### 2. 傳（1）（2）——多半 `[]`，少數例外

傳（1）（2）是給表裡每一格加一句訓詁式的註，如「君臣相（相位至貴，君之臣也。）」「陰民鬼（人死曰鬼，陰之民也。）」。**這仍然是在解釋這張表為什麼這樣排，不是在對人事下判斷。判 `[]`。**

例外要真的看得出來才給：若某一格的註離開了體系解釋、去講人該怎樣（如「民為邦本」一類帶有主張的句子），那一段可考慮給 V，但**整段主體仍是訓詁時不要給**——一句話不能把整段變成別的東西。

### 3. 傳（3）——**這一章多半命中，不要跟前兩傳一起判空**

傳（3）的句式是「乾形天，聖人以仰觀天象。……山天曲上，聖人以慎行求諫。川天曲下，聖人以察姦佞。」——它把每一個卦象轉成**聖人（治理者）該做的一件事**。求諫、察姦佞、澤蔭庶物、求賢代明、德教化民、恩及命婦、慎群小、聚財養士。

**這是治理規範，不是體系解釋。**給 V（責任與領導、公義與權力），`modes` 給 `prescription`（必要時加 `formalization`，因為它仍掛在方陣上）。

**這是本書最容易整批判錯的地方**：傳（1）(2)(3) 章名相近、掛在同一組表上，很容易一視同仁全部判空。三傳要分開讀。

### 4. 皇策辭與兩篇政典（26 段）——多半命中

這是仿《尚書》的訓誥：君主逐一對臣屬指派職掌並告誡（「爾分爵祿賢智……無掩大賢以恡財，無庇惡德以私賞」），或陳述施政綱領（「國無邪教，市無淫貨，地無荒土，官無濫士，邑無遊民」）。

- 職掌指派、施政綱領、對臣屬的告誡 → **V**，`modes` 給 `prescription`
- 「惟愛於民，則巍不危」「民安子安，民危子危」這類把治亂繫於愛民的句子 → **V**，加 `proposition`
- 涉及「父子不背恩，夫婦不相棄」這類家內倫理時 → 加 **IV**
- 君臣一問一答（「共工曰：工居君臣之位，無有勞，君其念哉」）→ `modes` 加 `expression`，領域照上面判

**注意**：這幾章夾雜大量「三十二易草木」「後二十二易草木」的紀年語，那只是計時，不承載內容，不因它而改判。

### 5. 太古河圖代姓紀（2 段）——**這裡可能有 I**

第一段從「清氣未升，濁氣未沉」講到太始、太極、太易、天地之父母，是一段**宇宙生成論**。本庫的判準裡，**文本在做形上學（追問萬物的根本與本末）時給 I**。這一段若確實在追問萬物從何而來，給 I。

但要分清楚：**若只是在排列名詞、記錄某氏是某氏之子、某年出了什麼圖，那是譜系與紀年，判 `[]`。**第二段（伏羲氏，燧人子也……）多半屬後者。

不要因為出現「混沌」「太極」就反射給 XII——XII 要的是人與神聖的關係或信仰實踐，不是宇宙論本身。

## `Z-wisdom` 陷阱

本書大量內容是「如何把世界排成一張表」的體系建構，那屬 `Z-wisdom`（方法與體系），**`domains` 判空**。`Z-wisdom` 絕不可寫進 `domains`。

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、方陣或制度表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

本書預期 `formalization` 與 `prescription` 佔大宗——**這一點與本庫已標的多數書相反，不要因為少見就迴避這兩個值。**

**`modes` 不要疊到三個以上**，挑主導的一到兩個。

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **不要更動 `chapter` 與 `para_index`**。它們是錨點，錯一個就整批對不上。`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。章名含全形括號與間隔號（「傳（1）」「山墳·連山易」「天皇伏羲氏《皇策辭》」），**逐字照抄，不要改標點**。
4. **`Z-wisdom`、`X-modern`、`Y-nature` 不是領域**，絕不可出現在 `domains`。
5. **不要用你對《尚書》《易經》或古三墳真偽問題的既有知識去補文本沒說的東西。**只判這一段文字寫了什麼。真偽爭議不影響判讀。

## 輸出格式

寫到 `delegation/gu-sanfen/out/b01.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "氣墳·歸藏易", "para_index": 1, "domains": [], "modes": ["formalization"],
     "reason": "八個範疇兩兩配對的卦位方陣，只排格子未對人事下判斷"},
    {"chapter": "地皇軒轅氏政典", "para_index": 5, "domains": ["V"], "modes": ["prescription"],
     "reason": "命龍東正掌爵祿賢智並戒其勿掩大賢勿私賞惡德，是對用人之權的規範"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。** 這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，但**判 `[]` 的段落也要寫 `reason`**——寫出你認為它少了什麼。
