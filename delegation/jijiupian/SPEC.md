# 發包 spec：急就篇 段落級標註

## 你要做什麼

讀 `delegation/jijiupian/bNN.md`，逐段判兩件事：

1. `domains`：這一段觸及哪些人生問題領域（下表 13 個 id，可以是空陣列）
2. `modes`：這一段用什麼方式說話（下表 8 個 id，可以是空陣列）

輸出寫成 `delegation/jijiupian/out/bNN.json`，格式見文末。

## 這部書是什麼

《急就篇》西漢史游撰，是**童蒙識字課本**：把姓名、器物、身體、疾病、官職等字編成韻語，斷六十字為一章，共三十二章。本庫落地的是**顏師古注、王應麟補注本**，所以正文與兩層注文混在一起。

5 章：`卷一`、`卷二`、`卷三`、`卷四`、`急就篇注敘`。**章名逐字照抄。**

段落長這樣——先是一句正文（常常只有三五個字），接著是大段注解：

```
蘭偉房。〈一作𢨲。〉
鄭穆公本因夢蘭而生，故號公子蘭，其後支庶或爲蘭氏。〈補曰︰《廣韻》：漢有武陵太守蘭廣。〉偉房，言其器大，衆藝所聚也。〈補曰︰偉，奇也。《後漢‧馮衍傳》注……〉
```

`〈 〉` 內是夾注（注音、異文、王應麟「補曰」）。**本書段落長短極不平均**，有的只有三個字，有的是一整頁考據，兩種都照同一道閘門判。

## 唯一的通則性閘門

替換測試與敘事的刪除閘門在字書上都咬不到——識字課本不是要告訴讀者一件事，是要登錄一批字。改問：

> **這一段除了「這幾個字怎麼寫、這個姓從哪來、這個詞出自哪本書」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指人可以怎麼活、人有哪些惡、人與人之間如何。**不是**指這些字的意思跟人有關。

## 硬撈風險（本書最容易錯的方向）

1. **正文是字表，被列出的字不等於內容。**「褚囬池」「蘭偉房」「減罷軍」是拿來湊韻的人名用字。它們碰巧包含「愛」「病」「死」「孝」這類字時，那仍然是字表。**這一條吃掉正文全部。**
2. **姓氏源流考不是 IV。**「鄭穆公本因夢蘭而生，故號公子蘭，其後支庶或爲蘭氏」是在說這個姓怎麼來的，不是在寫宗族或繼承。要給 IV，得是這一段真的在寫親子、教養、家內事。
3. **舉某朝某人曾用這個名字不是內容。**「漢有褚大、褚少孫」「漢有武陵太守蘭廣」是書證，證明這個字確實用作人名。
4. **注文的訓詁與異文校勘不是內容。**「淵，一作深，避唐諱」「池，疑當作淵」「徐鉉曰：今別作池，非是」是校勘。
5. **反切注音（「丑吕反」「薄蟹反」）一律不承載任何東西。**
6. **典故被引到不等於文本在談那個典故。**「驪姬之難，晉廢公族」是解釋減氏的由來，不是在寫那場政爭。
7. **一個詞的所指涉及人的活動，不等於這一段在說關於人的什麼。這一條吃掉卷二全部，是本書最大的硬撈來源。**卷二是器物、飲食、衣服、農商的名物篇，被訓的詞本來就大量指向商業、階層、族群、勞動——**訓詁它們仍然只是在說這個詞是什麼意思**。
   - 「貰，賖也。貸，假與也。出曰賣，入曰買。賤買而貴賣之曰販。肆，謂坐市行列也」→ 這是六個商業詞的字義，**不是**「描述商業營生」。`[]`
   - 「市，亦買也…多積布帛，匹幅皆全，無虧損也。四丈曰匹」→ 這是「市」的訓詁加上匹幅的尺度定義，**不是**「商業經營與收益」。`[]`
   - 「綌，謂葛之麤者。紵，織紵為布…枲，麤麻也」→ 這是四種麻布的分別，**不是**「貧困處境」。`[]`
   - 分界線：文本**自己說出**一句關於人的話（斷語、評價、勸誡、因果主張），才算。只是「這個詞指的東西被某種人使用／某個階層穿戴／某個族群持有」，不算。

8. **不准替原文補上它沒說的話。**`reason` 只能寫這一段字面上有的東西。前一版判讀曾對「綌紵枲緼」四個麻布訓詁寫出「貧乏者沒有良好綿帛，只能用粗麻自行包裹成衣被」——原文沒有任何一個字提到貧乏或包裹。**寫 `reason` 前先確認那句話在原文找得到；找不到就是 `[]`。**

## 判空風險（〈急就篇注敘〉，反方向的風險在這裡）

**第 5 章〈急就篇注敘〉是顏師古的序，是散文，要當論說文逐段認真讀。**它談：小學家的傳承、這部書怎麼在傳寫中訛誤、以及當時兩種人怎麼對待它——「蓬門野賤，窮鄉幼學，遞相承稟，猶競習之。旣無良師，祗增僻謬」對「縉紳秀彦，膏粱子弟，謂之鄙俚，耻於窺涉」。**那是在講不同出身的人與學問的關係，該給就給。**序裡也有顏師古追述父親生前想注這部書而未成（「雅志未申，昊天不弔」），那是自道不是考據。

不要因為「這是識字課本」就整批機械填 `[]` 而不讀；也不要因為序在講學問就反射填 VIII。**逐段讀懂它在做什麼，然後照實記。**

| III | 愛與親密 | 愛與性、被拒絕、承諾、信任與脆弱、溝通與被理解 |

| VII | 善惡·良心·品格 | 德性、良心、品格養成 |
| VIII | 工作·成就·召喚 | 勞動、職業、才能發揮、成就 |

`Z-wisdom`、`X-modern`、`Y-nature` **不是領域**，絕不可出現在 `domains`。

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、方陣或制度表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

要點：

- **正文字表與注文考據一律 `observation`**，這是本書主導 mode
- 姓氏源流裡出現人物與事件時（「鄭穆公因夢蘭而生」）可加 `narrative`，但**它仍然是考據不是故事，`domains` 照閘門判**
- 〈注敘〉裡顏師古自道（「奉遵遺範，永懷罔極」）→ `expression`
- 〈注敘〉裡有「A 故 B」推理（為什麼會傳寫湮訛、為什麼會祗增僻謬）→ `proposition`
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。本書正文預期絕大多數段落 `domains` 為空，**那是正確結果不是失敗**。
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」。
3. **不要更動 `chapter` 與 `para_index`**。章名逐字照抄；`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。
4. **不要用你對顏師古、王應麟的既有知識去補文本沒說的東西。**
5. 原文有缺字、異體字、反切、`〈 〉` 夾注、`︰` 全形冒號，那是來源格式，不影響判讀。

## 輸出格式

寫到 `delegation/jijiupian/out/bNN.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "卷二", "para_index": 4, "domains": [], "modes": ["observation"],
     "reason": "考蘭氏、偉房兩個人名用字的由來與書證，是姓氏源流與訓詁，沒說關於人的什麼"},
    {"chapter": "急就篇注敘", "para_index": 1, "domains": ["V", "VIII"], "modes": ["proposition"],
     "reason": "對比窮鄉幼學無良師而愈習愈謬與膏粱子弟耻於窺涉，講的是出身如何決定人與學問的關係"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。** 缺漏會整批退回。

`reason` 一句話即可，**判 `[]` 的段落也要寫 `reason`**，至少要指出它在做的是字表、姓氏源流、校勘、書證，還是別的。

## 不要做的事

- 不要改 `translations/` 底下任何檔案
- 不要跑 git 指令（commit、reset、pull、checkout、stash 一律禁止）
- 不要改 `delegation/jijiupian/` 的輸入 `.md` 與 `MANIFEST.json`
- 只寫 `delegation/jijiupian/out/` 底下你這一批的那個 `.json`
