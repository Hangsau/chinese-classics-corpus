**這部書內部落差是本組五部兵書裡最大的，必須逐篇分開判：**

- **前半（天官～治本）**論政、論人、論刑罰、論戰爭該不該打——**命中密集區**
- **後半（戰權～兵令下，含各種「令」）**是軍法條文與教練程序——**預期幾乎整篇判空**

**兩件來源格式的事，先講清楚：**

1. **原文夾有校注編號**，形如「肥墝**[1]**而立邑」「一作『節』**[3]**」。**這些方括號數字與校語不是內容**，判讀時直接無視，也不要把它們寫進 `reason`。
2. **〈十二陵〉等少數段落原文是簡體字**（「不祥在于恶闻己过」「祸在于好利」）。那是來源混排，**照內容判，不要因字體差異另眼看待、更不要判成無法辨識**。

## 通則性閘門

兵書整部在講怎麼打仗、用什麼打、怎麼傳令，內容表面上全與人有關。所以問：

> **這一段除了「怎麼打／用什麼打／怎麼傳令／怎麼看出勝負」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指**人可以怎麼活、人有哪些品性、人與人之間如何、什麼樣的人該被託付什麼**。

**不是**指段落裡出現了人、出現了「仁義」兩個字（兵書拿仁義當致勝條件時，那是工具不是主張），也不是指那件戰法的對象是人。

兩個對稱的錯法都要防：

- **判空太快**：看到「這是兵書」就整批判空。本書前半有整篇在講刑訊與冤獄的
- **硬撈太多**：軍法條文裡出現「誅」「賞」「族」就填 V。**只規定違令者如何處置**是條文，不是關於人的主張

正解只有一個：**逐段真的讀懂它在做什麼，然後照實記。**

## 六韜校準基準（同體裁前一部，**本書有兩處逐字對應，務必判得一致**）

《六韜》60 段已標完並驗收，判空 38 段。四條已驗收的判準沿用：

- **原文自己去解釋「人為何如此」，就命中。**〈勵軍〉「士非好死而樂傷也，為其將知寒暑饑飽之審」→ V
- **談賞罰施用的階層與正當性算 V；只規定號令怎麼下、鼓鐸怎麼響不算。**〈將威〉「殺及當路貴重之臣」「賞及牛豎馬洗厩養之徒」→ V
- **占候術數不進 XII。**〈五音〉律管候敵、〈兵徵〉「得神明之助」「城之氣如死灰」→ `[]`
- **器物對照／清單判空，但同一段末尾若轉成治國與生計的主張，仍照該主張命中。**〈農器〉→ V+VIII

**本書兩處與六韜逐字重合，必須跟六韜判一樣（皆為 V）：**

1. **〈武議〉「殺一人而三軍震者，殺之……賞及牛童馬圉者，是賞下流也」——與六韜〈將威〉「殺及當路貴重之臣」「賞及牛豎馬洗厩養之徒」同一主張**（賞罰穿過貴賤兩端）→ **V**
2. **〈制談〉「民非樂死而惡生也」——與六韜〈勵軍〉「士非好死而樂傷也」同一句式同一論證**（明說人本不願死，然後解釋為何仍赴戰）→ **V**

**一段最多兩個領域。六韜 60 段沒有任何一段疊到三個。本書前半內容較厚，允許出現第三個，但 `reason` 必須寫得出「拿掉它這一段就少講了什麼」。**

## 本書的命中區

### 〈天官〉——與六韜正好相反的一篇，**不要判反**

- [1][2] 梁惠王問黃帝刑德可以百戰百勝，尉繚答「不然」，並舉「按天官曰背水陣為絕地，向阪陣為廢軍。武王伐紂……而不得已也」，結論「**黃帝者，人事而已矣**」——**這一篇在明確否定占候術數，把勝負歸給人事** → **XI**（命定與人為）；可考慮併 **V**
- **注意方向**：六韜〈五音〉〈兵徵〉是在**做**占候，所以判空、XII 掛零；尉繚〈天官〉是在**否定**占候並提出「人事」的主張，所以命中。**兩者判法不同不是矛盾，是因為它們在做的事不同。**
- 同一主張在〈戰威〉再出現一次（「不時日而事利，不卜筮而事吉，不禱祠而得福……聖人所貴，人事而已矣」）——**照樣命中**，不要因為重複就判空

### 〈兵談〉〈制談〉——論國力與制度何以立

- 〈兵談〉論量地立邑、「地大而城小者必先收其地，城大而地窄者必先攻其城」——**若整段落在國土與城邑的配置計算 → `[]`＋`formalization`**
- 〈兵談〉論將（「將者上不制於天，下不制於地，中不制於人」「寬不可激而怒，清不可事以財」）→ **VII**（品性）或 **VIII**（勝任）
- 〈制談〉[4]「民非樂死而惡生也」——見上節，**V**
- 〈制談〉論「什伍相結，上下相聯，無有不得之姦，無有不揭之罪」「使民內畏重刑，則外輕敵」——**要單獨想過**：這是在講一套連坐制度如何改變人的行為。可考慮 **V**；若你判定它只是編制與刑名條文，就判空＋`formalization` 並在 `reason` 說明
- 〈制談〉論「今天下諸國士，所率無不及二十萬眾者，然不能濟功名者，不明乎禁舍開塞也」與「殺人於百步之外者，弓矢也……」——**若整段在論兵器與戰法的效力就判空**

### 〈戰威〉——論何以能使人戰

- 「凡兵，有以道勝，有以威勝，有以力勝」、「民之所以戰者，氣也」、「舉功別德，明如白黑，令民從上令，如四支應心也」——**在解釋人為何肯戰、士氣從何而來** → **V**
- 「不時日而事利，不卜筮而事吉……聖人所貴，人事而已矣」→ **XI**（見〈天官〉一節）
- 「先王之所以罰，不重刑；賞，不重賞」類的賞罰論 → 若談施用的正當性 → **V**；若只是額度規定 → `[]`

### 〈攻權〉〈守權〉——多數判空，一處例外

- 〈攻權〉論攻城時機、將帥心與眾心（「將帥者心也，群下者支節也」）→ 若只是比喻用兵原則 → `[]`；若在講上下如何連成一體 → 可考慮 V
- **〈守權〉[2]「守法：城一丈十人守之……」是守城人數規格 → `[]`＋`formalization`**
- **〈守權〉裡的「愚夫蠢婦無不守陴而泣下，此人之常情也」——這是全書少數真的在寫情緒本身的地方**，且明說「此人之常情也」。→ 可考慮 **VI**；若該句只是整段守城規格中的一句附帶描述，就以整段主導內容為準判空並在 `reason` 說明你看到了這一句、為何不採。**兩種都可以，但必須在 `reason` 交代。**

### 〈十二陵〉——格言體，兩段都要細讀

- 「威在于不變，惠在于因时，机在于应事，战在于治气，攻在于意表，守在于外饰，无过在于度数，无困在于豫备，慎在于畏小，智在于治大……」
- 「悔在于任疑，孽在于屠戮，偏在于多私，不祥在于恶闻己过，不度在于竭民财，不明在于受间，不实在于轻发，固陋在于离贤，祸在于好利，害在于亲小人，亡在于无所守，危在于无号令」
- **這是把德性與敗壞逐項定義的清單**，同六韜〈論將〉五材十過、〈上賢〉六賊七害的判法 → **VII**（＋ **V** 若該條重心在權力與群體）
- mode 是 `formalization`（綱目定義表）＋ `proposition`

### 〈武議〉——本書論戰爭正當性最集中的一篇

- 「兵不攻無過之城，不殺無罪之人。夫殺人之父兄，利人之貨財，臣妾人之子女，此皆盜也」——**在論什麼樣的戰爭等同於盜** → **V**（可考慮併 **VII**）
- 「殺一人而三軍震者，殺之……賞及牛童馬圉者，是賞下流也」→ **V**（見六韜對應）
- 「吳起與秦戰，舍不平隴畝，樸樕蓋之，以蔽霜露」＋「將受命之日忘其家；張軍宿野忘其親；援枹而鼓忘其身」——**在講一個人為了職責放棄什麼** → 可考慮 **VIII**（＋ **IV** 若「忘其家」「忘其親」承重，要寫得出理由）；`narrative`＋`proposition`
- 斬材士以立威那一則（有將材而不聽令者斬之）——**若整則在示範軍法威信如何建立 → V；若只是軍法執行的例子 → `[]`**，照原文實際說的判
- 「太公望年七十屠牛朝歌、賣食盟津……遇文王」類的舉例——**在講人的際遇與被識** → 可考慮 **VIII** 或 **XI**

### 〈將理〉——**本書最非軍事的一篇，五段全部要細讀，不要跟著兵書慣性判空**

整篇在講**司法與刑訊**：

- 「將理官也，萬物之主也，不私於一人」——治獄者的公正 → **V**
- 「笞人之背，灼人之脅，束人之指，而訊囚之情，雖國士有不勝其酷，而自誣矣」——**在說刑訊會逼出假供，連國士也扛不住** → **V**（公義）；可考慮併 **VII**（誠實與虛偽）或 **IX**（身體的極限）——**IX 要給的話 `reason` 必須指出原文哪一句在寫身體承受本身**
- 「今世諺云：『千金不死，百金不刑。』」——**在指司法被財力左右** → **V**
- 「良民十萬，而聯於囹圄……上不能省，臣以為危也」——**在寫牽連無辜者的規模與後果** → **V**
- **這一篇是整組五部兵書裡最不像兵書的地方。如果你的答案是整篇判空，那幾乎確定判錯了。**

### 〈原官〉〈治本〉

- 〈原官〉多為官制職掌陳述（「官者事之所主，為治之本也」「明法稽驗，主上之操也」）→ **多數 `[]`＋`formalization`**，同六韜〈王翼〉編制表的判法
- 〈原官〉若某段在講「名實相符」「舉賢任能」的道理 → 可考慮 **VIII**（＋ **II** 若名實承重），同六韜〈舉賢〉判法
- 〈治本〉論「凡治人者何？曰非五穀無以充腹，非絲麻無以蓋形」「使民無私……欲心去，爭奪止，囹圄空」——**在講人的欲望從何而生、如何止息** → 可考慮 **V** 或 **VII**
- **〈治本〉的「神明」是 XII 陷阱**：「夫謂治者，使民無私也……天子之德也，非神明也」之類的說法裡，「神明」是形容治理境界的詞，**不進 XII**（同醫書「神」「魂」是生理術語的先例）

### 後半各「令」——預期幾乎整篇判空

〈戰權〉〈重刑令〉〈勒卒令〉〈將令〉〈踵軍令〉〈兵教上〉〈兵教下〉〈兵令上〉〈兵令下〉共 28 段，內容是：

- 金鼓旗鈴的號令規格、教練的分合進退程序（〈勒卒令〉〈兵教上〉）
- 將軍受命誓師與軍門開閉的時刻規定（〈將令〉）
- 分營前後距離與踵軍興軍的日程（〈踵軍令〉）
- 違令者誅、亡軍者身戮家殘、什伍連坐的條文（〈重刑令〉〈兵令下〉）
- 十二條必勝之道、五教之數（〈兵教下〉）

→ **`[]`＋`formalization`／`prescription` 為主。**

**但有三處值得停下來看一眼**（判空也可以，`reason` 要說明）：

- 〈重刑令〉「使民內畏重刑，則外輕敵」類的說明——若條文自己解釋了「人為何因此改變行為」，照通則性閘門命中
- 〈兵令上〉論「兵者，凶器也；爭者，逆德也」——**與三略「兵者，不祥之器，天道惡之」同類，在論戰爭本身的性質** → 可考慮 **V**
- 〈兵教下〉「十二曰死力」「使民背國門之限，決死生之分」類的——若在解釋人為何肯赴死就命中，若只是綱目就判空

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、編制表、器械規格、數量比例、綱目分類表、刑名條文 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

要點：

- **主導 mode 是 `proposition` 與 `prescription`**
- **`formalization` 在後半各「令」數量極大**（伍什連坐的罰則階梯、守城人數比、踵軍距離日程、十二必勝之道、五教之數、〈十二陵〉的綱目對句）。**綱目定義表就是 `formalization`，與領域無關**
- **`narrative` 少數幾處**：〈天官〉梁惠王問答（有具體對話與武王伐紂之例）、〈武議〉吳起舍不平隴畝、〈武議〉斬材士、〈武議〉太公望屠牛賣食。**「尉繚子曰」本身不是敘事**
- **`ritual` 只給真的規定儀節動作時序的**：〈將令〉將軍受命後鑿凶門而出、誓師的程序
- **不要給 `expression`。**問對框架不是自道
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。**本書後半判空段數會很多，前半不應該。**
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **`reason` 裡寫的話必須在原文找得到。**不可以替原文補上它沒說的東西，也不可以用你對《尉繚子》的既有知識去補。判斷依據只有你眼前這一段的文字。
4. **不要更動 `chapter` 與 `para_index`**。章名逐字照抄（「天官」「將理」「兵教上」），`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。
5. **不要判斷書中的軍事、司法或政治主張對不對，也不要評價它的道德立場。**〈重刑令〉的連坐族誅、〈將理〉的刑訊，都只記錄它在做什麼。
6. **校注編號 `[N]` 與「一作『X』」是校勘符號不是內容**，無視即可，不要寫進 `reason`。
7. **少數段落是簡體字，照內容判**，不要當成無法辨識。
8. 其餘異體字、夾注、引號不對稱是來源格式，不影響判讀。**看不懂的短句不要硬掰內容，判空並在 `reason` 說明文意不明。**

## 輸出格式

寫到 `delegation/weiliaozi/out/b01.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "將理", "para_index": 2, "domains": ["V", "VII"], "modes": ["proposition"],
     "reason": "明說笞背灼脅束指訊囚雖國士亦不勝其酷而自誣，在指刑訊逼出的是假供，觸及治獄的公正與人在強迫下的誠實"},
    {"chapter": "勒卒令", "para_index": 1, "domains": [], "modes": ["formalization"],
     "reason": "金鼓鈴旗各對應何種進退動作的號令規格，全段是操典程序"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。**共 84 段，各章段數見上表。這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，**判 `[]` 的段落也要寫 `reason`**，至少要指出它在做的是軍法條文、教練程序、號令規格、官制職掌，還是別的。
