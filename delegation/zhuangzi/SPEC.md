# zhuangzi（莊子）段落級判讀規格

## 你要做什麼

替《莊子》的一批段落做心理學領域標註。每一段回答兩件事：

1. `domains`：這一段承重地談到下表 13 個人生領域的哪幾個（可以是 `[]`）
2. `modes`：這一段用什麼方式在說（8 個 discourse_mode 挑一到兩個）

## 這部書是什麼

內篇七、外篇十五、雜篇十一，共三十三篇。本庫底本是 ctext 白文，共 463 段。章名是英文代號（`enjoyment-in-untroubled-ease`＝逍遙遊、`adjustment-of-controversies`＝齊物論、`perfect-enjoyment`＝至樂、`full-understanding-of-life`＝達生），**回報時照抄英文代號**。

## 體例群與閘門

莊子同一篇裡寓言與論說交錯，**不按篇分群，按段落體例分**：

| 體例 | 閘門 |
|---|---|
| 寓言（有人物、有情節的一則故事） | 刪掉這一則，讀者少知道了什麼 |
| 論說（直接講道理） | 中性物件替換＋道論規則 |
| 學術評論（`tian-xia` 天下篇） | 品題之外 |

### 寓言——刪掉這一則，讀者少知道了什麼

**判的是故事承載的主張，不是故事裡出現了誰、什麼動物。**鯤鵬、蝴蝶、渾沌、魚都是載體：

- 鯤鵬與蜩鳩：大小之辯若落到「人以自己的尺度笑別人」→ II；若只是描寫鵬飛九萬里的景象判空
- **技藝寓言**（庖丁解牛、輪扁斲輪、痀僂承蜩、津人操舟、呂梁丈夫蹈水、梓慶削鐻）：寫一個人怎麼練成、怎麼在技藝中忘我 → **VIII**；故事被拿來說養生、說心的狀態 → 再加 VI 或 XIII；輪扁「得之於手而應於心，口不能言」說技藝不能言傳 → VIII＋II
- 死生寓言（妻死鼓盆、子祀子輿相與友、髑髏）→ X；寫到面對死亡如何安頓 → 加 XIII
- 支離疏、兀者、惡人哀駘它等殘形者：**寫身體處境本身而文本在談那件事 → IX**；被拿來說德與形的關係 → VII
- 讓王、盜跖、說劍、漁父等外雜篇故事：照它對富貴、權力、名節的主張給 V／VII／I

### 論說——中性物件替換＋道論規則

- **純道體、純宇宙論判空**（「夫道，有情有信，無為無形」若整段只講道）
- 齊物論的是非、彼此、名實之辯：**落到人如何被自己的立場蒙蔽 → II**；純語言邏輯的辯證（「指之非指」）判空
- 心齋、坐忘、虛室生白 → VI（心的虛靜）
- 「命」「時」「安時而處順」→ XI；寫到受苦失意後如何自處 → 加 XIII
- 對儒墨仁義的批判：說仁義如何扭曲人性 → VII
- 對君主與治天下的批評（應帝王、在宥、胠篋）→ V

### `tian-xia`（天下篇）——品題之外

天下篇評述百家學術。**純點名與學說摘要判空**，`observation`；評語落到一般性的人生主張（何謂「內聖外王」、學術分裂對人的損害）才給 I 或 V。

### 本書特有的四個陷阱

1. **「神人」「真人」「至人」是理想人格**，描寫他們的境界時照它主張的活法給（I／VI／XIII），**不因「神」字給 XII**；「肌膚若冰雪」「乘雲氣，御飛龍」的形容判空
2. **「造化」「造物者」是自然變化的過程**，用來談死生 → X／XIII，**不給 XII**；只有文本描寫祭祀、祈禱、鬼神賞罰時才看五分
3. **寓言裡的動物、樹木說話不等於有內容**：櫟社樹託夢說「無用之用」是主張（I），樹本身不是
4. **反諷與詭辯照它實際指向判**：盜跖罵孔子，承載的是對名節與富貴的質疑（VII／I），不因為說話的是盜就判空

## 天與神的五分（全書通用，每一側都有反面）

1. **認證側 → XII**：文本自己斷言天／神有意志、會賞罰、會降命（「天生德於予」「獲罪於天，無所禱也」）
2. **破除側 → XI，不得含 XII**：文本把成敗從天、鬼神、占卜挪回人事（「天行有常」「雩而雨……無何也」）
3. **存而不論側 → 不給 XII**：避談、敬而遠之、「未能事人，焉能事鬼」——文本沒有認證也沒有否定，判它實際在主張什麼
4. **技術側 → 判空**：祭祀儀節、占筮程序本身
5. **比喻側 → 判空**：拿天、道、自然當比喻支撐一個人事主張時，判的是那個人事主張
6. **「道」「天」「神」不是萬用桶**：只講道體、宇宙生成、天地運行而沒有落到人，判空；「神」指人的精神作用時不是 XII

## 13 個領域（`domains` 只能填這些 id）

| id | 名稱 | 涵蓋 |
|---|---|---|
| I | 存在與意義 | 人為何而活、意義從何而來、本末輕重、人在宇宙中的位置（**純宇宙論不算**） |
| II | 自我與認同 | 我是誰、自知與自欺、名與實落在自己身上、認知的限度落在人身上 |
| III | 愛與親密 | 愛與性、夫婦、承諾、信任、被理解 |
| IV | 家庭與傳承 | 親子、孝、兄弟、宗族、繼承、教養、喪葬 |
| V | 群體·社會·公義 | 歸屬、友誼、公義與權力、責任與領導、君臣、民心、用人、風俗 |
| VI | 情緒與內在生活 | 喜怒憂懼、情欲、心的虛靜與擾動 |
| VII | 善惡·良心·品格 | 德性、良心、人性善惡、品格養成（**德目排比不算，要拆成行為、下定義或連到後果**） |
| VIII | 工作·成就·召喚 | 勞動、技藝、才能、學與教、事功 |
| IX | 苦難·疾病·身體 | 有人在自己的身體處境裡而文本在寫那件事（養生術語、病名不算） |
| X | 無常·老·死·失去 | 死亡、衰老、失去 |
| XI | 自由·命運·改變 | 命定與自由、禍福無常、把成敗推回人力、時與遇 |
| XII | 信仰·神聖·超越 | **只給文本自己認證的神聖或超越**（見上方五分） |
| XIII | 安頓·修復·平安 | 受苦、失去、失意之後如何自處 |

`Z-wisdom`、`X-modern`、`Y-nature` **不是領域**，絕不可出現。

## 8 個 discourse_mode（`modes` 只能填這些 id，挑一到兩個）

| id | 定義 |
|---|---|
| `observation` | 陳述某物／某人實際如何（品題、記行、天象） |
| `proposition` | 主張某個因果或原理 |
| `prescription` | 規定應該如何 |
| `formalization` | 把規範化成可計算的程序或表（官制職掌、度數） |
| `narrative` | 用故事承載（寓言、對話情節） |
| `ritual` | 用儀節承載 |
| `expression` | 第一人稱抒發（感嘆、自述、韻文） |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案（預期極少） |

## 硬規則

1. **`[]` 是合法答案。**負面結果本身是資料。你的工作是記錄這一段實際在做什麼，不是讓結果好看。
2. **一段預設一到兩個領域。**標第三個時，`reason` 必須寫得出「拿掉它這一段就少講了什麼」。**不得標到四個。**
3. **章名逐字照抄批次檔的寫法（包括英文代號，如 `xue-er`），`para_index` 照批次檔給的數字**，不要重新編號、不要換成中文篇名。
4. **異體字逐字照抄**，不要把 `爲` 改成 `為`、`僞` 改成 `偽`。
5. **不要用你對這部書或這個學派的既有知識去補文本沒說的東西**——名句不等於命中，要看這一段自己說了什麼。
6. **不要把別部書、別一群的命中比例搬過來當預期值。**
7. **`reason` 必須逐字引到這一段自己的文字**，用「」括起來：
   - 引句必須是這一段正文**連續的原字**，一字不改、不增、不刪
   - **原文裡有引號時，不准刪掉原文的引號再引**。例：原文 `子曰：「未能事人，焉能事鬼？」`，要引只引引號裡面的一截，如「未能事人，焉能事鬼」；**不可寫成「子曰未能事人」**
   - 原文中間被別的字隔開時，拆成兩個「」分別引，不要自己補省略號、不要把兩截接起來
   - 判 `[]` 的段落也要寫 `reason`，並引一句說明它在做什麼（儀節、官制、宇宙論、品題、比喻……）

## 輸出格式

寫到 `delegation/zhuangzi/out/bNN.json`，UTF-8、不要 BOM：

```json
{
  "batch": "b05.md",
  "rows": [
    {"chapter": "perfect-enjoyment", "para_index": 5, "domains": ["X", "XIII"], "modes": ["narrative"],
     "reason": "莊子妻死，「鼓盆而歌」，自述從「概然」到察其始而本無生，是面對死亡與喪妻之後的安頓"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。**每一列都要有非空 `reason`。
