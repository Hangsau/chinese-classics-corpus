# 發包 spec：管子 段落級標註

## 你要做什麼

讀 `delegation/guanzi/bNN.md`（NN 是這次指派給你的批號），逐段判兩件事：

1. `domains`：這一段觸及哪些人生問題領域（下表 13 個 id，可以是空陣列）
2. `modes`：這一段用什麼方式說話（下表 8 個 id，可以是空陣列）

輸出寫成 `delegation/guanzi/out/bNN.json`，格式見文末。

## 這部書是什麼

《管子》，戰國至漢初管仲學派著述，收 76 篇，本庫落地 668 段、切成 24 批。全書體裁極為混雜：既有法家治術，也有黃老修養論、宏觀經濟政策（輕重），乃至農業知識與軍事。**這部書比韓非子更雜，「管子」不是一個判讀單位。**

> **不要把韓非子 23% 的判空比例搬過來當預期值，也不要把商君書、慎子的比例搬來。**這部書各篇的內容落在判準的哪一側本來就大不相同——論說篇近乎全命中，輕重篇大量判空，黃老修養篇落在中間。**尤其不要用前一批的比例推下一批。**

## 通則性閘門

法家整體在講怎麼立法、怎麼賞罰、官制怎麼設，**每一段都在談人**——「有沒有提到民、君、賞罰」不是判準。問：

> **這一段除了「該立什麼法／怎麼賞罰／官怎麼設、令怎麼下／名分怎麼定」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指**人是什麼樣的、人可以怎麼活、人有哪些品性、人與人之間如何**。

操作上最好用的分界：

> **文本有沒有自己把「人是什麼樣的」當成依據說出來？**
> 說了 → 命中。
> 只給「做 A 則得 B」的政策鏈、調控條文、制度條文，不解釋人為何如此 → 判空。

**這一格與兵書相反。**兵書拿仁義當致勝條件時判空（工具不是主張），法家把人性當統治依據時要命中——差別在於兵書那句沒有說人是什麼樣的，法家這句說了。**工具性動機不能拿來當判空理由**：段落的用意百分之百是工具性的（要君主知道民欲），只要它確實斷言了人是什麼樣的，就命中。

## 本書分成七種體例，判法不同——先認出你手上這一段屬於哪一種

**這比批號重要。**同一批裡可能有兩三種體例，逐段先問「這一段在做什麼」。

### A. 論說篇與政論篇（命中最密的一端）

含〈牧民〉〈权修〉〈立政〉〈五輔〉〈法禁〉〈重令〉〈法法〉〈兵法〉〈君臣上〉〈君臣下〉〈小稱〉〈四稱〉〈任法〉〈正世〉〈治國〉〈七主七臣〉〈禁藏〉〈九守〉〈桓公問〉〈度地〉〈侈靡〉（部分）等。

**這一類通篇在論立政原則與人的狀態，預期高命中。**〈牧民〉[3]「民惡憂勞，我佚樂之；民惡貧賤，我富貴之」是直說人的好惡，命中 VI 或 VII；[2]「四維不張，國乃滅亡」在論人的行為邊界，命中 VII 或 V。

### B. 術治條文篇（判空更多的一端）

含〈版法〉〈明法〉〈制分〉〈地圖〉〈參患〉〈封禪〉〈弟子職〉（部分）等。

**這一類是制度操作手冊，預期大量判空。**「凡一曰二曰三曰」的分類綱目、官制條列一律判空＋`formalization`。**但逐段看，不要整章判空**，末尾若轉向解釋人為何如此，就照末尾判。

### C. 經／解成對篇——**本書最大的陷阱，等同韓非子的儲說**

〈第02篇形勢〉↔〈第64篇形勢解〉（b17，全書最大批 93 段）
〈第04篇立政〉↔〈第65篇立政九敗解〉（b18）
〈第07篇版法〉↔〈第66篇版法解〉（b18）
〈第46篇明法〉↔〈第67篇明法解〉（b19）

> **管子的「解」是逐句疏釋正文，不是韓非子儲說的「故事」。解篇的每一段自己在做論說，走通則性閘門逐段判。解篇絕不繼承對應經篇的判斷，要自己讀自己這一段說了什麼。**

形勢解（93 段）逐句展開〈形勢〉原文，常見格式是引一句原文→疏釋其含義。**引句本身有沒有說人是什麼樣的，要從疏釋文字判，不要只看原句是否熟悉。**

### D. 黃老修養篇（離開法家語言的一端）

含〈第36篇心術上〉〈第37篇心術下〉〈第38篇白心〉〈第49篇內業〉（b12/b13/b14）。

**這幾篇離開法家語言，談心、氣、靜、精神修養。**預期這一區像韓非子的〈解老〉——高命中且 domain 覆蓋寬（VII、VI、I、XIII、X、XI 都可能出現）。

> **「精」「氣」「神」在這幾篇是修養論術語，不是生理術語，也不是宗教術語。**與醫書的「神魂魄」不同，這幾篇的「精氣」在討論人怎麼活、怎麼養心。**不要因為出現「神」就反射填 XII**（同醫書的「神魂魄是生理術語不給 XII」那條判準的精神），除非那段真的在談人與神聖者的關係。

另外：〈第39篇水地〉〈第40篇四時〉〈第41篇五行〉（b13）是黃老宇宙論，討論水土性質、四時五行與人的關聯，預期偏高判空，但若文本把四時五行與人的德行、修養或命運直接對應，就照對應判。

### E. 輕重經濟條文（預期高判空）

含〈第69篇乘馬數〉〈第72篇海王〉〈第73篇國蓄〉〈第74篇山國軌〉〈第75篇山權數〉〈第76篇山至數〉〈第77篇地數〉〈第78篇揆度〉〈第79篇國准〉〈第79篇國準〉〈第80篇輕重甲〉〈第81篇輕重乙〉〈第83篇輕重丁〉〈第84篇輕重戊〉〈第85篇輕重己〉（b19–b24）。

**這一類是宏觀經濟調控條文，三小部與韓非子都沒有的體裁。預期高判空＋`formalization`。**

> **「調價格 → 民會怎麼反應 → 則國富矣」這個政策鏈套語是本書最大的硬撈風險，要指名道姓。**這種格式表面滿滿是人（民）會怎麼反應，實則只有推論沒有主張——「民，予則喜，奪則怒」這一型看起來在說人的心理，但它在政策鏈裡只是推導一步，沒有把「民這樣是因為……」的人性依據說出來。**遇到這一型，先判空，除非文本另有一句直說人的樣態。**

> **但適用第④條**：同一段若有一句直說人的樣態（例如「民，予則喜，奪則怒」本身被當成依據而非只是推論的結論），就照那一句判。

### F. 歷史敘事篇（含〈匡君大匡〉〈中匡〉〈小匡〉〈霸形〉〈霸言〉〈小問〉〈戒〉）

這幾篇含有管仲與齊桓公的對話敘事，走 §2.2「刪除閘門」：

> **把這一則對話或事件刪掉，讀者少知道了什麼？**
> 少的是史料事實（誰說了什麼、做了什麼政策決定）→ `[]`。
> 少的是對人的看法（人可以怎麼活、某種領袖是什麼樣的）→ 命中。

敘事段預設走 `narrative`，若是論說段走 `proposition`/`prescription`。

### G. 特殊章節

**b01 的「注釋本」2 段（para_index 1–2）是版本附記而非正文。**

> **這 2 段全部判空 `[]`，`modes` 給 `["formalization"]`，`reason` 統一寫「版本附記，非正文——[1] 尹知章《管子注》，[2] 章炳麟《管子餘義》」。不要試圖從附記推斷書的內容。**

「七法」「七法/七法」「七法/四傷百匿」「七法/爲兵之數」是來源把〈七法〉子節切成獨立章的結果。章名逐字照抄（含斜線），MANIFEST 以完整字串為 key，改了會讓 check-delegation-out 報缺。

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、制度表、數量比例、綱目分類表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | **本書不會用到** |

要點：

- **`formalization` 在本書會大量出現**（輕重條文、地員土壤分級、弟子職禮節程序），不要迴避
- **`narrative` 在歷史敘事篇（F 類）出現**（匡君大匡、中匡、小匡等）
- **`expression` 只給引號內的第一人稱話語**，第三人稱論述一律不算
- **`ritual` 只給封禪、祭儀等禮節程序段**
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**。負面結果本身是資料。**本書七種體例的判空比例落差極大，不要用前幾章的比例推後面。**
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **`reason` 裡寫的話必須在原文找得到。**不可以替原文補上它沒說的東西，也不可以用你對管仲、管子學派的既有知識去補。判斷依據只有你眼前這一段的文字。
4. **不要更動 `chapter` 與 `para_index`**。章名逐字照抄，**繁簡與異體都照抄不要統一**（「第79篇國准」與「第79篇國準」是兩個不同的 `chapter` 值，寫錯會整批退回）。`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。
5. **不要判斷書中的政治主張對不對，也不要評價它的道德立場。**你的工作是記錄這一段在做什麼。
6. **章序不是書序，批次是按段數切的。**照你手上那一批的實際內容判，不要去猜別批有什麼。
7. 原文有訛字、異體與費解處，那是傳世本實況。**看不懂的句子不要硬掰內容，判空並在 `reason` 說明文意不明。**
8. **直接執行，不要先提出計畫徵求確認。**這是非互動式呼叫，你回問就等於整批白做。
9. **本次交付物就是那個 .json 檔本身。**寫完後把該檔讀回來確認存在且 rows 數正確，然後停止。不要做任何 git 操作。
10. **你唯一可以建立或修改的檔案是 `delegation/guanzi/out/<本批>.json`**。別批的 out/*.json 是已驗收成果，禁止修改。
