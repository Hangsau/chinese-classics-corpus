# 發包 spec：神異經 段落級標註

## 你要做什麼

讀 `delegation/shenyijing/b01.md`（61 段，全書），逐段判兩件事：

1. `domains`：這一段觸及哪些人生問題領域（下表 13 個 id，可以是空陣列）
2. `modes`：這一段用什麼方式說話（下表 8 個 id，可以是空陣列）

輸出寫成 `delegation/shenyijing/out/b01.json`，格式見文末。

## 這部書是什麼

《神異經》託名東方朔，仿《山海經》體例，按八方＋中荒分卷，逐條記荒外的山、樹、獸、人、宮室、礦產。**它不是故事集，沒有情節，沒有敘事者的立場。**每一條的標準句式是「東方有樹焉，高百丈……」——先說某地有某物，再說它長什麼樣、有什麼用。

**這一部是刻意挑來檢驗判準的：本庫已標的八部，每一部都有一個在說話的人**（兵家的謀者、算家的出題者、論者、家長、軼事的編者）。神異經是第一部**作者不在場**的文本。要驗的是：**當沒有人在下判斷時，判準會不會空轉**——會不會因為條目裡出現了「人」「食之」「國」「壽」這些字，就硬讀出人生問題來。

**所以本批的預設答案是 `[]`。**但這不是配額，見下一節。

## 唯一的通則性閘門（博物誌版本）

> **這一條除了「世上有這麼個東西」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指的是：人可以怎麼活、人有哪些惡、什麼樣的人算好、人與人之間該如何。**不是**指條目裡出現了人形生物，也不是指它對人有用。

兩個對稱的錯法都要防，**兩者一樣糟**：

- **硬撈**：看到「食之令人益壽」就填 X（無常老死），看到「其國大旱」就填 IX（苦難疾病），看到「人民」「君」就填 V。這些是物產功效與地理記載，不是在談死亡、疾病或公義。
- **判空太快**：看到「這是一部志怪／博物書」就整批判空。本書確實有一批條目在用怪物講人的惡與善，那些是真命中，漏掉就等於沒讀。

**不要為了讓結果符合「預設判空」而判空。**預設是起點不是目標；本批的用途是看判準準不準，硬湊出來的空跟硬湊出來的滿一樣沒有價值。

## 本書真正會命中的那一類：**用怪物寫道德類型**

神異經有一批條目表面在記獸，實際在給一種人格取名字。判斷方式是問：**把這條裡的道德描述拿掉，還剩下什麼？**剩下的只是「有這麼一隻獸」——那道德描述就是這一條的內容本身，不是裝飾。

典型（這些是真命中，不要判空）：

- 記某獸「聞人鬥輒食直者，聞人忠信輒食其鼻，聞人惡逆不善輒殺獸往饋之」——這是一套**顛倒的賞罰**，整條都在寫這件事
- 記某獸「人有德行而往牴觸之，有凶德則往依憑之」——同上
- 記某族「貪如狼惡，好自積財……強者奪老弱者，畏群而擊單」並註明《春秋》稱之為不才子——這是在定義一種惡
- 記某方之人「恒恭坐而不相犯，相譽而不相毀，見人有患，投死救之，名曰善人」——這是在定義一種善
- 記某鳥身上的紋分別寫著不孝、不慈、不道、愛夫、憐婦，並說「故天立此異，畀以顯忠孝也」——結尾直接把用意說出來了

反面（這些要判空）：

- 記樹高幾丈、葉幾尺、實幾寸、味甜或酸
- 記某物「食之令人益壽」「食之為地仙」「飲此酒人不生死」「食之可以止瘡癘」——這是**本草式的功效記載**，跟這一條談不談死亡或超越無關。**這是本書最大的硬撈風險，全書出現多次，一律判空**，除非該條另外說了關於人的什麼
- 記火山、銀山、金闕、銅柱、宮墻顏色、鳥獸形貌尺寸
- 記某獸食人、某蟲叮人——那是習性不是苦難
- 記某物出現則旱、殺之則禍去福來——那是物候與禳除，不是在談苦難或命運

## `Z-wisdom` 陷阱

本書幾乎不會踩到（沒有論辯、沒有方法論外殼）。若真遇到只在講「如何辨識某物」的條目，那屬 `Z-wisdom`，`domains` 判空。**`Z-wisdom` 絕不可寫進 `domains`。**

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法或制度 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

本書預期 `observation` 佔絕大多數。要點：

- 「東方有樹焉，高百丈」是 `observation`，不是 `narrative`——**沒有情節就不是敘事**，光有一隻獸在做事不算
- 條目結尾點出道理（「故天立此異，畀以顯忠孝也」）→ 加 `proposition`
- 引《春秋》《書》《詩》作註仍是 `observation`，不因為引書而變別的
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **不要更動 `chapter` 與 `para_index`**。它們是錨點，錯一個就整批對不上。`para_index` 在每一章內從 1 重新編號，所以**回報時章名與 para_index 兩者都要給**。
4. **`Z-wisdom`、`X-modern`、`Y-nature` 不是領域**，絕不可出現在 `domains`。
5. **不要用你對《山海經》或這些神話名物的既有知識去補條目沒說的東西。**只判這一段文字寫了什麼。饕餮在別處的典故不算，本條寫了什麼才算。
6. 文中的 `[1]` `[2]` 這類方括號數字是原書註釋編號，不是內容，判讀時忽略。

## 輸出格式

寫到 `delegation/shenyijing/out/b01.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "東荒經九則", "para_index": 4, "domains": [], "modes": ["observation"],
     "reason": "記桑樹高廣與蠶繭出絲，純物產描述，未觸及對人的看法"},
    {"chapter": "西北荒經六則", "para_index": 1, "domains": ["VII"], "modes": ["observation"],
     "reason": "窮奇食正直者、食忠信者之鼻、反饋惡逆者，整條在寫一套顛倒的賞罰"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。** 這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，但**判 `[]` 的段落也要寫 `reason`**——寫出你認為它少了什麼。本批的全部價值就在這些 reason 上，它們是驗證判準的依據，不要寫成「無關」兩個字了事。
