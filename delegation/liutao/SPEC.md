# 發包 spec：六韜 段落級標註

## 你要做什麼

讀 `delegation/liutao/bNN.md`，逐段判兩件事：

1. `domains`：這一段觸及哪些人生問題領域（下表 13 個 id，可以是空陣列）
2. `modes`：這一段用什麼方式說話（下表 8 個 id，可以是空陣列）

輸出寫成 `delegation/liutao/out/bNN.json`，格式見文末。

## 這部書是什麼

《六韜》託名太公望，戰國成書的兵書，分六卷 60 篇：**文韜（12 篇）、武韜（5 篇）、龍韜（13 篇）、虎韜（12 篇）、豹韜（8 篇）、犬韜（10 篇）**。切批時六個卷首標題章（只有「第一篇 文韜」一行）已被排除，所以你拿到的每一段都是正文。

**全書 60 篇沒有例外，全是同一個外殼**：「武王（或文王）問太公曰：『……』太公曰：『……』」，常以「武王曰：『善哉！』」收尾。**這個外殼本身不承載任何判讀訊息**——不要因為它是問答就給 `expression`，也不要因為每篇都長得一樣就整批用同一個答案。

**內容分成四種，拉力完全不同，下面各寫一節。**前一部書（急就篇）就是因為陷阱清單只為第一卷而寫、漏掉第二卷，整批判讀作廢重跑。這裡不要重蹈。

## 通則性閘門

兵書整部在講怎麼打仗、用什麼打、怎麼傳令，內容表面上全與人有關（士卒、將領、敵我）。所以問：

> **這一段除了「怎麼打／用什麼打／怎麼傳令／怎麼看出勝負」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指**人可以怎麼活、人有哪些品性、人與人之間如何、什麼樣的人該被託付什麼**。

**不是**指段落裡出現了人（兵書每一段都有人）、出現了「仁義」兩個字（兵書拿仁義當致勝條件時，那是工具不是主張），也不是指那件戰法的對象是人。

兩個對稱的錯法都要防：

- **判空太快**：看到「這是兵書」就整批判空。文韜、武韜大半在論政論人，判空會漏掉本書最實的部分
- **硬撈太多**：看到「將不仁則三軍不親」就填 VII。那句在講將領失格會導致什麼戰場後果，仁是條件不是主題

正解只有一個：**逐段真的讀懂它在做什麼，然後照實記。**

## 第一種：文韜、武韜——論政論人，命中密集區（b01）

這兩卷幾乎不談戰術，談的是「國怎麼治、人怎麼用、賞罰怎麼給」。**這裡是全書最該命中的地方，不要因為書名是兵書就保守。**

會命中的典型（這是下限不是上限，沒列到的照樣照實判）：

- 〈國務第三〉「愛民而已……故善為國者，馭民如父母之愛子」——整篇在講治理者對被治理者的責任 → **V**
- 〈六守第六〉「富之而觀其無犯；貴之而觀其無驕……仁義忠信勇謀」——用處境試出人的品性，且逐項定義 → **VII**（品性本身）＋ **VIII**（識人以任事）
- 〈舉賢第十〉「舉賢而不用，是有舉賢之名而無用賢之實也……按名督實，選才考能，令實當其能，名當其實」——名與實的分裂 → **II**（名實）＋ **VIII**
- 〈上賢第九〉六賊七害逐條點名各種敗壞的人（結朋黨蔽賢智、有名無實掩善揚惡、樸其身躬語無為以求名的偽人）→ **VII**＋**V**
- 〈盈虛第二〉「禍福在君不在天時」——把治亂歸因於人而非天 → **XI**（命定與人為）＋ **V**
- 〈明傳第五〉「義勝欲則昌，欲勝義則亡；敬勝怠則吉，怠勝敬則滅」——在講人內部的較量 → **VII**

不會命中的典型：

- 〈文伐第十四〉十二節伐交權術（陰賂左右、收其內、輔其淫樂）——這是**操作手冊**，教怎麼瓦解對手，不是在談人該怎麼活 → `[]`
- 〈兵道第十六〉〈三疑第十七〉——用兵原則與權謀，方法論外殼 → `[]`
- 〈王翼第十八〉七十二人編制表（腹心一人、謀士五人、天文三人……）——職官編制 → `[]`＋`formalization`

**分界線**：同樣寫「用人」，〈舉賢〉問的是「怎樣算真的用了賢人」（關於人），〈王翼〉列的是幕府該配幾個什麼官（編制表）。前者命中，後者判空。

## 第二種：龍韜——一卷之內裂成兩半（b02 大半）

**這一卷必須逐篇分開判，它是全書內部落差最大的一卷。**

**會命中的半邊（論將）**：

- 〈論將第十九〉五材十過（勇、智、仁、信、忠；勇而輕死、急而心速、貪而好利、仁而不忍人……）——**逐項在寫人的性格弱點如何毀事**，是全書最像人物志的一篇 → **VII**（品格）＋ **VIII**（能不能勝任）
- 〈選將第二十〉八徵（問之以言以觀其詳、窮之以辭以觀其變、與之間諜以觀其誠、明白顯問以觀其德、使之以財以觀其廉、試之以色以觀其貞、告之以難以觀其勇、醉之以酒以觀其態）——**外貌與內實不相符**（「士有外貌不與中情相應者十五」）→ **VII**＋**II**
- 〈勵軍第二十三〉「將冬不服裘，夏不操扇……將與士卒共寒暑勞苦饑飽，故三軍之眾聞鼓聲則喜……士非好死而樂傷也，為其將知寒暑饑飽之審」——**在解釋人為什麼願意為另一個人赴死** → **V**（責任與領導）
- 〈將威第二十二〉「殺貴大，賞貴小……刑上極，賞下通」——賞罰及於貴賤兩端才立得起威信 → **V**
- 〈立將第二十一〉君將授鉞、「國不可從外治，軍不可從中御」——君將之間的信任與權責邊界 → **V**

**判空的半邊（協定與方法論）**：

- 〈陰符第二十四〉八等符信各長幾寸、洩密者誅 → `[]`＋`formalization`。**這是通訊協定，不是人與人之間的信任問題**
- 〈陰書第二十五〉分書為三部、三人各操一分而不相知 → `[]`＋`formalization`
- 〈軍勢第二十六〉「用兵之害，猶豫最大。三軍之災，莫過狐疑」——**這是本卷最尖銳的硬撈陷阱**。看起來在談猶豫與恐懼（像 VI），實際整篇在講決斷的技術與「勝於無形」的用兵原則，猶豫是被當成戰術缺陷講的 → `[]`
- 〈奇兵第二十七〉一長串「所以……者」戰術對照表 → `[]`。末尾「將不仁則三軍不親，將不勇則三軍不銳」照樣不給 VII，那是把品性列成戰力條件

## 第三種：占候與器械——最容易反射填錯的一節（b02 後半、b03）

**占候三篇的 XII 要卡到最緊：**

- 〈五音第二十八〉律管候敵、五行青龍白虎朱雀玄武、「五行之神，道之常也」「六甲之分，微妙之神」——**這是技術性占驗，不是人與神聖的關係** → `[]`。「神」「五行」「三皇」在這裡是術數術語，同醫書裡的「神」「魂」「魄」是生理術語，一律不給 XII
- 〈兵徵第二十九〉望城之氣色定可攻不可攻、「此得神明之助，大勝之徵也」——同上，`[]`＋`observation`
- 〈三陳第三十二〉天陳地陳人陳（日月星辰／丘陵水泉／用車用馬）→ `[]`＋`formalization`
- **但〈兵徵〉前半不一樣，要單獨判**：「凡三軍悅懌，士卒畏法，敬其將命，相喜以破敵……此強徵也；三軍數驚，士卒不齊，相恐以強敵，相語以不利，妖言不止，眾口相惑，不畏法令，不重其將，此弱徵也」——這在寫**一群人的情緒與互信如何整體垮掉**。可考慮 **V** 或 **VI**；判不出來就判空並在 `reason` 說明你為什麼認為那只是勝負徵候

**器械與戰法一律判空，這是本書段數最多的一類：**

- 〈軍用第三十一〉全篇是器械清單（武衝大扶胥三十六乘、方首鐵棓重十二斤柄長五尺、飛鉤長八寸……）→ `[]`＋`formalization`。**清單很長不代表內容多**，這與前一部書（急就篇）卷二的名物篇是同一類陷阱
- 〈火戰〉〈林戰〉〈突戰〉〈必出〉〈絕道〉〈略地〉〈分險〉等：遇某種地形或敵情該怎麼處置 → `[]`＋`prescription`
- 〈金鼓〉〈臨境〉〈動靜〉〈壘虛〉：號令與偵察 → `[]`
- 〈戰車〉〈戰騎〉〈戰步〉〈均兵〉：兵種比例與地形勝負 → `[]`＋`formalization`

**兩篇要單獨想過，不要跟著整批判空**（判不出來就判空並在 `reason` 說明）：

- 〈農器第三十〉把農具逐項對應成兵器（耒耜即行馬蒺藜、鋤耰之具即矛戟），末尾「善為國者，取於人事……丈夫治田有畝數，婦人織紝有尺度，其富國強兵之道也」——前半是類比表（判空），末尾在講怎麼組織一國的生產與人力。可考慮 **V** 或 **VIII**
- 〈練士第五十三〉把士卒按動機分類編伍：「有勇力願死傷者聚為一卒」「贅婿人虜欲掩迹揚名者」「死將之人子弟欲與其將報仇者」「貧窮憤怒欲快其志者」——這是**按人為什麼肯拼命來分類**，可考慮 **II**、**VIII** 或 **V**；若你判定它只是編伍規格表，就判空並說明

`Z-wisdom`、`X-modern`、`Y-nature` **不是領域**，絕不可出現在 `domains`。

**本書特別提醒的三格**：

- **X（死亡）**：兵書滿篇死傷。「士非好死而樂傷也」「殺一人而三軍震者殺之」都不是 X——那是戰爭的手段與後果。要給 X，得是這一段真的在談死亡本身
- **XII（神聖）**：見上一節，占候術數不給
- **VI（情緒）**：「三軍恐怖」「聞鼓聲則喜」是戰場反應的描述，不是在寫情緒如何住在人身上。要給 VI，得是這一段在處理情緒本身

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、編制表、器械規格、數量比例 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

要點：

- **主導 mode 是 `proposition`（「故 A 則 B」）與 `prescription`（當為句）**，兩者常同現
- **`formalization` 在本書數量會很大**（器械規格、兵種比例、編制表、符信長度、陣法方位）。不要因為它不像制度表就迴避——它綁的是「有可執行的程序」，與領域無關
- **不要給 `expression`。**全書都是武王與太公的對話，但那是問對框架不是自道；`expression` 要整段就是說話者抒發自己的處境
- **`narrative` 全書幾乎只有一處**：〈文師第一〉文王卜得太公、坐茅以漁、載與俱歸的那段有人物有情節。其餘篇章的「武王問曰」不是敘事
- 〈兵徵〉望氣、〈五音〉候管雖涉術數，**不給 `ritual`**——它們是偵測程序不是儀節。`ritual` 要有規定的動作時序與器物且以儀節本身為目的（〈立將第二十一〉君「親操鉞持首授將其柄」的授鉞儀節才是）
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。**本書判空的段數預期會遠多於命中**，這正常。
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **`reason` 裡寫的話必須在原文找得到。**不可以替原文補上它沒說的東西，也不可以用你對《六韜》或太公望的既有知識去補。判斷依據只有你眼前這一段的文字。
4. **不要更動 `chapter` 與 `para_index`**。章名逐字照抄（「將威第二十二」「烏雲山兵第四十七」，含中文數字序號），`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。
5. **不要判斷書中的軍事主張對不對，也不要評價它的道德立場。**你的工作是記錄這一段在做什麼。
6. 原文有異體字、夾注（〈兵家取此象〉）、引號不對稱，那是來源格式，不影響判讀。

## 輸出格式

寫到 `delegation/liutao/out/bNN.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b02.md",
  "rows": [
    {"chapter": "勵軍第二十三", "para_index": 1, "domains": ["V"], "modes": ["proposition", "prescription"],
     "reason": "將與士卒共寒暑勞苦饑飽，並明說士非好死而樂傷、是因將知其寒暑饑飽，在解釋人為何願為另一人赴死"},
    {"chapter": "陰書第二十五", "para_index": 1, "domains": [], "modes": ["formalization"],
     "reason": "分書為三部、三人各操一分而不相知情，全段是通訊協定的操作規定，沒有說到關於人的什麼"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。** 這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，**判 `[]` 的段落也要寫 `reason`**，至少要指出它在做的是戰法處置、器械規格、通訊協定、占候程序，還是別的。

## 不要做的事

- 不要改 `translations/` 底下任何檔案
- 不要跑 git 指令（commit、reset、pull、checkout、stash 一律禁止）
- 不要改 `delegation/liutao/` 的輸入 `.md` 與 `MANIFEST.json`
- 只寫 `delegation/liutao/out/` 底下你這一批的那個 `.json`
