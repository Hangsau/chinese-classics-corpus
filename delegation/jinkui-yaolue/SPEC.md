# 發包 spec：金匱要略 段落級標註

## 你要做什麼

讀 `delegation/jinkui-yaolue/bNN.md`，逐段判兩件事：

1. `domains`：這一段觸及哪些人生問題領域（下表 13 個 id，可以是空陣列）
2. `modes`：這一段用什麼方式說話（下表 8 個 id，可以是空陣列）

輸出寫成 `delegation/jinkui-yaolue/out/bNN.json`，格式見文末。

## 這部書是什麼

《金匱要略》東漢張仲景撰，與《傷寒論》同源而分治雜病，宋林億校定。二十五篇，主體是「某病脈證並治」——先立病名與脈證，再出方。四種東西混成：

| 體例 | 內容 | 預設 |
|---|---|---|
| 各篇「辨某病脈證並治」 | 「病某某者，脈某，某湯主之」 | `[]`，全書大宗 |
| 方劑組成與煎服法 | 「右三味，以水七升，煮取三升，分溫再服」 | `[]` |
| 【附方】／附方：／附注：《外臺秘要》方 | 後人採他書補入的方 | `[]` |
| 末二篇食物禁忌（第二十四、二十五） | 「凡某某不可食之」逐條 | **多半 `[]`，但有兩三條例外，見下** |

**這部書沒有作者自序。**《傷寒論》裡張仲景原序那一整塊人的內容，本書沒有對應物。不要去找。

## 唯一的通則性閘門

> **這一段除了「這種病長什麼樣／該怎麼治／什麼不可吃」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指的是：人怎麼對待自己的身體與性命、人在病與死面前是什麼處境、人與人之間如何。**不是**指這一段提到了病、死、身體部位或藏府。

## 最大的硬撈風險：**「死」「不治」遍布全書**

「其目正圓者痙，不治」「唇口青，身冷，為入臟即死」「呼吸動搖振振者，不治」「從四肢流來入口者不可治」——這是**預後判語**，在說什麼證候對應什麼結局，不是在談死亡。一律 `[]`。

同理一律 `[]`：

- 病名與證候定義（「太陽病，發熱無汗，反惡寒者，名曰剛痙」）
- 方劑組成與煎服法（「麻黃三兩去節　杏仁七十個　甘草一兩炙。上三味，以水八升，煮取三升」）
- 【附方】整塊
- 食物禁忌條目（「肉中有朱點者，不可食之」「六畜肉，熱血不斷者，不可食之」「諸肉及魚，若狗不食，鳥不啄者，不可食」）——這是**辨壞食物的判準表**，不是在講人該怎麼活
- 中毒解方（「食某某中毒，某某汁解之」）

**末二篇 154 段幾乎全屬此類，是本書最容易整批做錯的地方。**

## 反過來也要防：本書有四處真的離開了病與方，**不要因為它印在醫書裡就跟著判空**

以下是**該用力讀的位置**，不是保證命中的清單——過不過閘門照文字判，判空要在 `reason` 寫出為什麼：

1. **臟腑經絡先後病脈證第一 #1**「上工治未病……中工不曉相傳，見肝之病，不解實脾，惟治肝也」——這是在分醫者的高下。若你認為它整段仍是在講治法而分等只是引子，判空並說明；若你認為它在講這門職業做得好不好，給 VIII
2. **同篇 #3**「若人能養慎，不令邪風干忤經絡……更能無犯王法、禽獸災傷，房室勿令竭乏，服食節其冷熱苦酸辛甘，不遺形體有衰」——這一條開出的是**一整套生活自持**，「無犯王法」已經在醫學之外
3. **雜療方第二十三 #29**「上療自縊溺暍之法并出自張仲景為之，其意殊絕，殆非常情所及……實救人之大術矣」——這是在替這門技藝的價值作評斷
4. **禽獸魚蟲禁忌第二十四**裡兩條與其餘八十幾條性質不同：
   - 「凡心皆為神識所舍，勿食之，使人來生復其報對矣」——講來生報應
   - 「父母及身本命肉，食之令人神魂不安」——講父母與本命

   這兩條的禁忌理由不是壞肉會讓人生病，而是別的東西。**判它們要看你怎麼讀那個理由**，給不給 XII／IV 都要在 `reason` 說出依據

**除了這幾處，本書幾乎全是病與方。**

## 婦人三篇（第二十、二十一、二十二）要特別想清楚

「婦人妊娠病」「婦人產後病」「婦人雜病」共 59 段。直覺會想給 III 或 IV。判準是同一道閘門：

- 「婦人懷娠六七月，脈弦發熱，其胎愈脹，腹痛惡寒者……當以附子湯溫其臟」→ 這是**妊娠期的病候與治法**，胎與婦只是病位。`[]`
- 「婦人之病，因虛、積冷、結氣，為諸經水斷絕，至有歷年，血寒積結胞門」→ 病因論。`[]`
- 只有當文本真的在寫**這個人在她的處境裡怎麼樣**（而不是她的身體出了什麼證候）才給領域

**不要因為章名有「婦人」就反射填 III／IV。**

## IX 這一格要特別想清楚

IX 是「苦難·疾病·身體」。這是一部治雜病的書，直覺會想給。判準是同一道閘門：

- **病作為技術的對象** → `[]`。「病歷節不可屈伸，疼痛，烏頭湯主之」是在指派治法，不是在寫痛苦
- **病作為人的處境** → IX。有人在病裡、在身體的限制裡，而文本在寫那件事

本書幾乎全屬前者。**不要為了讓 IX 有數字而硬撈，也不要因為「醫書判空聽起來很怪」而回頭補。**

## `Z-wisdom` 陷阱

本書絕大部分是「如何辨病、如何處方」的技藝與體系，那屬 `Z-wisdom`（方法與體系），**`domains` 判空**。`Z-wisdom` 絕不可寫進 `domains`。

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、方陣或制度表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

要點：

- 病候定義（「某某之為病，脈某」）是 `observation`
- 「某湯主之」的治法指派是 `prescription`；病候與治法同段時兩個都給
- **方劑組成與煎服法給 `formalization`**（幾味、幾兩、水幾升、煮取幾升、日幾服）。這是本書 `formalization` 的主要來源，數量會很大，**不要因為它不像「制度表」就迴避**
- 食物禁忌逐條（「某某不可食之」）給 `prescription`
- 「問曰……師曰……」的問答形式**不影響 mode**，看它答的內容是什麼
- 「五臟元真通暢，人即安和」「風氣雖能生萬物，亦能害萬物」這類講機理的推論給 `proposition`
- 救自縊、救卒死的施救步驟（「一人以腳踏其兩肩，手少挽其髮……一人摩捋臂脛，屈伸之」）是可執行程序 → `formalization`（或 `prescription`，挑主導的）
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **不要更動 `chapter` 與 `para_index`**。它們是錨點，錯一個就整批對不上。`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。章名逐字照抄，**包括 `【附方】（1）`、`附方：`、`附注：《外臺秘要》方` 這幾個看起來不像章名的章名——來源就是這樣切的，照抄，不要合併也不要改寫**。
4. **`Z-wisdom`、`X-modern`、`Y-nature` 不是領域**，絕不可出現在 `domains`。
5. **不要用你對中醫、對張仲景的既有知識去補文本沒說的東西**，也不要判斷醫理對不對。
6. 夾注用〈〉標出（「〈疑非仲景方。〉」「〈見《千金翼》。〉」），那是校語，不改變該段判讀。

## 輸出格式

寫到 `delegation/jinkui-yaolue/out/bNN.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "痙濕暍病脈證並治第二", "para_index": 1, "domains": [], "modes": ["observation"],
     "reason": "立剛痙的病名與辨識條件，是病候定義，病在此是技術對象不是人的處境"},
    {"chapter": "雜療方第二十三", "para_index": 25, "domains": [], "modes": ["formalization"],
     "reason": "逐步規定三人如何合力施救自縊者，是可執行的急救程序"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。** 這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，但**判 `[]` 的段落也要寫 `reason`**——**判空段落佔本書大宗，那些 reason 是驗證判準的依據**，不要寫成「醫方」兩個字了事；至少要指出它在做的是辨病、處方、服法還是食忌。
