## 這部書是什麼

《慎子》，戰國稷下學者慎到之書，清錢熙祚校刊本。原書四十二篇今僅存殘卷，**現存本由兩塊性質完全不同的東西拼成**：

- **b01（14 段，7 章）**：〈威德〉〈因循〉〈民雜〉〈知忠〉〈德立〉〈君人〉〈君臣〉——依《群書治要》所存的完整篇章，是連貫論說文
- **b02（61 段，2 章）**：〈慎子逸文〉60 段＋〈慎子跋〉1 段——逸文是從《意林》《太平御覽》《文選》注等類書裡輯出的**散句殘文**，長短相差極大，短的只有四個字；跋是清代校勘者錢熙祚的版本考證

慎到的主張是**「勢」與「法」**：權位本身（而非賢能）決定人服不服，所以治國要靠法度與名分，不靠君主的個人德性與智慧。

> **不要把同組其他法家書的判空比例搬過來當預期值。**體裁差異不是判準差異——判準完全一致，只是每部書的內容落在判準的哪一側本來就不同。
>
> 反過來也一樣：**不要因為它是子書就整批硬撈。**逸文裡有大量只是一個名物、一個年代、一句殘缺比喻的斷片，那些判空才是正確答案。

## 通則性閘門

法家整部在講怎麼立法、怎麼賞罰、怎麼使民、官制怎麼設，**每一段都在談人**——所以「有沒有提到民、人情、賞罰」完全不是判準。問：

> **這一段除了「該立什麼法／怎麼賞罰／官怎麼設、令怎麼下／名分怎麼定」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指**人是什麼樣的、人可以怎麼活、人有哪些品性、人與人之間如何**。

操作上最好用的一條分界：

> **文本有沒有自己把「人是什麼樣的」當成依據說出來？**
> 說了 → 命中。
> 只給「做 A 則得 B」的政策鏈或制度條文，不解釋人為何如此 → 判空。

**這一格與兵書相反，要特別注意。**兵書拿仁義當致勝條件時判空（「將不仁則三軍不親」——那是工具不是主張）。**但法家把人性當統治依據時要命中**，差別在於：兵書那句沒有說人是什麼樣的，法家這句說了。

〈因循〉「因也者，因人之情也。人莫不自爲也，化而使之爲我，則莫可得而用矣」——它的用意百分之百是工具性的（要拿來用人），但它**確實斷言了人是什麼樣的**（人沒有不為自己的）。**工具性動機不能拿來當判空理由。**

## b01——《治要》所存七篇

### 必須命中的段落（判空即為漏判）

- **〈因循〉[1]**「因也者，因人之情也。人莫不自爲也，化而使之爲我，則莫可得而用矣……故用人之自爲，不用人之爲我」——**全書最明確的人性斷言** → **VII**（人的本性）或 **VIII**（用人任事）或 **V**，挑主導的一到兩個
- **〈民雜〉[1]**「民雜處而各有所能，所能者不同，**此民之情也**」——原文自己標明「此民之情也」，且後半在講因人之能而用 → **VIII** 或 **II**（可併 V）
- **〈知忠〉[1]**「忠未足以救亂世，而適足以重非」「孝子不生慈父之家，而忠臣不生聖君之下」「忠盈天下，害及其國」——**整篇在重估「忠」這件事的價值**，是對德目本身的明確主張 → **VII**（可併 V）

### 會命中的典型

- **〈威德〉[1]** 天有明不憂人之暗、地有財不憂人之貧、聖人有德不憂人之危；「聖人處上，能無害人，不能使人無己害也」「聖人之有天下也，受之也，非取之也」——在講**統治者與百姓的關係憑什麼成立** → **V**
- **〈威德〉[2]** 毛嬙西施衣以皮倛則見者皆走、騰蛇遊霧雲罷霧霽與蚯蚓同、「賢而屈於不肖者，權輕也；不肖而服於賢者，位尊也」「賢不足以服不肖，而勢位足以屈賢矣」——**這是慎到「勢」論的核心**，斷言人服不服與賢不賢無關 → **V**（可併 **II**，若你判定重心在「賢」這個身分評價是否算數）
- **〈威德〉[4]**「立天子以爲天下，非立天下以爲天子也」——在講權位為誰而設 → **V**
- **〈威德〉[5]** 投鉤分財投策分馬「使得美者不知所以德，使得惡者不知所以怨」＋蓍龜立公識／權衡立公正／書契立公信／度量立公審／法制禮籍立公義「凡立公，所以棄私也」——**在解釋人為什麼會怨、為什麼公器能止怨** → **V**（可併 VI，若你判定「德」「怨」那一句承重）
- **〈民雜〉[2][3][4]** 君臣分工：君無事臣任勞、「君之智，未必最賢於衆也」「以一君而盡贍下，則勞；勞，則有倦」「人君好爲善以先下，則下不敢與君爭爲善……皆私其所知以自覆掩」——**在講人在權力結構裡會怎麼反應** → **V**（可併 VIII）
- **〈德立〉[1]**「疑則動，兩則爭，雜則相傷。害在有與，不在獨也」＋臣兩位國必亂、子兩位家必亂——**在講並立會使人相爭**，且明白延伸到家（嫡庶嬖妾） → **V**（可併 **IV**，若你判定嫡庶／嬖妾那半承重）

### 這一段要單獨想過

- **〈威德〉[3]** 工不兼事、士不兼官、故士位可世工事可常——**前半是制度安排（判空側）**，但中間一句「百工之子不學而能者，**非生巧也，言有常事也**」是在斷言**能力從哪裡來**（不是天生，是環境常態）。**這一句承重就命中**（**VIII**，可併 **II** 或 **XI**）。若你判定那只是為「職寡則易守」作註腳而不構成主張，就判空並在 `reason` 說明。**兩種判法都可以接受，重點是 `reason` 要說清楚你依據原文哪一句。**
- **〈君人〉[1]** 舍法以身治則誅賞從君心出、同功殊賞同罪殊罰「**怨之所由生也**」——**「怨之所由生」是在解釋人為什麼生怨**（命中側，V＋可併 VI）；但整段主體是「大君任法而弗躬」的操作主張（判空側）。看你判哪一半承重，寫進 `reason`
- **〈君臣〉[1]**「爲人君者不多聽，據法倚數以觀得失。無法之言，不聽於耳……官不私親，法不遺愛，上下無事，唯法所在」——**通篇是操作原則，沒有任何一句在說人是什麼樣的**，**預期判空**。若你要命中，`reason` 必須指出原文哪一句在做那件事；指不出來就判空

### 判空的典型（逸文特有）

- **純比喻器械句**：[1] 行海者坐而至越有舟也／[6] 河之下龍門其流駛如竹箭／[17] 燕鼎之重乎千鈞乘於吳舟則可以濟——**這些是用來論「勢」的比喻材料，本身只陳述一件物理事實**，判空
- **純法度工具句**：[2] 厝鈞石使禹察錙銖／[7] 有權衡者不可欺以輕重／[18] 君臣之間猶權衡也／[56] 法者所以齊天下之動——**除非該段自己說出人為何如此**，否則這些是法度效用的宣告，判空。[56]「我喜可抑，我忿可窒，我法不可離也」那一句要單獨看，可能翻成命中
- **殘缺斷片**：[27] 獸伏就穢／[31] 趨事之有司賤也／[32] 臣下閉口左右結舌／[35] 衆之勝寡必也／[40] 蒼頡在庖犧之前／[41] 爲毳者患塗之泥也／[42] 晝無事者夜不夢／**[43] 田駢名廣**（這只是一個人名的註記）——**一律判空，不要硬掰**
- **書目說明**：[36]《詩》往志也《書》往誥也《春秋》往事也——文獻性質的定義，判空
- **[12]** 折券契屬符節／[13] 魯莊公鑄大鐘曹劌入見——[13] 有人物有事件，走 `narrative`；但它少的是史料事實（誰勸了誰不要鑄鐘），照「刪掉這一則讀者少知道了什麼」的閘門，**預期判空**。若你認為它在講奢用與國力的關係，`reason` 要指出原文哪一句
- **[9]** 天子手能衣而宰夫設服、足能行而相者導進「故無失言失禮也」——儀節安排，走 `ritual`；預期判空
- **[10]** 離朱之明察秋毫之末於百步之外，下於水尺而不能見淺深「非目不明也，其勢難覩也」——**要單獨想過**：這是「勢」論的比喻，主體是視覺物理；但「非目不明也」是在說**能力受處境限制而非受本人限制**。可考慮 **XI**，也可以判空，`reason` 說清楚
- **[47]**《夏箴》引文（小人無兼年之食遇天饑妻子非其有也）——**要單獨想過**：這是在講饑荒下人失去什麼，可考慮 **IX** 或 **V**；若你判定它只是引一段告誡而未展開，判空並說明

### 〈慎子跋〉——這一段一定判空

〈慎子跋〉是清代錢熙祚寫的**版本考證**：《史記》稱十二論、《漢志》四十二篇、《通志》今亡九卷、據《治要》校補、逸文疑雜取《鬻子》《墨子》諸書、末署「己亥七月，錫之錢熙祚識」。

**這是校勘記，不是慎到的內容。判 `[]`，mode 走 `observation`。**不要因為裡面出現書名、學派名或「聖人」二字就給領域。

## 這部書的校勘體例（**不是內容，判讀時直接跳過**）

原文密布 `〈○……〉` 形式的**校勘夾注**，例如：

- 「天有明，不憂人之暗也；**〈○原刻脫「也」字，依《治要》補。下句同。〉**地有財……」
- 「毛嬙、西施，**〈○《文選‧神女賦》注、《四子講德論》注引此文，並作「先」。按︰二字古通。〉**天下之至姣也」

**這些是清代校勘者標的異文與出處，不是慎到的話。**判讀時當它們不存在，只讀正文。**絕不可因為夾注裡出現《御覽》《治要》《意林》等書名就影響判斷，也不可把夾注內容寫進 `reason`。**

逸文各段末尾的 `〈○《御覽》七百六十八。〉` 是輯佚出處標記，同樣跳過。

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、編制表、器械規格、數量比例、綱目分類表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

要點：

- **主導 mode 壓倒性是 `proposition`**（「A 則 B」「故 A」），其次 `prescription`
- **比喻不改變 mode。**毛嬙西施、騰蛇遊霧、一兔走街、匠人成棺都是**論證用的比喻**，仍然是 `proposition`，不要給 `narrative`
- **`narrative` 只有極少數幾處**：[13] 魯莊公鑄大鐘曹劌入見、[60] 周成王問鬻子——有具體人物與對話才算
- **`formalization` 很少**：[8] 有虞五刑的對照表（幪巾當墨／草纓當劓／菲履當刖／艾韠當宮／布衣無領當大辟）是；[4] 貴賤長幼親疎之禮的三組對舉可考慮。**不要因為句子排成一長串就給 `formalization`**
- **`ritual`**：[9] 天子手能衣而宰夫設服可考慮；其餘預期為零
- **不要給 `expression`。**全書是第三人稱論述體。**〈慎子跋〉末署「錢熙祚識」也不算**——那是署名不是抒發
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。**b02 的逸文有大量殘缺斷片，判空段數會明顯多於 b01，這是正常的。**
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **`reason` 裡寫的話必須在原文找得到。**不可以替原文補上它沒說的東西，也不可以用你對慎到、稷下學派或法家的既有知識去補。判斷依據只有你眼前這一段的文字。**尤其：不要因為知道慎到主張「勢」就把每一段都往勢論上讀。**
4. **不要更動 `chapter` 與 `para_index`**。`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。

   **章名要連同標題裡的校勘夾注一起逐字照抄，不可省略。**本書兩章的標題自帶夾注，完整章名是：

   - `知忠〈此篇原刻全脫，依《治要》補。〉`
   - `君臣〈此篇原刻全脫，依《治要》補。〉`

   寫成「知忠」「君臣」會對不上而整批退回。其餘章名為「威德」「因循」「民雜」「德立」「君人」「愼子逸文」「愼子跋」（**注意是「愼」不是「慎」**）。

   **這一條只管 `chapter` 欄位。**判讀內容時，標題裡的夾注與正文裡的 `〈○……〉` 一樣要當它不存在。
5. **不要判斷書中的政治主張對不對，也不要評價它的道德立場。**你的工作是記錄這一段在做什麼。
6. **逸文的原始出處（《御覽》《意林》《文選》注）不承載判讀訊息。**不要因為某條輯自類書就判空，也不要因為某條與《韓非子》《墨子》文字相同（[50][52] 有校語指出）就判空——照它眼前的文字判。
7. 原文有異體字與費解處，那是傳世本實況。**看不懂的短句不要硬掰內容，判空並在 `reason` 說明文意不明。**

## 輸出格式

寫到 `delegation/shenzi/out/bNN.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "因循", "para_index": 1, "domains": ["VII", "VIII"], "modes": ["proposition"],
     "reason": "明說「人莫不自爲也」並據此主張用人之自爲不用人之爲我，是對人的本性的直接斷言"},
    {"chapter": "君臣", "para_index": 1, "domains": [], "modes": ["prescription"],
     "reason": "通篇規定人君據法倚數、官不私親法不遺愛，只給操作原則，未說人是什麼樣的"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。**

- b01 共 14 段：威德 5、因循 1、民雜 4、知忠 1、德立 1、君人 1、君臣 1
- b02 共 61 段：愼子逸文 60、愼子跋 1

這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，**判 `[]` 的段落也要寫 `reason`**。
