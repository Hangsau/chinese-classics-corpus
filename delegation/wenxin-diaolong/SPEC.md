## 閘門：這一段除了「怎麼寫」之外，還說了關於人的什麼？

文論體整部在談文章——這個文體是什麼、從哪來、怎麼寫才好、誰寫得好不好。中性物件替換測試會判它整本判空（把「文章」換成「陶器」，大半篇章仍成話），登錄閘門又咬不到「原始以表末，釋名以章義」這種文體史結構。改問：

> **這一段除了「這個文體是什麼／從哪來／怎麼寫才好／誰寫得好不好」之外，還說了關於人的什麼？**

> 有 → 給領域。

操作判準只有一句（沿用 §2.6）：**文本有沒有自己把「人是什麼樣的」當成依據或結論說出來？**

### G2 文體論的四段式預設

劉勰每篇文體論走「原始以表末 → 釋名以章義 → 選文以定篇 → 敷理以舉統」四段。**不同段落有不同預設**：

| 段落型 | 內容 | 預設 | 依據 |
|---|---|---|---|
| 原始以表末 | 這個文體從哪來、歷代誰寫過 | **判空**，走 `observation` | §2.7 考辨體：來源考證本身不是內容 |
| 釋名以章義 | 這個名稱是什麼意思 | **判空** | §2.7：純語義還原判空（同風俗通義〈山澤〉22／23 判空） |
| 選文以定篇 | 歷代作品逐一品題（「陳思，群才之英也」） | **判空**，走 `observation` | §2.2 配套：純人物品題語沒有事件 |
| 敷理以舉統 | 這一體該怎麼寫、贊曰 | **照新閘門逐句判** | 命中多半在這裡，但仍以「有沒有落到人」為準 |

**預設不是硬條件。**四段式在多數篇裡混在同一段裡，判的是這一段有沒有承重句，不是這一段是四段式的第幾段（同 §2.3 碑誄體那條）。

## 十五條配套（**每一條都是判反過的地方**）

**(1) 一句就算，不要求主論點跨界。**段內只要存在一個落到人身上的承重句，這一段就命中，不管它是不是全段的主論點。示範：〈知音〉[5] 同段有「披文以入情，沿波討源」（鑑賞程序，判空側）與「豈成篇之足深，患識照之自淺耳」（對人的斷語，承重側）——照後者判命中。同型還有〈樂府〉[3]（「樂心在詩」是術語 vs「俗聽飛馳……欠伸魚睨」是人）、〈頌讚〉[2]、〈養氣〉[1]、〈體性〉[4]。依據是 §2.6④（慎子〈威德〉[3] 整段制度安排但一句「非生巧也」命中 VIII＋XI）與管子〈事語〉[2] 的漏判事故。

**(2) 情、心、志、氣、性、神、思這幾個字預設判空。**本書這幾個字的密度是全庫最高，但它們在文論裡絕大多數是寫作術語（「情采」「文心」「神思」「氣力」「體性」都是篇名）。**例外必須是文本自己在說人是什麼樣的**，不是它用了這個字。這是這一格的第五個體裁版本（醫書的神魂魄是生理術語、兵書的占候是技術術語、風俗通義的祀典神名是考證對象、太玄的技術側；本書是寫作術語）。

**(3) XII（信仰・神聖・超越）四側，本書都有。**

| 側 | 判 | 錨點 |
|---|---|---|
| **技術側** | 一格都不填 | 〈原道第一〉[1]「文之為德也大矣」（「德」是屬性不是神聖） |
| **認證側** | **必含 XII** | 〈原道第一〉[4]「莫不原道心以敷章，研神理而設教，取象乎《河》、《洛》，問數乎蓍龜」；[5]贊「道心惟微，神理設教」；[6]贊「龍圖獻體，龜書呈貌」；〈正緯〉[3]「原夫圖籙之見，迺昊天休命」 |
| **破除側** | **必含 XI 且不得含 XII** | 〈正緯〉[2]「按經驗緯，其偽有四」；〈祝盟〉[4]「崇替在人，咒何預焉」「忠信可矣，無恃神焉！」 |
| **過度側** | 命中（VII 或 V），寫的是人做過了頭 | 〈正緯〉[3]「至於光武之世，篤信斯術……乖道謬典，亦已甚矣」；〈祝盟〉[2]「春秋已下，黷祀諂祭……靡神不至」 |

**〈正緯〉[3] 同段兩向並存**（既有「昊天休命」的認證，又有「篤信斯術……乖道謬典」的過度）→ **XII ＋ V/VII 兩格都給**。〈祝盟〉[4] 承認神存在但把成敗推回人 = **XI 不 XII**（依晏子春秋前例：破除的是祝禳不是神本身）。

**(4) 告神 rider：文體功能描述不填 XII。**〈封禪〉〈祝盟〉〈頌讚〉〈誄碑〉四篇大量出現「告神」「降神」「對越天休」「祈福」——那是在描述這個文體用來做什麼，不是文本在談信仰。另外三段特別點名：〈檄移〉[7]贊「鞶鑑吉凶，蓍龜成敗」是技術側（同 §2.5 兵書占候），**不得含 XII**；〈明詩〉[6]贊「神理共契」**不得含 XII**。

**(5) 贊語硬規定：101 段各判各的。**贊曰在復述本篇論點，但復述不是判空的理由（列女傳前例）。〈養氣〉贊、〈程器〉贊、〈才略〉贊、〈序志〉贊都是全書最承重的段落之一。

**(6) 〈原文集注〉的包含條件。**因為 [2][3] 的文字整段包含在 [1] 內、[6][7] 包含在 [5] 內，邏輯上必然有：`domains([1]) ⊇ domains([2]) ∪ domains([3])`、`domains([5]) ⊇ domains([6]) ∪ domains([7])`。整章預設判空、`modes` 走 `observation`，**不得填 `formalization`**（集注是注釋不是可計算程序）。

**(7) 〈諧讔〉／〈諧隱〉：兩章都判，不要求判齊。**兩章共 14 段，你只會看到其中一批。照自己看到的文字判。判齊與否是我事後的觀測，不是你的目標。

**(8) 〈才略〉與〈程器〉的界線在有無可指認的行為及後果。**〈才略〉[3][4][5] 是純品題（「陳思，群才之英也」「仲宣溢才，捷而能密」）→ 判空；〈程器〉[2]「相如竊妻而受金，揚雄嗜酒而少算，敬通之不循廉隅，杜篤之請求無厭」列的是可指認的行為並下了品格判斷 → **必含 VII**。同一批人、同一部書、相反的判。

**(9) 〈體性〉〈養氣〉是真例外篇，但同篇也有兩側。**〈體性〉[1]「然才有庸俊，氣有剛柔，學有淺深，習有雅鄭，並情性所鑠，陶染所凝」明說人的差異從哪來 → 承重；〈體性〉[2][3] 的八體風格分類（典雅、遠奧、精約……）是文章風格的分類表 → **判空**。

**(10) 〈哀弔〉[4] 與〈情采〉[4] 是同一條誠偽軸的兩端。**〈情采〉[4]「心非鬱陶，苟馳夸飾，鬻聲釣世」「真宰弗存，翩其反矣」點名了動機與人的狀態 → **承重（II 或 VII）**；〈哀弔〉[4]「隱心而結文則事愜，觀文而屬心則體奢」只給兩條寫作路徑、後果落在文本上 → **判空**。差別在後果落在人還是落在文章。

**(11) X（無常・老・死・失去）在本書要壓住。**〈誄碑〉13 段、〈哀弔〉12 段整篇在寫死人，靠詞面聯想 X 會吞掉這兩篇。**〈誄碑〉X 至多 2 段；〈哀弔〉X 至多 3 段且必含〈哀弔〉[11]贊「苗而不秀，自古斯慟」。**依據：蔡中郎集 207 段 X 只得 22，通篇夭逝哀辭的童子碑反而判空。

**(12) XII 用位置限制不用數量限制。**XII **不得出現在〈原道第一〉〈正緯〉〈祝盟〉〈封禪〉以外的任何篇**。數量放 B 類。

**(13) `formalization` 不得出現在〈練字〉〈體性〉〈知音〉。**「選字四條」（詭異、聯邊、重出、單複）、「數窮八體」、「六觀」看起來像條列規格，但它們是編號的分類名目，不是可計算程序。全書 `formalization` 預期 0–3 段；`worked_instance` 0 段。

**(14) 天生的差異承重，練出來的程度差異判空。**〈神思〉[5]「若夫駿發之士，心總要術……覃思之人，情饒歧路」講的是稟賦類型 → 承重；〈定勢〉[5]「舊練之才，則執正以馭奇；新學之銳，則逐奇而失正」講的是熟練程度 → 判空。接 §2.5 六韜〈練士〉（按人想要什麼分類，命中）／〈王翼〉（按人能做到什麼分類，判空）那條分界。

**(15) 比喻的普遍性不是承重理由。**〈議對〉[5]「秦女楚珠」是說理的譬喻 → 判空；〈養氣〉[2] 所在段承重是因為「器分有限，智用無涯……精氣內銷」直說人的限度，**不是**因為它用了「同乎牛山之木」這個譬喻。同理〈附會〉[1] 的身體譬喻（首尾、血脈）與〈聲律〉[3] 的喉脣病例譬喻都判空且**不得含 IX**。

## 我不設錨的灰區（判者自裁，`reason` 要寫出你選了哪一讀）

以下段落兩讀都成立，**我不裁定，也不會用它們擋收**：

- `序志`[3]「隨仲尼而南行」的夢——可讀為作者自述立志的動機（命中 I／VIII），也可讀為著述緣起的敘事（判空）
- `正緯`[5][6] 兩段贊語的方向——贊語同時復述了「昊天休命」與「乖道謬典」兩側
- `祝盟`[5][6] 兩段贊語；`封禪`[6][7] 兩段贊語

- `辨騷`[1]「班固以為露才揚己，忿懟沉江」——若判命中落 VII 或 X；**若判空，`reason` 必須寫明「這是登錄班固的評語，不是文本自己的斷語」**
- `神思`[2]「疏瀹五藏，澡雪精神」——可讀為寫作前的準備工夫（判空），也可讀為對人的修養主張（命中 IX／XIII）
- `隱秀`[4]「氣寒而事傷，此覉旅之怨曲也」——可讀為秀句舉例（判空），也可讀為對羈旅處境的描寫（命中 VI／XIII）

- `章表`[6]「然懇惻者辭為心使，浮侈者情為文使」——可讀為文辭技法的兩型（判空），也可讀為對誠偽的斷語（命中 II／VII）

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。**本書 G3 技術側的預設就是判空**，不要為了讓結果好看去撈。
2. **一段可多標領域，但預設一到兩個。標了 N 格，`reason` 裡就要有 N 條逐字承重句**，一格一句、指得出是哪一句。**寫不出來的那一格就是湊的，刪掉。**不設格數上限。
3. **不要更動 `chapter` 與 `para_index`。**章名逐字照抄（`原道第一` 帶篇次、`頌讚` 不是「頌贊」、`諧讔` 不是「諧隱」），`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。
4. **逐字照抄**：`為` 不可寫成 `爲`、`於` 與 `于` 照原文不要統一、`𡢿` 原樣複製、〈諧隱〉的 `"` 與 `︰` 照抄不要換成「」與：。
5. **校異「一作「X」」必須連著抄。**引句落在含校異的句子上時，把「一作「X」」一起抄進 `reason`，否則機械檢查對不上（63 處，見底本事實 5）。
6. **不要用你對劉勰、對六朝文學史、對《昭明文選》的既有知識去補文本沒說的東西。**你的工作是記錄這一段在做什麼。**尤其不要用篇名代替正文**——〈情采〉不等於在談情、〈養氣〉不等於在談身體、〈知音〉不等於在談友誼。
7. **贊語照自己的文字判，復述不是判空的理由**（101 段，見底本事實 4）。
8. **不要因為看到「神」「道」「天」「靈」「聖」就填 XII**；也不要因為看到「死」「卒」「殞」「慟」「哀」就填 X。兩格都要落到「文本在寫那件事」，且 XII 另有篇級限制（配套 (12)）。
9. **`reason` 必須引到這一段自己的正文**，不得只寫概括、不得複述本規格、**不得引篇名**。判 `[]` 的段落也要寫 `reason`，至少指出它做的是文體溯源、名義訓釋、作品品題、還是技法界定。

## 輸出格式

寫到 `delegation/wenxin-diaolong/out/bNN.json`，UTF-8、LF、不要 BOM：

```json

  "rows": [
    {"chapter": "奏啟", "para_index": 4,
     "domains": ["VII"], "modes": ["proposition"],
     "reason": "「名儒之與險士，固殊心焉」把彈劾文的兩種寫法歸到寫的人心術不同上，是對品格的斷語（VII）"},
    {"chapter": "事類", "para_index": 5,
     "domains": [], "modes": ["observation"],
```
