# 發包 spec：釋名 段落級標註

## 你要做什麼

讀 `delegation/shiming/bNN.md`，逐段判兩件事：

1. `domains`：這一段觸及哪些人生問題領域（下表 13 個 id，可以是空陣列）
2. `modes`：這一段用什麼方式說話（下表 8 個 id，可以是空陣列）

輸出寫成 `delegation/shiming/out/bNN.json`，格式見文末。

## 這部書是什麼

《釋名》東漢劉熙撰，用**聲訓**解釋日常詞語：拿一個同音或近音的字去說某個詞為什麼叫這個名字。全書 27 篇（分繫 8 卷，本庫以篇為章），從天地山水一路到親屬、言語、飲食、衣服、疾病、喪制。

條目長這樣：

```
天，顯也，在上高顯也。
父，甫也，始生巳也。
孝，好也。愛好父母，如所悅好也。
未二十而死曰殤，殤傷也，可哀傷也。
```

篇名依序：釋天、釋地、釋山、釋水、釋丘、釋道、釋州國、釋形體、釋姿容、釋長幼、釋親屬、釋言語、釋飲食、釋綵帛、釋首飾、釋衣服、釋宮室、釋床帳、釋書契、釋典藝、釋用器、釋樂器、釋兵、釋車、釋船、釋疾病、釋喪制。**章名逐字照抄（含「第十一」這種序號尾巴）。**

〈釋喪制第二十七〉來源沒有標點，是連續的字串，那是來源格式，照樣判。

## 唯一的通則性閘門

替換測試與敘事的刪除閘門在字書上都咬不到——字書不是要告訴讀者一件事，是要登錄一個詞。改問：

> **這一條除了「這個詞為什麼叫這個名字、它指的是什麼」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指人可以怎麼活、人有哪些惡、人與人之間如何。**不是**指這個詞的意思跟人有關。

## 硬撈風險（本書最容易錯的方向，而且風險極高）

**這部書逐篇對應到 13 個領域的每一格。**〈釋親屬〉整篇都是親屬稱謂，〈釋言語〉頭一段就是仁義禮智信孝慈友恭悌敬，〈釋形體〉〈釋疾病〉講身體與病名，〈釋喪制〉整篇講死。**若照字面聯想，這部書會被標成 13／13 全覆蓋——那會是本庫最嚴重的一次硬撈。**

1. **聲訓的主張是詞源，不是那件事本身。**「孝，好也。愛好父母，如所悅好也」是在主張「孝」這個詞來自「好」，順帶說明理據。刪掉它，讀者少的是一條詞源說法，不是一種對親子的看法。**這一條吃掉本書絕大多數條目。**
2. **〈釋親屬〉是稱謂系統，不是在寫家庭。**「父之兄曰世父」「仲父之弟曰叔父」是命名規則。要給 IV，得是這一條真的在說親族之間怎麼樣，不是只在給名稱配詞源。
3. **〈釋喪制〉是死亡詞彙表，不是在談死。**「士曰不祿」「諸侯曰薨」「戰死曰兵」是按身分與死法分別命名。要給 X，得是這一條真的在寫死亡、失去本身。
4. **〈釋疾病〉同理**，病名登錄不是 IX。IX 要的是「有人在病裡，而文本在寫那件事」。
5. **〈釋言語〉的德目條目不是 VII。**「仁，忍也」「義，宜也」「禮，體也」是在替德目找同音字，不是在主張人該怎麼樣。
6. **引書證是舉出處**：「故《樂記》曰」「《孝經》說曰」「故《月令》曰」是替詞源找旁證，不是在論那部經講的事。
7. **地域讀音對照不是 V。**「豫司兗冀以舌腹言之／青徐以舌頭言之」「故汝穎言敏曰閔也」是方音記錄，不是我群他群。

## 判空風險（反方向，一樣要防）

不要因為「這是一部訓詁書」就整批機械填 `[]` 而不讀。**條目底下的申說有時會離開詞源走進對人的判斷**，例如〈釋親屬〉講遠親時「恩情轉遠，以禮貫連之耳」「恩意實遠也」是在說親情隨世代遞減、只剩禮在維繫——那不是詞源，那是對人的看法。**遇到這種申說要照實給領域**，判不出來就判空並在 `reason` 說明理由。

兩個方向的錯法只有一個解：**逐段真的讀懂它在做什麼，然後照實記。**

## 13 個領域（`domains` 只能填這些 id）

| id | 名稱 | 涵蓋 |
|---|---|---|
| I | 存在與意義 | 人為何而活、意義從何而來、有無本末 |
| II | 自我與認同 | 我是誰、自我評價、身分、名與實 |
| III | 愛與親密 | 愛與性、被拒絕、承諾、信任與脆弱、溝通與被理解 |
| IV | 家庭與傳承 | 親子、宗族、繼承、教養、婚姻家內事 |
| V | 群體·社會·公義 | 孤獨與歸屬、友誼、我群他群與偏見、公義與權力、責任與領導 |
| VI | 情緒與內在生活 | 喜怒憂懼、內在經驗 |
| VII | 善惡·良心·品格 | 德性、良心、品格養成 |
| VIII | 工作·成就·召喚 | 勞動、職業、才能發揮、成就 |
| IX | 苦難·疾病·身體 | 痛苦、疾病、身體限制 |
| X | 無常·老·死·失去 | 死亡、衰老、失去 |
| XI | 自由·命運·改變 | 命定與自由、人能否改變 |
| XII | 信仰·神聖·超越 | 神聖、超越、信仰實踐 |
| XIII | 安頓·修復·平安 | 受苦之後如何自處、如何與處境相處 |

`Z-wisdom`、`X-modern`、`Y-nature` **不是領域**，絕不可出現在 `domains`。

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、方陣或制度表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

要點：

- **條目一律 `observation`**，這是本書主導 mode。聲訓是在陳述「這個詞實際上從哪裡來」
- **聲訓有「A 也，B 也」的形式但那不是因果**，不要因為看到「故」「所以」就反射給 `proposition`。要給 `proposition`，得是真的在主張一條原理
- **〈釋喪制〉〈釋典藝〉裡按身分與時序規定名稱的段落可考慮 `ritual`**（若它規定的是動作、時序、器物），判不出來就只給 `observation` 並在 `reason` 說明
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。本書預期絕大多數段落 `domains` 為空，**那是正確結果不是失敗**。
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」。
3. **不要更動 `chapter` 與 `para_index`**。章名逐字照抄（「釋親屬第十一」不是「釋親屬」）；`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。
4. **不要用你對劉熙、對訓詁學的既有知識去補文本沒說的東西。**
5. 原文有缺字、異體字、無標點，那是來源格式，不影響判讀。

## 輸出格式

寫到 `delegation/shiming/out/bNN.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "釋言語第十二", "para_index": 10, "domains": [], "modes": ["observation"],
     "reason": "聲訓「孝，好也」替德目配同音字並說理據，是詞源主張不是對親子的看法"},
    {"chapter": "釋親屬第十一", "para_index": 14, "domains": ["IV"], "modes": ["observation"],
     "reason": "說遠親「恩情轉遠，以禮貫連之耳」，離開詞源在講親情隨世代遞減、只剩禮維繫"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。** 缺漏會整批退回。

`reason` 一句話即可，**判 `[]` 的段落也要寫 `reason`**，至少要指出它在做的是聲訓、稱謂登錄、書證，還是別的。

## 不要做的事

- 不要改 `translations/` 底下任何檔案
- 不要跑 git 指令（commit、reset、pull、checkout、stash 一律禁止）
- 不要改 `delegation/shiming/` 的輸入 `.md` 與 `MANIFEST.json`
- 只寫 `delegation/shiming/out/` 底下你這一批的那個 `.json`
