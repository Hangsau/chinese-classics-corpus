## 核心測試（**先過這關，再看領域表**）

> **把題目裡的社會場景換成中性物件，這題還成不成立？**
>
> 成立 → 場景只是出題的包裝，填 `[]`。
> 不成立（換掉之後題目就垮了、或問的東西整個變了）→ 場景是題目本質，才給領域。

**九章算術是一部數學書。它就是在探討數學。** 官員、爵位、分地、賦稅是作者用來出題的方式，正如現代課本用「小明小華分蘋果」——你不會說那題在探討兒童社會關係。

### 什麼情況才真的給領域

只有當文字**本身在對人事下判斷或發議論**時才給——也就是它離開了「出題」進入了「說理」。例如作者或注家跳出來評論某種做法對不對、某類人如何如何。純粹的題面、答案、術，無論場景包了什麼，一律 `[]`。

若整卷判下來全是 `[]`，那就是正確答案，照實輸出。**數學書就讓它回歸數學。** 不要為了讓結果好看而找東西填。

## 硬規則

1. **`[]` 是合法且重要的答案**。若一段真的只是純幾何或純算術操作（如開方術的步驟、單純的面積公式），就填 `[]`。不要為了讓每段都有東西而硬填——負面結果本身是資料。
2. **`Z-wisdom`（智慧·學習·好奇）不是領域，絕不可填進 `psych_domains`**。談「如何求知」「學者踵古習其謬失」這類方法論自覺的段落，領域欄仍照實判（多半是 `[]`），不要用 Z-wisdom 頂替。
3. **既有標註不是標準答案**。檔案裡標了 `[既有標註: V]` 的段落是上一輪的判斷。你若認為它錯或不完整，直接改，並在 `reason` 說明為什麼。
4. **一段可多標**，但不要濫用。真正同時觸及兩個領域才多標。
5. **題面、答案、術三段屬同一題**。判斷時要看整題脈絡（題面給處境、術給程序），但**逐段輸出**：題面通常承載題材（→ 有領域），純運算步驟的術可能是 `[]`，答案多半跟隨題面。
6. **不要更動 `para_index`**。它是錨點，錯一個就整卷對不上。

## 判斷示例（照這個力度）

- `〔一〕今有田廣十五步，從十六步。問：為田幾何？` → `["V"]`，理由：田畝丈量是地權與賦稅的基礎，量田標準即是分配標準
- `〔一〕北鄉遣一百三十五人…` （衰分按戶口攤徭役）→ `["V"]`，理由：徭役按鄉戶口比例攤派，處理的是負擔如何分才算公平
- `術曰：置各人數，各為列衰，副并為法…` → `["V"]`，理由：這條術把「按比例分」寫成可執行程序，是公平標準的形式化。**但若術純粹是算術操作（如通分、約分），填 `[]`**
- `〔一〕今有九分之八，減其五分之一。問：餘幾何？` → `[]`，理由：純分數運算，無題材
- `〔二二〕有木去人不知遠近。立四表…` → `[]`，理由：純測量，不涉人事安排

## 輸出格式

寫到 `delegation/out/<chXX>.json`，UTF-8、LF、不要 BOM：

```json
{
  "chapter_file": "ch04.md",
  "rows": [
    {"para_index": 1, "domains": ["V"], "reason": "按爵位分鹿，處理身分等級與分配比例的對應"},
    {"para_index": 2, "domains": [], "reason": "純分數運算"}
  ]
}
```

**`rows` 必須涵蓋該檔所有 para_index，一個都不能少、不能多。** 這是回填時的雙向檢查條件，缺漏會整卷退回。
