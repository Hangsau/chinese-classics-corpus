# 發包 spec：說文解字 段落級標註

## 你要做什麼

讀 `delegation/shuowen-jiezi/bNN.md`，逐段判兩件事：

1. `domains`：這一段觸及哪些人生問題領域（下表 13 個 id，可以是空陣列）
2. `modes`：這一段用什麼方式說話（下表 8 個 id，可以是空陣列）

輸出寫成 `delegation/shuowen-jiezi/out/bNN.json`，格式見文末。

## 這部書是什麼

《說文解字》東漢許慎撰，中國第一部字書，按 540 部首編排，逐字說解形、音、義。

本庫落地 530 章：

| 章 | 內容 |
|---|---|
| 第 1–529 章 | 部首。章名就是部首名（「艸部」「蓐部」「兄部」「亥部」），底下是該部所屬的字條 |
| 第 530 章 | 章名是 **`15`**（來源就是這樣標的，**逐字照抄，不要改成「卷十五」或「敘」**）。內容是許慎的〈說文解字敘〉 |

字條長這樣：

```
莫（）：日且冥也。从日在茻中。
蓐：陳艸復生也。从艸辱聲。一曰蔟也。凡蓐之屬皆从蓐。
亥：荄也。十月，微陽起，接盛陰。从二，二，古文上字。……《春秋傳》曰：“亥有二首六身。”凡亥之屬皆从亥。
```

字後面的空圓括號 `（）` 是小篆圖檔被抽掉留下的殘跡，忽略即可。來源缺卷一上的 11 個部（一部、丄部、示部、三部、王部、玉部、𤤴部、气部、士部、丨部、屮部），這是抽取限制，不影響你手上這批的判讀。

## 唯一的通則性閘門

替換測試與敘事的刪除閘門在字書上都咬不到——字書不是要告訴讀者一件事，是要登錄一個字。改問：

> **這一條除了「這個字怎麼寫、怎麼念、本義是什麼、哪本書這樣用過」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指人可以怎麼活、人有哪些惡、人與人之間如何。**不是**指這個字的意思跟人有關。

## 硬撈風險（本書最容易錯的方向，而且風險極高）

**字書會把 13 個領域的每一個都「提到」一次，因為那些字都存在。**「孝」「仁」「怒」「死」「病」「婚」「友」「君」全都有字條。這是本書唯一但壓倒性的陷阱：

1. **釋義的內容不等於文本的內容。**「孝：善事父母者」是在說「孝」這個字的本義，不是在談親子關係。刪掉它，讀者少的是一條字義，不是一種對人的看法。**這一條吃掉本書絕大多數字條。**
2. **「从某从某」「某聲」「讀若某」是字形與讀音分析**，與內容無關。
3. **「凡某之屬皆从某」是部首歸屬體例**，每部首條末尾都有，不承載任何東西。
4. **引書證是舉用例，不是在論那件事。**「《春秋傳》曰」「《詩》曰」「《周禮》曰」「《易》曰」出現在說解裡是替字義找出處，不是文本在討論那部經講的事。
5. **說解裡的陰陽五行與干支宇宙論不是 XII。**「亥：荄也。十月，微陽起，接盛陰」「一：惟初太始，道立於一，造分天地」是漢代訓詁的說解方式，是在解釋字形為什麼這樣構成。**XII 要卡到最緊**：只有文本真的在寫人與神聖之間怎麼樣才給。
6. **「一曰……」是異說並列**，記錄另一種說法，不是文本自己的主張。

## 判空風險（反方向，一樣要防）

不要因為「這是一部字書」就整批機械填 `[]` 而不讀。第 530 章（章名 `15`）是**整部書裡唯一的連續散文**：許慎談造字的起源、六書的定義、文字與教化的關係，末段譴責當時「俗儒鄙夫，翫其所習，蔽所希聞」憑臆說解字、「人用己私，是非無正」。**那一章要逐段當論說文認真讀，不適用字條的判法。**

兩個方向的錯法只有一個解：**逐段真的讀懂它在做什麼，然後照實記。**讀懂之後發現它就是字義登錄，那 `[]` 就是正確答案；讀懂之後發現它在講人怎麼樣，那就給領域。

`Z-wisdom`、`X-modern`、`Y-nature` **不是領域**，絕不可出現在 `domains`。

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、方陣或制度表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

要點：

- **字條一律 `observation`**，這是本書主導 mode。它陳述「這個字實際上是什麼意思、怎麼構成」
- 〈敘〉裡追述庖羲、神農、倉頡造字經過的段落 → `narrative`
- 〈敘〉裡有「A 故 B」推理的段落（文字為什麼會孳乳寖多、俗儒為什麼會錯）→ `proposition`
- **六書定義那一段可考慮 `formalization`**：「指事者，視而可識，察而見意」是把字的分類寫成可逐條判別的程序。判不出來就只給 `observation`，並在 `reason` 說明
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。本書預期絕大多數段落 `domains` 為空，**那是正確結果不是失敗**。負面結果本身是資料。
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **不要更動 `chapter` 與 `para_index`**。章名逐字照抄（含第 530 章的 `15`）；`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。
4. **不要用你對許慎、對文字學的既有知識去補文本沒說的東西。**你的工作是記錄這一段在做什麼。
5. 原文有缺字、異體字、空圓括號、引號不對稱，那是來源格式，不影響判讀。

## 輸出格式

寫到 `delegation/shuowen-jiezi/out/bNN.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "艸部", "para_index": 3, "domains": [], "modes": ["observation"],
     "reason": "字條，說「蓏」的本義與从艸从㼌的構形，除了字義之外沒說關於人的什麼"},
    {"chapter": "15", "para_index": 12, "domains": ["VIII"], "modes": ["proposition"],
     "reason": "譴責俗儒不通字學而憑己意妄說，講的是治學者怎麼敗壞自己的本業"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。** 這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，**判 `[]` 的段落也要寫 `reason`**，至少要指出它在做的是字義登錄、字形分析、書證舉例，還是別的。
