# 發包 spec：世說新語 段落級標註

## 你要做什麼

讀 `delegation/shishuo-xinyu/<bNN>.md` 裡的每一段，判斷兩件事，輸出對照表 JSON 到 `delegation/shishuo-xinyu/out/<bNN>.json`：

1. **L2 `domains`**：這段在處理哪些「人生問題領域」（13 個 id，見下表）
2. **L3 `modes`**：這段**用什麼方式**處理（8 個 discourse_mode 值，見下表）

兩者正交：任一領域可搭配任一姿態。

## 這部書是什麼，以及為什麼特別難判

《世說新語》，南朝宋劉義慶編，1,140 則魏晉人物軼事，分 38 門。**它跟本庫先前發包的每一部都不同：前面幾部（九章算術、顏氏家訓、鹽鐵論）不是算題就是議論，作者會直接說出他的判斷；世說幾乎不說判斷，只把事情擺出來。**

所以本書的 `modes` 會壓倒性是 `narrative`，這不是重點。**重點全在 `domains`：能不能從故事裡讀出它在處理什麼。**

這件事有兩個對稱的錯法，兩個都要防：

- **全部判空**：因為每則都「只是講一個故事」，沒有命題句可抓，於是整批 `[]`。
- **全部判滿**：因為每則都有人、有對話、有情境，看起來都很「人生」，於是每則都塞兩三格。

## 唯一的通則性閘門（敘事體版本）

前幾部用的是「把場景換成中性物件還成不成立」。**軼事不能這樣換**（人就是內容），所以本書改用等價的另一問法：

> **把這一則刪掉，讀者少知道了什麼？**
>
> 少的是**某人某時做了某事**這個史料事實 → 填 `[]`
> 少的是**人在這種處境下可以是這樣**這種對人的看法 → 給領域

實例：

- 「陳仲舉言為士則，行為世範」——少的是「一個人可以把自己活成標準」→ `["VII"]`
- 「王藍田性急。食雞子，以箸刺之，不得，便大怒舉以擲地」——少的是「性急的人是什麼樣子」，這是對人的觀察 → `["VI"]`（情緒與內在生活）
- 「魏武帝崩，文帝以武帝宮人盡留自侍」加上何等年月的純紀事、或只交代某人官職遷轉、某書某注的成立經過 → `[]`
- 「支道林買山而隱，人問其故」→ 看他答什麼；答的若是隱與仕的取捨，那是 VIII／XI，不是 `[]`

## 最大的風險：拿門類名當答案

38 個門類名（德行、言語、政事、文學、方正、雅量、識鑒、賞譽、品藻、規箴、捷悟、夙惠、豪爽、容止、自新、企羨、傷逝、棲逸、賢媛、術解、巧藝、寵禮、任誕、簡傲、排調、輕詆、假譎、黜免、儉嗇、汰侈、忿狷、讒險、尤悔、紕漏、惑溺、仇隟……）**是編者的分類，不是領域對映表。**

**禁止**看到「德行」就填 VII、看到「賢媛」就填 IV、看到「傷逝」就填 X。**每一則都要讀它自己在做什麼。**同一門裡的則與則差別很大：〈德行〉裡有真在講品格的，也有純粹記某人某事的；〈傷逝〉裡有寫哀慟本身的（VI／X），也有只記「某某卒，某某往弔」的（`[]`）。

下面這張表是**提示不是對映**，用來提醒你某些門類容易出現哪些領域，仍要逐則判：

| 門類 | 常見（但非必然） |
|---|---|
| 德行、方正、自新、尤悔、仇隟、讒險、汰侈、儉嗇 | VII 善惡·良心·品格 |
| 雅量、忿狷、豪爽、傷逝 | VI 情緒與內在生活；雅量另常見 XIII |
| 賞譽、品藻、識鑒、容止 | II 自我與認同（名與實）；也常 `[]`，見下節 |
| 政事、規箴、寵禮、黜免 | V 群體·社會·公義 |
| 文學 | 見下方「文學門與 I」 |
| 棲逸、任誕、簡傲 | XI 自由·命運·改變；VIII 工作·成就·召喚 |
| 惑溺、賢媛 | III 愛與親密；IV 家庭與傳承 |
| 傷逝 | X 無常·老·死·失去 |
| 術解、巧藝、捷悟、夙惠、紕漏 | 多半 `[]`，除非在評人 |

## 〈賞譽〉156 段與〈品藻〉88 段：本書最容易整批判錯的地方

這兩門合計 244 段，佔全書兩成，而且外觀高度一致——多半是一句人物品題：「某某曰：某某人如何如何」「某某與某某孰勝」。

**不要整批判空，也不要整批填 II。** 分辨標準：

- 只是把某人比作某物、給一個雅稱、記錄一句評語，沒有觸及評價本身的問題 → `[]`
  （例：「王戎云：太尉神姿高徹，如瑤林瓊樹」——這是品題語彙，不是在處理人生問題）
- 觸及**名與實相不相稱、人該被如何衡量、評價的根據是什麼、被評者如何看待自己** → **II**
  （例：「桓公問謝安：卿何如安石？」這類要人自我定位的，或「名過其實」「盛名之下」的討論）
- 觸及**誰該用、誰可任、識人與用人** → **V**（有時加 VIII）
- 評的是德性高下（清、廉、忠、孝）→ **VII**

**判空在這兩門是常態，不是失敗。**本庫守則明寫負面結果是資料。

## 〈文學〉105 段與 I（存在與意義）

**本庫已標七部，領域 I 至今零命中。**顏氏家訓 12/13 命中，唯一落空就是 I——訓誡體只講人該怎麼活，不問人為何而活。

〈文學〉門記魏晉清談：老莊、才性四本、聲無哀樂、養生、言盡意與否、逍遙義。**這是本庫第一次可能真的碰到 I 的地方。**但請不要因為我這樣說就去湊。分辨：

- 在問**萬物從何而來、人為何而生、生死之際何所依、有無本末** → **I**
- 在問**人的本性與才能是不是一回事**（才性同異離合）→ **II**（有時 VII）
- 在講**誰談贏了、誰注得好、某書某義的源流、清談的技術與勝負** → 屬 `Z-wisdom`，`domains` 填 `[]`
- 在講**某人少年能文、某人作賦幾日而成** → `[]`（記才學事實）

**這一格請不要漏，也請不要湊。零命中依然是合法且有價值的答案。**

## `Z-wisdom` 陷阱

**`Z-wisdom`（智慧·學習·好奇）不是領域，絕不可填進 `domains`。**談清談方法、注書優劣、讀書求學、辯難技巧的段落，`domains` 照實判，多半是 `[]`。

〈文學〉〈捷悟〉〈術解〉最容易踩。人物志與潛夫論都在這一格整篇判錯過。

## XIII 是本次要特別驗的一格

本庫已立的假設：**XIII（安頓·修復·平安）的有無，取決於文本裡有沒有人替自己的處境說話。**

世說寫的是亂世——士人被殺、被廢、被迫仕於新朝、家國傾覆。〈雅量〉〈棲逸〉〈黜免〉〈傷逝〉裡若有人在**已經無法改變的處境裡安頓自己**，標 **XIII**，並在 `reason` 說明是誰替誰的處境說話。

注意分辨：講**該怎麼改變處境**是 XI 或 V；講**處境改不了、人可以怎麼與它相處**才是 XIII。
（例：嵇康臨刑索琴彈廣陵散 → XIII + X；謝安圍棋不動聲色 → XIII + VI）

## 13 個領域（`domains` 只能填這些 id）

| id | 名稱 | 涵蓋 |
|---|---|---|
| I | 存在與意義 | 人為何而活、意義從何而來、有無本末 |
| II | 自我與認同 | 我是誰、自我評價、身分、名與實 |
| III | 愛與親密 | 愛與性、被拒絕、承諾、信任與脆弱、溝通與被理解 |
| IV | 家庭與傳承 | 親子、宗族、繼承、教養、婚姻家內事 |
| V | 群體·社會·公義 | 孤獨與歸屬、友誼、我群他群與偏見、公義與權力、責任與領導 |
| VI | 情緒與內在生活 | 喜怒憂懼、內在經驗 |
| VII | 善惡·良心·品格 | 德性、良心、品格養成 |
| VIII | 工作·成就·召喚 | 勞動、職業、才能發揮、成就 |
| IX | 苦難·疾病·身體 | 痛苦、疾病、身體限制 |
| X | 無常·老·死·失去 | 死亡、衰老、失去 |
| XI | 自由·命運·改變 | 命定與自由、人能否改變 |
| XII | 信仰·神聖·超越 | 神聖、超越、信仰實踐 |
| XIII | 安頓·修復·平安 | 受苦之後如何自處、如何與處境相處 |

**友誼在 V 不在 III。**世說大量寫士人交遊、絕交、相知——那是 V。

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法或制度 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

本書預期 `narrative` 佔絕大多數。要點：

- 有人物與情節就是 `narrative`，即使很短。
- **只有一句人物評語、沒有事件**（〈賞譽〉大量如此）→ 那是 `observation`，不是 `narrative`。
- 則中人物說出帶普遍性的道理（「聖人忘情，最下不及情，情之所鍾，正在我輩」）→ `narrative` + `proposition`。
- 則中人物自陳心境（「我與我周旋久，寧作我」）→ `narrative` + `expression`。
- **`modes` 不要疊到三個以上**，挑主導的一到兩個。全都標等於沒標。

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。不要為了讓每段都有東西而硬填——負面結果本身是資料。
2. **一段可多標領域，但不要濫用。**真正同時觸及兩個領域才多標，不要把一則裡的每個名詞都對映成一格。
3. **不要更動 `chapter` 與 `para_index`**。它們是錨點，錯一個就整批對不上。`para_index` 在每一章內從 1 重新編號，所以**回報時章名與 para_index 兩者都要給**。
4. **`Z-wisdom`、`X-modern`、`Y-nature` 不是領域**，絕不可出現在 `domains`。
5. **敘事段也要判領域**：故事是載體，它承載的內容照判。**這一條在本書是主線，不是例外。**
6. **兩篇明代序文**（〈劉應登序〉〈袁褧序〉，在 b06）談的是此書源流與刊刻，不是軼事本體。照實判，多半 `[]`。
7. **不要用你對這些人物的既有知識去補故事沒說的東西。**只判這一則文字寫了什麼。

## 試點（b22〈雅量〉）校準後補的兩條

b22 已判完並通過錨點與值域檢查，判讀品質好（`reason` 逐則具體、王戎識苦李那則正確判空、XIII 的四則全部落在真正無法改變的處境上）。以下兩點是從它修出來的：

1. **「神色不變」是世說的敘事套語，不是心理描寫。** 神色自若／意色自若／顏色不異／夷然不動在全書出現極頻繁，它只是這一體裁記人的固定寫法。**看到這四個字不要反射填 VI。**

2. **看該則的收束決定主軸。** 若一則以「某人因此被賞識／被評為某器／名價大重／世以此定某某優劣」作結，它處理的是**評價與識人**（II，涉及任用時加 V），不是當事人的內心。**VI 只在文本真的著墨於他的情緒或內在經驗時才標**——怕不怕、忍不忍得住、心裡怎麼想、旁人驚亂而他如何。

   對照：〈雅量〉裡雷擊近身而夏侯玄書寫如故、虎吼而王戎無恐色，寫的是這個人在驚懼下的內在狀態 → VI 成立。而顧和捉蝨、桓溫突騎試王珣，收束在「有令僕才」「公輔器」，那是別人在判斷他 → II／V，VI 不必陪標。

   **這條在〈賞譽〉156 段、〈品藻〉88 段、〈識鑒〉會大量用到**，那三門幾乎每則都以評語收束。

## 輸出格式

寫到 `delegation/shishuo-xinyu/out/<bNN>.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b22.md",
  "rows": [
    {"chapter": "雅量", "para_index": 1, "domains": ["VI", "XIII"], "modes": ["narrative"],
     "reason": "嵇康臨刑顧視日影索琴而彈，死期已定無可改，人在其中自處"},
    {"chapter": "雅量", "para_index": 2, "domains": [], "modes": ["narrative"],
     "reason": "只記某人某時遇某事而不動聲色，未觸及對人的看法"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。** 這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，但**判 `[]` 的段落也要寫 `reason`**——寫出你認為它少了什麼。這是本次驗證判準的依據。
