## §0 本群形態

本群從韓策末段一路讀到全書序跋，主體由宮廷制衡、合從連橫轉入燕國興亡與宋衛、中山故事，最後突然換成版本學與書評文字。

- 全群共 113 章、249 段；逐批小計均見 §1。
- 策文共 217 段：韓策 53 段、燕策 120 段、宋衛策 22 段、中山策 22 段。燕策占策文過半，且多見一章分成多段的長敘事或長書信。
- 非策文異類共 32 段／12 章：`b64.md` 後四章 16 段與 `b65.md` 全八章 16 段，內容是校注後題、序跋、版本源流及全書倫理評議；不得與策士說辭或正文敘事混為一層。
- 以 `〈…〉` 粗計，本群有 1,486 條夾注，夾注字元約占 54.4%；低於全書 61.6% 主要因 b64–b65 序跋夾注較少，單批 b62 仍高至約 68.6%。
- 劉向書錄所在的 b01 前五段不在本群；本群沒有該一異類，但有上述更晚出的序跋群。章名全按首句定位，摘要與候選均未由章名預判。

已知陷阱的回報位置如下：夾注中的人物評論見 §5；寓言及其落點見 §4；人物品題與怒、悅、哭等敘事套語見 §3；重出見 §6；章名只作定位；劉向書錄本群無。復述不作判空理由，各段仍按自己的文字蒐證。

| `韓傀相韓` | [3] | 「老母今以天年終，政將為知己者用。」 | 親養、知己與報答構成行動理由，不只是刺殺流程。 |
| `韓傀相韓` | [6] | 「夫愛身不揚弟之名，吾不忍也。」 | 姊姊直接權衡自保與為弟揚名，並據此赴死。 |
| `韓傀相韓` | [7] | 「非獨政之能，乃其姊者，亦列女也。」 | 敘事者對姊弟行為作整體人物評價，不只是記事。 |
| `段產謂新城君[5]` | [1] | 「能無議君於王，而不能令人毋議臣於君。」 | 直接說人能控制自己的言行，不能控制他人的議論。 |
| `人有惡蘇秦於燕王者` | [3] | 「且夫信行者，所以自為也，非所以為人也。」 | 明白提出德行、自全與為人辦事的衝突模型。 |
| `人有惡蘇秦於燕王者` | [5] | 「忠至如此然不免於笞，此以忠信得罪者也。」 | 寓言之後直接概括忠而受罰的悖論。 |
| `蘇秦死其弟蘇代欲繼之` | [3] | 「臣聞之，明主者務聞其過，不欲聞其善。」 | 是可獨立適用於領導者的規範性斷語。 |
| `蘇秦死其弟蘇代欲繼之` | [5] | 「夫無謀人之心，而令人疑之，殆；有謀人之心，而令人知之，拙；謀未發而聞於外，則危。」 | 三句直接分析意圖、觀感與保密，不依賴特定國名。 |
| `蘇秦死其弟蘇代欲繼之` | [9] | 「夫驕主必不好計，而亡國之臣貪於財。」 | 說辭自行把君臣性向當作亡齊依據。 |
| `燕昭王收破燕後即位` | [2] | 「帝者與師處，王者與友處，霸者與臣處，」 | 以領導者如何待人分層，核心是人際與用賢觀。 |
| `燕昭王收破燕後即位` | [3] | 「死馬且買之五百金，況生馬乎？天下必以王為能市馬，馬今至矣。」 | 寓言說明可見行動如何形成信號並吸引人才。 |
| `蘇秦謂燕昭王` | [1] | 「仁義者，自完之道也，非進取之術也。」 | 正面界定仁義、自我完成與功業進取的關係。 |
| `蘇秦謂燕昭王` | [5] | 「萬乘之主，不制於人臣。十乘之家，不制於眾人。疋夫徒步之士，不制於妻妾。」 | 從君主到匹夫提出同構的自主原則。 |
| `燕王謂蘇代` | [1] | 「且事非權不立，非勢不成。夫使人坐受成事者，唯訑者耳。」 | 直接宣稱權變、形勢與欺誑是成事條件。 |
| `蘇秦為奉陽君說燕於趙以伐齊[1]` | [4] | 「故舉大事，逃不足以為辱矣。」 | 把逃亡重新評價為成大事可接受的行動。 |
| `蘇秦自齊獻書於燕王` | [1] | 「臣貴於齊，燕大夫將不信臣；臣賤，將輕臣；」 | 將旁人對貴賤的相反反應說成普遍困境。 |
| `陳翠合齊燕` | [3] | 「人主之愛子也，不如布衣之甚也。非徒不愛子也，又不愛丈夫子獨甚。」 | 雖是反說，卻明白提出權力家庭如何對待兒子。 |
| `昌國君樂毅為燕昭王合五國之兵而攻齊` | [4] | 「臣聞賢聖之君，不以祿私其親，功多者授之；」 | 直接給出任官授祿不徇親的準則。 |
| `昌國君樂毅為燕昭王合五國之兵而攻齊` | [7] | 「臣聞善作者，不必善成；善始者，不必善終。」 | 是關於能力、起始與完成不必一致的獨立判斷。 |
| `昌國君樂毅為燕昭王合五國之兵而攻齊` | [8] | 「臣聞古之君子，交絕不出惡聲；」 | 對關係決裂時應如何自處提出明確規範。 |
| `張丑為質於燕` | [1] | 「夫欲得之君，不可說以利。」 | 以貪欲者的心理弱點解釋脫身方法。 |
| `燕王喜使栗腹以百金為趙孝成王壽` | [2] | 「厚者不毀人以自益也，仁者不危人以要名。」 | 可脫離求和書而成立的厚道與仁者準則。 |
| `燕王喜使栗腹以百金為趙孝成王壽` | [2] | 「義者不虧人以自益，況傷人以自損乎！」 | 直接用義評量損人利己與兩敗俱傷。 |
| `燕太子丹質於秦亡歸` | [3] | 「臣聞騏驥盛壯之時，一日而馳千里。至其衰也，駑馬先之。」 | 田光以衰老和能力變化自評，並非地緣計算。 |
| `燕太子丹質於秦亡歸` | [4] | 「夫為行使人疑之，非節俠士也。」 | 俠士如何看待信任與名節直接導致田光自殺。 |
| `公輸般爲楚設機` | [1] | 「義不殺王而攻國，是不殺少而殺眾。敢問攻宋何義也？」 | 墨子指出個人戒殺與國家殺眾的倫理矛盾。 |
| `魏太子自將過宋外黃` | [1] | 「彼利太子之戰攻，而欲滿其意者眾，」 | 把眾人逐利與迎合說成太子無法回頭的原因。 |
| `智伯欲伐衞` | [1] | 「無功之賞，無力之禮，不可不察也。」 | 對不相稱的恩賞與禮物提出可泛用的警戒。 |
| `衞嗣君病` | [1] | 「人生之所行，與死之心異。」 | 直接區分平日行為與臨死意向，是本群最明顯的人生斷語之一。 |
| `衞嗣君時胥靡逃之魏` | [1] | 「治無小，亂無大。」 | 把治亂根源置於原則而非國土大小。 |
| `衞嗣君時胥靡逃之魏` | [1] | 「民無廉恥，雖有十左氏，將何以用之？」 | 明說廉恥比土地更能支撐國家。 |
| `衞人迎新婦` | [1] | 「然而不免爲笑者，蚤晚之時失也。」 | 把正確內容仍遭嘲笑歸因於發言時機。 |
| `犀首立五王` | [2] | 「臣聞之，同欲者相憎，同憂者相親。」 | 直接把共同欲望與共同憂患連到相憎相親。 |
| `中山君饗都士[1]` | [1] | 「怨不期深淺，其於傷心。」 | 將怨的強度繫於是否傷心，而非事件表面大小。 |
| `樂羊為魏將` | [1] | 「樂羊食子以自信，明害父以求法。」 | 敘事者直接評價樂羊以害父換取公信。 |
| `昭王既息民繕兵[2]` | [4] | 「秦中士卒，以軍中為家，將帥為父母，不約而親，不謀而信，一心同功，死不旋踵。」 | 雖服務戰略論證，句內完整說明群體凝聚如何形成。 |
| `昭王既息民繕兵[2]` | [5] | 「臣聞明主愛其國，忠臣愛其名。破國不可復完，死卒不可復生。」 | 國、名、生命與不可逆損失成為白起拒命的價值理由。 |
| `又` | [4] | 「夫人患理之不明耳！知至而識融，則異端雜說，皆吾進德之助，而不足以為病也。」 | 非策文序論直接談讀書、辨理與進德。 |
| `戰國策目錄序` | [3] | 「蓋法者所以適變也，不必盡同；道者所以立本也，不可不一。」 | 非策文序論提出法可變、道須一的明確原則。 |
| `書戰國策後` | [1] | 「壽考安樂、富貴尊榮、顯名愛好、便利得意者，天下之所欲也，」 | 非策文書後直接概括人所共同欲求。 |
