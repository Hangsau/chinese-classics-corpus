## §0 本群形態

九批交錯呈現『自序釋名與篇次—治國與糶糴謀議—相劍與望氣技術—全書論贊』四種功能，不能用同一承重率或同一問句處理。

- 本群合計 9 章、71 段；各批段數相加為 8＋7＋6＋3＋4＋17＋12＋5＋9＝71。
- G3 有 4 章、29 段（b05、b09、b12、b14）；數字、物候與政策鏈逐句掃描後，另取其明說人之情態者。
- G4 有 2 章、20 段（b11、b13）；相劍走器物配套，軍氣的 [1] 與 [2]–[17] 分開，後十六段主要是占候、星土技術。
- G5 有 2 章、17 段（b01、b17），G6 有 1 章、5 段（b16）；前者拆開釋名／篇次與人物斷語，後者五段均逐句取證。
- `□` 出現在 b13[2]、b14[1]、b16[1][5]、b17[1][9]；本報告凡跨到闕字的引句均保留原符號，未補字。

本群不含 G1，故沒有地名靈異或宮室臺榭登錄可供回報，也沒有冢墓方位條目；G1 的 X、XII、V 詞面陷阱在此不適用。女性／親屬詞見 b11、b12、b16，但下文只依段落所寫的謀略、奢侈、死亡抉擇來取證，不因人名或親屬稱謂反射歸類。IX 的『身體處境』未見明確實例：劍的五色、軍氣的人氣、枕中篇的人身與魂魄多是器物或術數／物候語。與《吳越春秋》的共同人物、九術、范蠡與子胥之死只在 §6 報為同題異敘；本群的候選密度亦未參照其他群調整。

## §4 死亡與天命落點

| 章名 | 段序 | 這一段死了誰／出現什麼天命語（逐字首句） | 我讀到的那一句怎麼落（逐字引該句） |
|---|---|---|---|
| 越絕外傳本事第一 | [5] | 「吳亾而越興，在天與？在人乎？」 | X 不涉；五側屬破除側：「皆人也。夫差失道，越亦賢矣。」 |
| 越絕外傳本事第一 | [5] | 「天生宰嚭者，欲以亾吳。」 | 同段又有認證側：這句把宰嚭之生與吳亡寫成天意，兩側並存。 |
| 越絕外傳本事第一 | [7] | 「絕命危邦，不顧長生」 | X 的 A 側：「切切爭諫，終不見聽。」寫子胥明知危死仍諫。 |
| 越絕計倪內經第五 | [1] | 「靡從部分，伏地而死，前頓後僵。」 | X 的 B 側：死者是敗軍景象；天命另落破除側：「未必天之罪也，亦在其將。」 |
| 越絕計倪內經第五 | [2] | 「不早備生，不能相葬。」 | X 的 A 側：「人之生無幾，必先憂積蓄，以備妖祥。」寫人因生命有限而預備。 |
| 越絕外傳計倪第十一 | [1] | 「主辱臣死」 | X 的 A 側：「死者，是士之所重也。」直接討論士如何權衡死。 |
| 越絕外傳記寶劍第十三 | [1] | 「闔廬無道，子女死，殺生以送之。」 | X 的 B 側候選：死與殺是劍史所附事件；其無道、殉送之評可在其他問題承重。 |
| 越絕內經九術第十四 | [2] | 「行路之人，道死尸哭。」 | X 的 B 側：結果敘述，未寫死者面對自身死亡。 |
| 越絕外傳記軍氣第十五 | [2] | 「攻之殺將，其軍可降」 | X 的 B 側兼五側技術側：只是占辭預測的殺將結果。 |
| 越絕外傳枕中第十六 | [4] | 「身死邦亡，為天下笑。」 | X 的 A 側候選：「此謂行奢侈而亡也。」以死亡作奢侈後果的警戒。 |
| 越絕外傳枕中第十六 | [9] | 「欲捐軀出死，以報吳仇」 | X 的 A 側：「今王利地貪財，接兵血刃，僵尸流血，欲以顯於世，不亦謬乎？」正面諫止求死復仇。 |
| 越絕外傳枕中第十六 | [10] | 「父辱則子死，君辱則臣死。」 | X 的 A 側：「君辱則死，固其義也。」明說赴死義務並與成邦之計對辨。 |
| 越絕德序外傳記第十八 | [1] | 「欲殺妻子，角戰以死。」 | X 的 A 側：「殆哉！王失計也，愛其所惡。」范蠡直接評斷並改變句踐的死戰選擇。 |
| 越絕德序外傳記第十八 | [2] | 「人之將死，惡聞酒肉之味」 | X 的 A 側候選：「邦之將亡，惡聞忠臣之氣。」借臨死心理評論亡國拒諫。 |
| 越絕德序外傳記第十八 | [4] | 「子胥賜劍將自殺」 | X 的 A 側：「莫如早死，從吾先王於地下，蓋吾之志也。」為臨終自述。 |
| 越絕篇敘外傳記第十九 | [3] | 「臣不討賊，子不復仇，非臣子也。」 | X 的 A 側：「非義不為，非義不死也。」明定何事值得死。 |
| 越絕篇敘外傳記第十九 | [7] | 「死與生，敗與成，其同奈何？」 | X 的 A 側：「行雖有異，其義同。」把比干之死與微子之去放在同一義理辨析。 |

本群沒有 G1 的冢墓登錄可列；X 的 B 側因此改取戰況、築臺死者、器物史與技術預測，未拿死亡詞面本身作理由。
