# 發包 spec：新序 段落級標註

## 你要做什麼

讀 `delegation/xinxu/bNN.md`，逐段判兩件事：

1. `domains`：這一段觸及哪些人生問題領域（下表 13 個 id，可以是空陣列）
2. `modes`：這一段用什麼方式說話（下表 8 個 id，可以是空陣列）

輸出寫成 `delegation/xinxu/out/bNN.json`，格式見文末。

## 這部書是什麼

《新序》西漢劉向編，把先秦至漢初的軼事按主題分類編排，全書 218 段、10 章。**這是編纂的故事集，不是一個人的論著**——劉向的主張藏在他選了哪些故事、以及故事末尾的評語裡。

批次與章的對應（`chapter` 欄逐字照抄，**不要改寫、不要補字、不要正規化**）：

| 批 | 章 | 段數 |
|---|---|---|
| b01 | `刺奢` | 11 |
| b02 | `善謀/卷上` | 16 |
| b03 | `善謀/卷下` | 18 |
| b04 | `節士` | 30 |
| b05 | `義勇` 14 ＋ `雜事/卷一` 23 | 37 |
| b06 | `雜事/卷三` | 16 |
| b07 | `雜事/卷二` | 28 |
| b08 | `雜事/卷五` | 33 |
| b09 | `雜事/卷亖` | 29 |

**`雜事/卷亖` 的「亖」是來源使用的「四」之異體，不是訛字，逐字照抄，不准寫成 `雜事/卷四`。**

**章的順序不等於卷次順序**（檔案裡是 卷一 → 卷三 → 卷二 → 卷五 → 卷亖），這是來源實況，不影響判讀。

十章的形態差異很大，**不要拿前一章的判空比例當後一章的預期值**：

- `刺奢`：全部是「某君奢侈 → 諫者一句話點破」，每段幾乎都有直接評語，評語密度全書最高
- `善謀/卷上`、`善謀/卷下`：戰國到漢初的謀議與使臣說辭全錄，**評語極稀，是全書判空密度最高的兩章**
- `節士`、`義勇`：守節赴死者傳，多數段以「君子曰」或「詩曰」收尾，評語裝置最密
- `雜事` 五卷：形態最混雜，敘事、純議論、書信、表列都有

## 唯一的通則性閘門

這是敘事體，中性物件替換測試在這裡失效（軼事裡的人就是內容本身，換掉就沒有這一則了）。改問：

> **把這一則刪掉，讀者少知道了什麼？**
>
> 少的是史料事實（誰在哪一年打了誰、割了幾座城、封了哪塊地、誰接了誰的位）→ `[]`。
> 少的是對人的看法（人可以怎麼活、該怎麼被評價、人與人之間如何）→ 給領域。

**判空與命中兩側都有具體的錯法，兩邊都要防：**

- 判空太快：看到「這是史書、這只是講某個古人做了什麼」就整章判空。這部書的體例本來就是**用一個人的事蹟去主張人該怎麼活**，該命中的地方要照實記
- 硬撈太多：因為段落裡有人死、有人哭、有人提到天，就填 X／VI／XII。詳見下一節

正解只有一個：**逐段真的讀懂它在做什麼，然後照實記。**讀懂之後發現它就是外交推演與地緣算計，那 `[]` 就是正確答案。

## 本書最大的三個硬撈風險（**每一格都要卡住**）

### (a) X（無常·老·死·失去）——最嚴重

`節士` 30 段加 `義勇` 14 段共 44 段幾乎段段死人：伏劍、刎頸、投水、餓死、抱木而燔、烹、車裂。全書自殺密度極高。

> **「死」在《新序》裡預設是節與義的展示手段，不是被談論的對象。不給 X。**
> 只有文本自己把死亡本身、壽命、或失去當成在談的那件事時，才給 X。

會判錯的具體段（這幾段都**不是** X）：

- `節士` 黔敖「嗟！來食」一則：餓死是結局，整則在寫尊嚴 → II／VII
- `義勇` 弘演「因自刺其腹，內懿公之肝而死」：整則在寫臣對君的本分 → V
- `雜事/卷五` 秦二世自殺一則：整則在寫諂諛之臣不進言的後果 → V

**`節士` 與 `義勇` 兩章的 X 應該是 0。**

### (b) XII（信仰·神聖·超越）——次嚴重，而且會判反

全書卜、筮、妖、祥、彗星、禳、熒惑、天報材料極密。**但劉向幾乎每一次都是用占候的框架講「不在神在德」——那該落 XI，不是 XII。**

> 出現卜／筮／妖／祥／禳／熒惑／鬼神時，先問這一段是在**執行**占候還是在**否定**占候。
> 執行占候且無評語 → `[]`（那只是敘事程序）。
> 否定占候並把因果推回德行 → **XI**。
> 只有文本自己認證徵應真的成立，才給 XII。

這與兵書那一格完全同構（做占候判空、否定占候命中 XI）。

會判錯的具體段：

- `善謀/卷上`「卜偃卜之曰：『吉，遇黃帝戰於阪泉之兆。』筮之，遇大有之暌」→ 純史事記錄，**判 `[]`，絕不給 XII**
- `雜事/卷一` 孫叔敖埋兩頭蛇：「聞見兩頭之蛇者死」「有陰德者，天報以福」表面滿分 XII → 整則在寫一個孩子怕別人也看見而先埋了它，**主載是 VII**

### (c) III（愛與親密）與 IV（家庭與傳承）

全書妻、色、母、後宮、婦人材料不少，但主載幾乎都在朝廷或品格。**III 全書大概只有 0–2 段。**

> 妻／色／母／後宮／婦人出現時：家內事才給 IV，落到朝廷或治國一律給 V。
> 私慾被轉成公共議題的，判 V，不判 III。

會判錯的具體段：

- `雜事/卷三` 梁惠王「寡人有疾，寡人好色」→ 主載是「與百姓同之」，**判 V 不判 III**（全書第一號 III 陷阱）
- `雜事/卷二` 無鹽女：醜女自薦後宮＋「臼頭深目、皮膚若漆」同時觸發 III 與 IX → 實為 II＋V（四殆諫言、以貌取人的翻轉）
- `雜事/卷一` 申公巫臣攜夏姬奔晉 → 判語是「為先王謀則忠，自為謀則不忠」→ V＋VII
- `善謀/卷下` 保太子諸段（戚夫人泣、骨肉）→ 朝廷繼嗣操作，V＋VIII

### (d) 附帶：IX（苦難·疾病·身體）應該接近 0

- `雜事/卷二` 扁鵲見齊桓侯：通篇病程，但文本自己說「夫事之禍福，亦有腠理之地。故聖人蚤從事矣」→ 病是載體，判 VII／XI
- `雜事/卷五` 卞和斷兩足 → 斷足是代價不是主題，VIII＋II
- `善謀/卷上` 黃歇上書中段「刳腹絕腸，折顙折頸，身首分離，暴骨草澤」→ 全書血腥密度最高的一段，但整段是外交推演，**判 `[]`**

### (e) 附帶：VI 的體裁家具不要反射填

「顏色不變」「拱而待兵」「逡巡而謝」「面有愧色」「泣」「太息」是這一體裁的敘事套語，**出現本身不是 VI**。

- `雜事/卷一` 周舍死後簡子泣三年 → 主載是「沒有人再指出我的過錯了」，V＋II

## `modes` 的三條硬規定

1. **`ritual` 全書 0 段。**祝、禳、齋三日、喪這些材料（鮑叔祝酒、麥丘三祝、晏子止禳彗星、湯解網更祝、宿齋三日）**全部是被敘述的事件，不是被規定的程序**，一律 `narrative`。
2. **`worked_instance` 全書 0 段**（那是算書題例專用）。
3. **對話被包在敘事框架裡時，主導 mode 仍是 `narrative`**，不要因為有人說話就給 `expression`。`expression` 留給整段就是一封信或一篇上書、沒有敘事框架的段：黃歇上秦昭王書、燕惠王遺樂毅書、樂毅報燕王書、鄒陽獄中上書（這幾組各佔數段）。

預期分佈供對照（**不是配額，不要為了湊比例改判**）：`narrative` 佔八成五以上，`expression` 一成不到，`proposition` 與 `formalization` 各數段，`observation`、`prescription` 個位數。

`formalization` 的判空／命中要分開：呂子師承對照表雖是表列，但尾段轉為「不學其聞則不若聾……能全天之所生而勿敗之」，**是命中不是判空**；管仲薦五子職掌表、昭奚恤壇位與五臣職掌、推恩令則是判空＋`formalization`。

## 原文實況（**這些都不是你要修的東西**）

1. **缺字符號**：`齊有良兔曰東郭<夋兔>`（應作㕙）、`援矢於{甬}`（應作筩）。照原樣理解，不要改寫原文。
2. **懸空腳註**：「晉平公過九亰[1]而歎曰」的 `[1]` 指向空的校勘記，判讀時忽略。
3. **引號兩制**：`善謀/卷下` 與 `雜事/卷一` 用「」，其餘八章用“”，是兩份轉錄合併的痕跡。
4. **系統性訛字**，直接按右欄理解，不要因為看不懂就判空：

5. **承接殘段**：有些段是前一段的下半，單獨看沒有主語（「明日，王薨」「安國曰」「青蛉猶其小者也」「故仁人之兵」「王曰：『然則其為人上何如？』」「既而晉人之救鄭者至」「無鹽女曰」）。**同一單元的各段都在同一批裡，往前讀取語境再判這一段自己的文字。**
6. **最危險的一組在 b07**：曾參殺人、樂羊謗書讀起來完全像兩則獨立寓言，**實為甘茂說秦武王時的引譬**，本體是前一段、末尾又回到甘茂。**不要把它們當獨立寓言判成 VII**——這一組的主載是君臣信任（V）。

| IV | 家庭與傳承 | 親子、宗族、繼承、教養、婚姻家內事 |
| V | 群體·社會·公義 | 孤獨與歸屬、友誼、我群他群與偏見、公義與權力、責任與領導 |
| VI | 情緒與內在生活 | 喜怒憂懼、內在經驗 |
| VII | 善惡·良心·品格 | 德性、良心、品格養成 |
| VIII | 工作·成就·召喚 | 勞動、職業、才能發揮、成就 |
| IX | 苦難·疾病·身體 | 痛苦、疾病、身體限制（**不是「提到身體或生病」，是有人在自己的身體處境裡而文本在寫那件事**） |
| X | 無常·老·死·失去 | 死亡、衰老、失去（**見上面 (a)**） |
| XI | 自由·命運·改變 | 命定與自由、人能否改變 |
| XII | 信仰·神聖·超越 | 神聖、超越、信仰實踐（**見上面 (b)**） |
| XIII | 安頓·修復·平安 | 受苦之後如何自處、如何與處境相處 |

`Z-wisdom`、`X-modern`、`Y-nature` **不是領域**，絕不可出現在 `domains`。

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句；人物品題走這格 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、職掌表、制度條文 |
| `narrative` | 用故事承載 | 有人物與情節（**本書主導 mode**） |
| `ritual` | 用儀節承載 | 規定動作、時序、器物（**本書 0 段**） |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人、整段沒有敘事框架 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用（**本書 0 段**） |

**`modes` 不要疊到三個以上**，挑主導的一到兩個。

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。
2. **一段可多標領域，但預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。**不得標到四個。**
3. **不要更動 `chapter` 與 `para_index`。**章名逐字照抄（`雜事/卷亖` 不准寫成 `雜事/卷四`）；`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。b05 含兩章，兩章各自從 1 編號。
4. **不要用你對劉向、對這些歷史人物的既有知識去補文本沒說的東西**，也不要判斷書中的道德立場對不對。你的工作是記錄這一段在做什麼，不是評價它。
5. **不要把別批的判空比例搬過來當預期值。**十章形態差異極大，體裁差異不是判準差異。
6. **`reason` 必須引到這一段自己的文字**，不得只寫概括。判 `[]` 的段落也要寫 `reason`，至少指出它做的是事件記錄、地緣算計、還是譜系交代。

## 輸出格式

寫到 `delegation/xinxu/out/bNN.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "刺奢", "para_index": 1, "domains": ["V"], "modes": ["narrative"],
     "reason": "……（引原文句）……，整則在寫在上者取之於民該有的分寸"},
    {"chapter": "善謀/卷上", "para_index": 2, "domains": [], "modes": ["narrative"],
     "reason": "晉文公納周襄王的事件記錄，卜偃卜筮只是敘事程序，刪掉少的是史事不是看法"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。** 這是回填時的雙向檢查條件，缺漏會整批退回。

## 驗收條件（事先寫死，回收後逐條機械檢查）

1. **`rows` 數等於該批段數**，`chapter` 只能是該批的章名字串、逐字相符，`para_index` 每章從 1 連號無缺，每段都有非空 `reason`。
2. **`ritual` 與 `worked_instance` 全書 0 段。**
3. **`節士`（b04）與 `義勇`（b05）兩章的 `X` 為 0。**
4. **`III` 全書不超過 2 段**；`雜事/卷三` 梁惠王好色那一段必須含 `V` 且不得含 `III`。
5. **`XII` 全書不超過 3 段**，且只能落在 `雜事/卷亖`；`善謀/卷上` 卜偃那一段必須判 `[]`；`雜事/卷一` 兩頭蛇那一段必須含 `VII` 且不得含 `XII`。
6. **`IX` 全書不超過 2 段**；`雜事/卷二` 扁鵲那一段不得含 `IX`；`善謀/卷上` 黃歇上書中段必須判 `[]`。
7. **上表「必須判空」的段全部為 `[]`；「必須命中」的段全部含指定的那一格。**
8. **零段 `domains` 長度 ≥4；零段 `modes` 長度 ≥3。**
9. **`善謀/卷上` 與 `善謀/卷下` 兩章的判空率必須明顯高於 `刺奢`、`節士`、`義勇`**（這是文本形態的結果，不是配額——若判出來不是這樣，表示閘門在某一側鬆了）。
