## 這部書是什麼

《司馬法》相傳出於齊威王時追論古司馬兵法，今存殘本五篇 67 段：**仁本（10 段）、天子之義（15 段）、定爵（15 段）、嚴位（20 段）、用眾（7 段）**。

**這部書內部落差極大，五篇要分開看：**

- 〈仁本〉〈天子之義〉幾乎不談戰術，談的是**戰爭該不該打、打的時候人怎麼被對待、三代的賞罰與教化怎麼分**——這是全書最該命中的地方
- 〈定爵〉〈嚴位〉是格言體條列，**「凡戰……」開頭的短句一條接一條**，多半是用兵原則，但其中夾著幾條直接在論人的
- 〈用眾〉7 段是純戰法處置，預期整篇判空

**文體提醒**：〈定爵〉〈嚴位〉大量使用極短的四字對句與名詞並列（「順天，阜財，懌眾，利地，右兵，是謂五慮」）。**句子短不代表內容濃，也不代表內容空**——照樣逐條讀懂它在做什麼。

## 通則性閘門

兵書整部在講怎麼打仗、用什麼打、怎麼傳令，內容表面上全與人有關（士卒、將領、敵我）。所以問：

> **這一段除了「怎麼打／用什麼打／怎麼傳令／怎麼看出勝負」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指**人可以怎麼活、人有哪些品性、人與人之間如何、什麼樣的人該被託付什麼**。

**不是**指段落裡出現了人（兵書每一段都有人）、出現了「仁義」兩個字（兵書拿仁義當致勝條件時，那是工具不是主張），也不是指那件戰法的對象是人。

兩個對稱的錯法都要防：

- **判空太快**：看到「這是兵書」就整批判空。〈仁本〉〈天子之義〉大半在論政論人，判空會漏掉本書最實的部分
- **硬撈太多**：看到「以仁為本」四個字就填 VII。要看它接下來做了什麼——若接的是「所以殺人安人，殺之可也」，那是在論戰爭的正當性（V），不是在論德性本身

正解只有一個：**逐段真的讀懂它在做什麼，然後照實記。**

## 六韜校準基準（同體裁前一部，遇同類段落判得一致）

《六韜》60 段已標完，判空 38 段（63%）。四條已驗收的判準直接沿用：

- **原文自己去解釋「人為何如此」，就命中。**〈勵軍〉「士非好死而樂傷也，為其將知寒暑饑飽之審」→ V
- **談賞罰施用的階層與正當性算 V；只規定號令怎麼下、鼓鐸怎麼響不算。**〈將威〉「殺及當路貴重之臣」「賞及牛豎馬洗厩養之徒」→ V
- **占候術數不進 XII。**〈兵徵〉「得神明之助」「城之氣如死灰」是技術性占驗，不是敬畏或神秘經驗
- **器物對照／清單判空，但同一段末尾若轉成治國與生計的主張，仍照該主張命中。**〈農器〉→ V+VIII

同時六韜確認了這些判空是對的：通訊協定、器械規格清單、占驗與分類、「用兵之害，猶豫最大」（猶豫是戰術缺陷不是情緒論述，**不進 VI**）、「將不仁則三軍不親」（品性只作戰力條件）。

**一段最多兩個領域。六韜 60 段沒有任何一段疊到三個。**

## 本書的命中區

### 〈仁本〉——戰爭正當性與交戰規範

- [1]「古者以仁為本，以義治之……是故殺人安人，殺之可也。攻其國，愛其民，攻之可也。以戰去戰，雖戰可也」——**在論殺人在什麼條件下是正當的**，這是公義與權力的問題 → **V**（可考慮併 VII，但要寫得出理由）
- [2]「故國雖大，好戰必亡；天下雖安，忘戰必危」＋「不加喪，不因凶……所以愛夫其民也」——對敵國之民的責任 → **V**
- [4]「逐奔不過百步，縱綏不過三舍，是以明其禮也；不窮不能而哀憐傷病……成列而皷，是以明其信也」——**逐項把戰場動作解釋成某種德性的表現**，六德（禮義信義勇智）是這一段的主題不是條件 → **VII**（可考慮併 V）
- [7]「入罪人之地，無暴神祇……見其老幼，奉歸勿傷。雖遇壯者，不校勿敵。敵若傷之，醫藥歸之」——**規定征伐者怎麼對待非戰鬥者與已傷的敵人** → **V**
- [10] 九伐之法（憑弱犯寡則眚之、賊賢害民則伐之、賊殺其親則正之、放弒其君則殘之）——**按罪行的性質決定處置**，逐條在說哪種行為該被怎麼判 → 可考慮 **V**；若你判定它只是征伐條件表，就判空並在 `reason` 說明

**〈仁本〉的判空陷阱**：

- [6] 冢宰徵師的整套程序：「乃告于皇天上帝，日月星辰，禱于后土四海神祇，山川冢社，乃造于先王」——**這是出師的儀節程序，不是人與神聖的關係**。與六韜占候同一類 → **不進 XII**，走 `ritual`。但這一段前半「其有失命亂常，背德逆天之時，而危有功之君，偏告于諸侯，彰明有罪」在講公開宣示罪狀，那部分可考慮 V
- [3] 春蒐秋獮、諸侯春振旅秋治兵 → 制度登錄，`[]`＋`ritual` 或 `formalization`
- [9] 治諸侯者六（以土地形、以政令平、以禮信親……）→ 這是**對外操作手冊**，同六韜〈文伐〉十二節，教怎麼駕馭對手 → `[]`

### 〈天子之義〉——三代教化與賞罰，本篇一半命中一半判空

**會命中的：**

- [1]「天子之義，必純取灋天地……士庶之義，必奉於父母，而正於君長」——身分與其應盡之義的對應 → 可考慮 **V**（或 IV，若你認為「奉於父母」承重）
- [2][3] 貴賤之倫經、「上貴不伐之士……茍不伐則無求，無求則不爭」——**在解釋不自誇這種品性為什麼會導致不爭** → **VII**（可考慮併 V）
- [6] 三代誓師時機不同（有虞氏戒於國中／夏后氏誓於軍中／殷誓於軍門之外／周將交刃而誓之），末尾「夏賞於朝，貴善也。殷戮於市，威不善也。周賞於朝，戮於市，勸君子，懼小人也」——**在解釋賞罰的場所選擇背後對人性的假設** → **V**（可考慮併 VII）
- [11] 多威則民詘、少威則民不勝，逐項列出上位者做什麼會讓下民垮掉（「上不尊德而任詐慝……不貴善行而貴暴行」）→ **V**
- [13]「大捷不賞，上下皆不伐善……上下不伐善若此，讓之至也。大敗不誅，上下皆以不善在己……上下分惡若此，讓之至也」——**把「讓」當成一種人與人之間的關係狀態來論** → **VII**＋**V**
- [14]「古者戍兵三年不興，覩民之勞也。上下相報，若此，和之至也」→ **V**

**判空的：**

- [7] 長兵短兵輕重利鈍 → `[]`＋`prescription`
- [8][9][10] 三代戎車名（鉤車／寅車／元戎）、旂色（玄首／白／黃）、章飾（日月／虎／龍）——**這是制度沿革對照表**，與六韜〈軍用〉器械清單、〈三陳〉分類同類 → `[]`＋`formalization`。**「天之義」「地之道」在這裡是配色的說法，不給 XII**
- [12]「國容不入軍，軍容不入國……介者不拜，兵車不式，城上不趨」——這一段值得單獨想過：前半「軍容入國則民德廢，國容入軍則民德弱」在講兩套規矩混用會怎樣，末尾「故禮與灋表裏也。文與武左右也」是原則陳述。可考慮 **V**；若你判定它只是儀節分野的規定，就判空並說明
- [15] 愷歌、偃伯靈臺 → `[]`＋`ritual`

### 〈定爵〉——格言體，多數判空，少數要挑出來

**判空的主體**（本篇最多的一類）：戰前準備清單、五慮五兵、陣法、戰參戰患戰權的分類條列、「凡戰之道，既作其氣，因發其政」的施行程序 → `[]`＋`formalization` 或 `prescription`

**要單獨想過的：**

- [6]「時日不遷，龜勝微行，是謂有天」——**卜龜在這裡是勝算條件，不是信仰實踐，不進 XII**
- [11]「榮，利，恥，死，是謂四守」＋「唯仁有親，有仁無信，反敗厥身」——前者是**人會為了什麼守住陣地**（可考慮 V 或 VII），後者是仁與信的關係。整段其餘（七政、人人正正辭辭火火）是分類術語 → 判斷時以主導內容為準
- [13]「凡人之形，由眾之求……人生之宜謂之灋」——在講法從何而來 → 可考慮 **V** 或 **XI**；判不出來就判空並說明
- [14][15] 治亂七目（仁信直一義變尊）與立法七目——**這是綱目表**，同六韜〈王翼〉編制表，`[]`＋`formalization`。**不要因為出現「仁」「信」「義」就填 VII**

### 〈嚴位〉——本篇有全書最直接論人的兩條

**必須命中的：**

- [9]「凡人：死愛，死怒，死威，死義，死利」——**直接列舉人會為什麼而死**，這是關於人的斷言不是戰法 → **V** 或 **VII**（也可考慮 X，但要寫得出「這一段在談死亡本身」的理由；若只是列舉赴死的動機，X 不成立）
- [19]「凡民：以仁救；以義戰；以智决；以勇鬬；以信專；以利勸；以功勝。故心中仁，行中義，堪物智也，堪大勇也，堪久信也。讓以和，人自洽……人說其心，效其力」——**逐項定義德性並說它們各自能做到什麼**，是全書最像人物志的一段 → **VII**（可考慮併 V）
- [16]「人方有性，性州異，教成俗，俗州異，道化俗」——**在講人的性情因地而異、教化如何改變風俗** → **XI**（人能否被改變）或 **V**；可併不可濫
- [2] 末尾「若畏太甚，則勿戮殺，示以顏色，告之以所生，循省其職」——**在講對過度恐懼的人不能用殺，要用什麼**。這一段前半是隊形與號令規定（判空材料），是這個末尾把它拉進來。**判準同六韜〈農器〉：前半判空但末尾轉向就照末尾判** → 可考慮 **V** 或 **VI**；判不出來就判空並說明
- [18]「若使不勝，取過在己；復戰則誓以居前」——將領把敗責歸己 → 可考慮 **V**

**判空的：**

- [1][3][4][5][6][7][8][10][11][12][13][14][15][17][20]：位嚴政栗、車密徒坐、輕重相為、鼓的種類、三軍之戒不過三日、擊其微靜避其強靜——**全是用兵原則與號令規格** → `[]`
- 特別注意 [17]「兵不告利，甲不告堅，車不告固，馬不告良，眾不自多，未獲道」——看起來像在講不自誇（像〈天子之義〉[3]的不伐），但這裡整條在講勝而不驕的用兵狀態，**若你判定它與 [3] 同質就照 VII 判，若判定它只是戰備警語就判空**——兩種都可以，`reason` 要寫出你選哪一種、為什麼

### 〈用眾〉——預期整篇判空

7 段全是眾寡進退、地形選擇（背風背高右高左險）、觀敵法、追擊與退路。→ `[]`＋`prescription` 為主。

末段 [7]「書親絕，是謂絕顧之慮」（斷絕家書以絕後顧）值得看一眼：**它動的是士卒與家人的聯繫**，但整條在講怎麼提升戰力。判空並在 `reason` 說明即可；若你認為它在講人的牽掛本身，寫出理由再給 IV 或 V。

**本書特別提醒的四格**：

- **XII（神聖）**：〈仁本〉[6] 的皇天上帝／后土／四海神祇、〈定爵〉[6] 的龜勝、〈天子之義〉[9] 的「天之義」「地之道」，**一律不給**。六韜 60 段 XII 掛零就是這條的先例
- **VI（情緒）**：〈嚴位〉多處講「畏」「懼」（「畏則密」「擊其大懼，避其小懼」）——那是戰場狀態的操作變數，不是在寫情緒如何住在人身上。**唯一可能例外是 [2] 末尾對過度恐懼者的處置**
- **X（死亡）**：全書滿篇死傷。〈嚴位〉[9]「凡人：死愛，死怒……」列的是赴死的動機不是死亡本身。要給 X，得是這一段真的在談死亡
- **IX（苦難身體）**：〈仁本〉[7]「敵若傷之，醫藥歸之」是交戰規範不是在寫受傷的人。六韜 IX 掛零

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、編制表、器械規格、數量比例、綱目分類表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

要點：

- **主導 mode 是 `proposition` 與 `prescription`**，兩者常同現
- **`formalization` 在〈定爵〉〈嚴位〉數量會很大**（五慮、七政、四守、戰參戰患戰權、立法七目、鼓的八種）。綱目分類表就是 `formalization`，與領域無關
- **`ritual` 只給真的在規定儀節動作時序的段落**：〈仁本〉[6] 的告天禱地、[3] 的春蒐秋獮、〈天子之義〉[15] 的偃伯靈臺。誓師（[6] 三代誓於何處）也算
- **`narrative` 本書幾乎沒有**。全書無人物情節，不要因為提到「有虞氏」「夏后氏」就給 narrative——那是制度對照不是故事
- **不要給 `expression`。**全書是第三人稱論述體
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **`reason` 裡寫的話必須在原文找得到。**不可以替原文補上它沒說的東西，也不可以用你對《司馬法》的既有知識去補。判斷依據只有你眼前這一段的文字。
4. **不要更動 `chapter` 與 `para_index`**。章名逐字照抄（「仁本」「天子之義」「定爵」「嚴位」「用眾」），`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。
5. **不要判斷書中的軍事主張對不對，也不要評價它的道德立場。**你的工作是記錄這一段在做什麼。
6. 原文有異體字（灋＝法、皷＝鼓、荅＝答、陳＝陣、鬬＝鬥、踰＝逾、覩＝睹）與殘缺費解處，那是來源格式與傳世殘本的實況，不影響判讀。**看不懂的短句不要硬掰內容，判空並在 `reason` 說明文意不明。**

## 輸出格式

寫到 `delegation/sima-fa/out/b01.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "嚴位", "para_index": 9, "domains": ["VII"], "modes": ["proposition"],
     "reason": "「凡人：死愛，死怒，死威，死義，死利」直接列舉人會為什麼而死，是對人的斷言不是戰法規定"},
    {"chapter": "用眾", "para_index": 2, "domains": [], "modes": ["prescription"],
     "reason": "背風背高右高左險，全段是地形選擇的處置規定，沒有說到關於人的什麼"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。**共 67 段：仁本 10、天子之義 15、定爵 15、嚴位 20、用眾 7。這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，**判 `[]` 的段落也要寫 `reason`**，至少要指出它在做的是戰法處置、器械規格、制度對照、儀節程序，還是別的。
