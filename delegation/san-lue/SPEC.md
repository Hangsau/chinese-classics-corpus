## 這部書是什麼

《三略》（黃石公三略）託名黃石公授張良，成書於漢，分三卷 65 段：**上略（33 段）、中略（13 段）、下略（19 段）**。

**先把最重要的一件事說清楚：這部書名為兵書，實際幾乎不談戰術。**它談的是**君主怎麼駕馭將帥、怎麼收攬人心、什麼樣的人該用什麼樣的人該防、國家為什麼會亡**。上略大量引《軍讖》，中略引《軍勢》，下略幾乎是純論政論德。

**因此：本書的判空比例會遠低於同組的其他兵書。**同組前一部《六韜》60 段判空 38 段（63%），那是因為六韜有整整三卷（虎豹犬）是戰法手冊。**三略沒有那一半。**

> **不要把六韜的判空比例搬過來當預期值。**體裁差異不是判準差異——判準完全一致，只是這部書的內容本來就落在判準的命中側。
>
> 反過來也一樣：**不要因為知道它命中率高就整批硬撈。**每一段照樣要問通則性閘門。

## 通則性閘門

兵書整部在講怎麼打仗、用什麼打、怎麼傳令，內容表面上全與人有關。所以問：

> **這一段除了「怎麼打／用什麼打／怎麼傳令／怎麼看出勝負」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指**人可以怎麼活、人有哪些品性、人與人之間如何、什麼樣的人該被託付什麼**。

**不是**指段落裡出現了人、出現了「仁義」兩個字（兵書拿仁義當致勝條件時，那是工具不是主張），也不是指那件戰法的對象是人。

**本書的難處在於它幾乎每段都在講「怎麼駕馭人」，所以要再問一層：**

> 這一段是在教「怎麼把人變成可用的工具」（操作手冊），還是在說「人是什麼樣的、人與人之間該如何」（關於人）？

兩者都可能命中，但理由不同。中略[3]「使智、使勇、使貪、使愚……因其至情而用之」是**先斷言人的至情各不相同**才談使用——斷言那一半承重，命中。若只是「賞則來、罰則去」的操作規則而不解釋人為何如此，就判空。

## 六韜校準基準（同體裁前一部，遇同類段落判得一致）

《六韜》60 段已標完並驗收。四條已驗收的判準直接沿用：

- **原文自己去解釋「人為何如此」，就命中。**〈勵軍〉「士非好死而樂傷也，為其將知寒暑饑飽之審」→ V
- **談賞罰施用的階層與正當性算 V；只規定號令怎麼下、鼓鐸怎麼響不算。**〈將威〉「殺及當路貴重之臣」「賞及牛豎馬洗厩養之徒」→ V
- **占候術數不進 XII。**〈兵徵〉「得神明之助」「城之氣如死灰」是技術性占驗，不是敬畏或神秘經驗
- **器物對照／清單判空，但同一段末尾若轉成治國與生計的主張，仍照該主張命中。**〈農器〉→ V+VIII

六韜同時確認：通訊協定、器械規格、占驗分類、「用兵之害，猶豫最大」（猶豫是戰術缺陷不是情緒論述，**不進 VI**）、「將不仁則三軍不親」（品性只作戰力條件）——一律判空。

**一段最多兩個領域。六韜 60 段沒有任何一段疊到三個。三略內容較厚，允許出現第三個，但 `reason` 必須寫得出「拿掉它這一段就少講了什麼」。**

## 上略——《軍讖》引文密集區

### 會命中的典型

- [1]「夫主將之法，務攬英雄之心，賞祿於功，通志於眾……與眾同好靡不成，與眾同惡靡不傾」——**在講領導者與被領導者的關係如何成立** → **V**
- [7] 一長串處置人心的對照表：「危者安之，懼者歡之，叛者還之，冤者原之，訴者察之，卑者貴之，強者抑之，敵者殘之，貪者豐之，欲者使之，畏者隱之……」——**這一段要單獨想過。**它逐項列出人處在什麼狀態下該被怎麼對待，**看起來像操作手冊，但它承認並命名了十幾種人的處境**。可考慮 **V**；若你判定它整條在教怎麼收買各類人為己所用（工具化），就判空並在 `reason` 說明你的理由。**兩種判法都可以接受，重點是 `reason` 要說清楚。**
- [11] 昔者良將之用兵，有饋一簞醪者，投之於河，令士眾迎流而飲——**敘事，且明說「一簞之醪不能味一河之水，而三軍之士思為致死者，以滋味之及己也」，在解釋人為什麼肯赴死** → **V**（同六韜〈勵軍〉的判法）
- [21]「香餌之下必有死魚；重賞之下必有勇夫」——**用比喻斷言人受什麼驅動** → **V** 或 **VII**
- [24]–[33] 十則《軍讖》政治病理學：「賢人所歸則其國強，聖人所歸則其國六合同」「一令逆則百令失，一惡施則百惡結」「傷賢者殃及三世，蔽賢者身受其害，嫉賢者其名不全」「群吏朋黨，各進所親……此謂亂源」「世世作姦，侵盜縣官，進退求便，委曲弄文，以危其君，此謂國姦」——**逐條在寫敗壞的人做什麼、國家因此怎麼垮** → **V**（可考慮併 **VII**，若該條的重心在人的惡而非制度後果）
- [4][5][6] 柔能制剛、弱能制強、「能柔能剛，其國彌光；能弱能強，其國彌彰」——**要單獨想過**。這是把柔剛當成一種人／國的存在方式在論，可考慮 **XI** 或 **VII**；若你判定它只是用兵原則的抽象化，就判空並說明

### 判空的典型

- 純用兵原則與軍令：「軍井未達，將不言渴」這類要看——若只是規定將領的動作就判空，若明說「故能使三軍如一心」而在解釋人心怎麼被贏得，就照 V 判
- 出現「陰謀」「權變」「詭道」的操作段
- 純粹的成敗因果宣告（「得而勿有則兵強」）沒有說到人本身的

## 中略——君臣關係與功成身退

- [3]「夫三皇無言而化流四海……使智、使勇、使貪、使愚……故智者樂立其功，勇者好行其志，貪者邀趨其利，愚者不顧其死。因其至情而用之」——**先斷言四種人各有其至情**，命中 → **VII**（品性）＋**VIII**（用人任事），同六韜〈六守〉的判法
- [11]「夫高鳥死，良弓藏；敵國滅，謀臣亡」＋功臣如何被處置——**在講功成之後人的下場**，可考慮 **V**；若整段重心在「所以要收其權」的君主操作，就照操作判並說明
- 〈中略〉論《軍讖》《軍勢》的來歷、三略各為誰而設的段落 → 這是**本書的自我說明**，`[]`＋`observation`

**中略最尖銳的 XII 陷阱：**

- [5]「禁巫祝，不得為吏士卜問軍之吉凶」——**這是一條軍令，沒有給任何理由。**看起來與信仰有關，實際它只規定了一個禁令。**照六韜「判準咬的是禁忌的理由，不是禁令本身」，這一條預期判 `[]`。**若你認為它其實在論人與神聖的關係，`reason` 必須指出原文哪一句在做那件事——指不出來就判空。

## 下略——純論政論德，本書最厚的一卷

- [2]「所謂樂者，非金石絲竹也，謂人樂其家，謂人樂其族，謂人樂其業，謂人樂其都邑，謂人樂其政令，謂人樂其道德」——**在重新定義「樂」是什麼**，且落在人與其生活的關係上 → **XIII**（安頓）或 **V**；這是本書少見的 XIII 候選，判給哪一格都要寫出理由
- [5] 道德仁義禮五者壹體，「仁者，人之所親，有慈惠惻隱之心，以遂其生成」——**逐項定義德性本身** → **VII**
- [12]「雖窮，不處亡國之位；雖貧，不食亂邦之祿」——**在講人在困境中守住什麼** → **VII**（可考慮併 V）
- [13]「兵者，不祥之器，天道惡之。不得已而用之，是天道也」——**在論戰爭本身的性質與正當性** → **V**（若你認為「天道」在這裡承重而非修辭，可考慮併 XII，但要寫出理由——**參照六韜先例，術數與天道語彙預設不進 XII**）
- [14]「夫人之在道，若魚之在水，得水而生，失水而死。故君子者常畏懼而不敢失道」——**在講人依存於什麼而活** → **I**（存在與意義）或 **VII**；這是本書少見的 I 候選
- 賢者、聖王、姦雄、讒佞如何辨別與如何對待的段落 → **V**（＋ **VII** 若重心在人的品性）
- 「傷賢」「蔽賢」「近臣專政」「四民用虛」的亡國徵候 → **V**

**下略的判空區**：純粹陳述得失因果而不觸及人本身的短句；重複上略已說過而未增加新內容的——**但注意：復述不是判空的理由。**判準是這一段自己說了什麼，不是它有沒有被說過。

`Z-wisdom`、`X-modern`、`Y-nature` **不是領域**，絕不可出現在 `domains`。

**本書特別提醒的四格**：

- **V 會非常密集，這是對的，不必壓。**本書大半在論君臣、賢佞、權力與公義
- **XII**：「天道」「神」「三皇」在本書多為論政修辭與術數語彙，**預設不給**。中略[5] 禁巫祝的軍令也不給。要給 XII，得是這一段真的在處理人與超越者的關係
- **VIII**：「賢者所適其前無敵」這類要分清楚——談的是**任用**（VIII）還是**德性**（VII）還是**權力結構**（V）。三者常同現，挑主導的
- **VI**：「危者安之，懼者歡之」是處置對象的狀態標籤，不是在寫情緒本身。六韜 VI 掛零

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、編制表、器械規格、數量比例、綱目分類表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

要點：

- **主導 mode 壓倒性是 `proposition`**（「A 則 B」「故 A」），其次 `prescription`
- **`formalization` 在本書很少**——本書幾乎沒有編制表、器械規格或算法。上略[7] 的處置對照表是格言並列不是可執行程序，**不要因為它排成一長串就給 `formalization`**
- **`narrative` 只有極少數幾處**：上略[11] 投醪於河那一則有人物有情節。純粹的「昔者……」若沒有具體事件不算
- **不要給 `expression`。**全書是第三人稱論述體
- **`ritual` 本書預期為零**
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。**但本書的判空段數預期會明顯少於同組其他兵書——見開頭的說明，不要往六韜的比例上靠。**
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **`reason` 裡寫的話必須在原文找得到。**不可以替原文補上它沒說的東西，也不可以用你對《三略》或黃石公、張良的既有知識去補。判斷依據只有你眼前這一段的文字。
4. **不要更動 `chapter` 與 `para_index`**。章名逐字照抄（「上略」「中略」「下略」），`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。
5. **不要判斷書中的政治主張對不對，也不要評價它的道德立場。**你的工作是記錄這一段在做什麼。
6. **《軍讖》《軍勢》引文照它自己的內容判。**「《軍讖》曰」是引述框架不承載判讀訊息，不要因為它是引文就判空，也不要因為引文密集就整批同一個答案。
7. 原文有異體字與費解處，那是傳世本實況。**看不懂的短句不要硬掰內容，判空並在 `reason` 說明文意不明。**

## 輸出格式

寫到 `delegation/san-lue/out/b01.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "上略", "para_index": 11, "domains": ["V"], "modes": ["narrative", "proposition"],
     "reason": "投醪於河一則並明說一簞之醪不能味一河之水而三軍思為致死、是因滋味之及己，在解釋人為何肯為領導者赴死"},
    {"chapter": "中略", "para_index": 5, "domains": [], "modes": ["prescription"],
     "reason": "禁巫祝不得為吏士卜問吉凶只是一條軍令，未給任何理由，不觸及人與神聖的關係"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。**共 65 段：上略 33、中略 13、下略 19。這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，**判 `[]` 的段落也要寫 `reason`**。
