# 發包 spec：洞冥記 段落級標註

## 你要做什麼

讀 `delegation/dongmingji/b01.md`（63 段，全書四卷），逐段判兩件事：

1. `domains`：這一段觸及哪些人生問題領域（下表 13 個 id，可以是空陣列）
2. `modes`：這一段用什麼方式說話（下表 8 個 id，可以是空陣列）

輸出寫成 `delegation/dongmingji/out/b01.json`，格式見文末。

## 這部書是什麼

《洞冥記》託名郭憲，記漢武帝朝的異物、異境與方士。全書由三種條目混成：

1. **物產條**：某國獻某物、某地有某草某木，說它長什麼樣、有什麼效驗（「食一片則歷月不飢」「千歲不渴」）。**這是全書大宗。**
2. **宮室條**：帝起某臺某閣某池，臺上有什麼、池中有什麼。
3. **人物條**：東方朔、董謁、李充、孟岐、郭瓊、黃安等方士異人的小傳或與武帝的問答。

它與《神異經》是姊妹體裁，差別在**這一部有人物與情節**——武帝貫穿全書，東方朔反覆出場。所以它會有一部分 `narrative`，而神異經幾乎沒有。

## 唯一的通則性閘門

> **這一則除了「有這麼一件奇物／進獻過這麼一次／起了這麼一座臺」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指的是：人可以怎麼活、人怕什麼、人與人之間如何。**不是**指條目裡出現了皇帝或方士，也不是指那件奇物對人有效。

## 本書最大的硬撈風險：**求仙不死的字眼遍布全書，但那不等於命中**

「千歲不飢」「服之不老」「身輕肌滑」「乘黃蛇入水」「仙人某某採藥食之」——這一類在全書出現數十次。**它們是物產的效驗記載，屬本草體，不是在談死亡、衰老或超越。一律 `[]`。**

同理，「起某臺以望仙」「召諸方士言遠國遐方之事」是宮室與朝儀記載，不因為出現「仙」字就給 XII。

**XII 要卡緊**：只有當該則真的在寫「人與神聖的關係」或「人如何求道」本身時才給，而不是在寫「有一種仙草長這樣」。

## 本書真正會命中的那一類

數量不多，但確實存在，漏掉就等於沒讀。判斷方式：**這一則的重心是那件奇物，還是那個人的處境？**

會命中的典型：

- 武帝晚年直接問「朕所好甚者不老，其可得乎」——這是他在替自己的老死發問，不是在記一種藥
- 武帝思念已故的李夫人而不可得，因此有草名懷夢——重心是思念與失去，奇草只是媒介
- 記某人少時家貧、拾樹葉代書簡、乞薪自照讀書、形貌醜劣而意度過人——這是在寫一個人怎麼對待自己的處境與才能
- 臣下藉一件異物向皇帝進諫（如以妹喜金簪之事諷帝好微行）——重心是勸諫與君臣關係
- 記帝待某寵姬「恐體痕」「恐塵垢汙其體」——重心是他怎麼對待她

不會命中的典型：

- 某國獻某獸某石某香某鳥，記其形色尺寸與用途
- 帝起某臺某閣，臺上陳設如何、池中有什麼船
- 東方朔向帝陳述遠國見聞，內容是一串地名物名
- 某仙人採某果食之而身生毛羽
- 奇物變形飛去（刀化為鵲、鵲化成龍、鴨化為童子）——那是異事本身

## `Z-wisdom` 陷阱

若某則只在講「如何辨識吉兇」「如何佔驗」，那屬 `Z-wisdom`，`domains` 判空。**`Z-wisdom` 絕不可寫進 `domains`。**

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法或制度 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

要點：

- 物產條、宮室條是 `observation`，**不是 `narrative`**——沒有情節就不是敘事
- 有人物對答、有事情發生（帝問朔答、獻獸後獸骨飛去、巨靈化青雀而帝起臺）→ `narrative`
- 帝或方士自陳（「朕所好甚者不老」「臣能使少者不老」）→ `narrative` + `expression`
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **不要更動 `chapter` 與 `para_index`**。它們是錨點，錯一個就整批對不上。章名是「卷第一」「卷第二」「卷第三」「卷第四」，`para_index` 在每一卷內從 1 重新編號，**回報時兩者都要給**。
4. **`Z-wisdom`、`X-modern`、`Y-nature` 不是領域**，絕不可出現在 `domains`。
5. **敘事段也要判領域**：故事是載體，它承載的內容照判。但反過來不成立——**有情節不等於有內容**，異物變形飛去仍然可以是 `[]`。
6. **不要用你對漢武帝、東方朔、李夫人的既有知識去補條目沒說的東西。**只判這一段文字寫了什麼。

## 輸出格式

寫到 `delegation/dongmingji/out/b01.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "卷第二", "para_index": 8, "domains": [], "modes": ["observation"],
     "reason": "記塗山之梨大小顏色與別名，純物產條，未觸及對人的看法"},
    {"chapter": "卷第四", "para_index": 1, "domains": ["X"], "modes": ["narrative", "expression"],
     "reason": "武帝暮年當面問不老可不可得，是他替自己的衰老發問，不是記一種藥"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。** 這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，但**判 `[]` 的段落也要寫 `reason`**——寫出你認為它少了什麼。這些 reason 是驗證判準的依據，不要寫成「無關」兩個字了事。
