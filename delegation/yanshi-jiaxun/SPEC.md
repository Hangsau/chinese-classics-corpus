# 發包 spec：顏氏家訓 段落級標註

## 你要做什麼

讀 `delegation/yanshi-jiaxun/<bNN>.md` 裡的每一段，判斷兩件事，輸出對照表 JSON 到 `delegation/yanshi-jiaxun/out/<bNN>.json`：

1. **L2 `domains`**：這段在處理哪些「人生問題領域」（13 個 id，見下表）
2. **L3 `modes`**：這段**用什麼方式**處理（8 個 discourse_mode 值，見下表）

兩者正交：任一領域可搭配任一姿態。

## 這部書是什麼

《顏氏家訓》，北齊顏之推寫給子孫的訓誡，20 篇。**它整部都在對人事下判斷、發議論**——這跟前一部發包的九章算術正好相反，所以預期會大量命中，判空反而是少數。

但有三篇是例外，見下方「三篇特殊體例」。

## 唯一的通則性閘門

> **把這段裡的具體場景換成中性物件，它還成不成立？**
> 成立 → 場景只是包裝，填 `[]`。
> 不成立（垮掉，或講的東西整個變了）→ 場景是本質，才給領域。

這道閘門在本書多數段落會**通過**（因為顏之推直接在講人該怎麼活），列在這裡是因為書證、音辭兩篇要靠它擋掉。

## 最大的風險：V 被當成萬用桶

本庫已標的六部裡，V（群體·社會·公義）從未低於半數，鹽鐵論 88%、潛夫論 65%。**這次發包就是要驗 V 到底是文本特徵還是判準過寬。** 所以請嚴格照下面分工，不要因為顏之推是士族、講的是南北朝門第社會，就把家內事一律讀成階級與權力。

| 這段在講 | 填 |
|---|---|
| 父子、兄弟、夫婦、宗族、繼嗣、教養子女、後母與前子、喪葬奉先 | **IV 家庭與傳承**（不是 V） |
| 朋友、鄉黨、士人相處、我群他群與偏見（南人／北人、士／庶）、孤獨與歸屬 | **V** |
| 朝廷制度、官位權力、賦稅刑罰、誰該承擔什麼、為政責任與領導 | **V** |
| 一個人該有什麼品格、該不該做某事（德性、良心層） | **VII 善惡·良心·品格** |
| 讀書、學問能不能養活人、才能、職業、做官謀生、技藝該不該精 | **VIII 工作·成就·召喚** |
| 我是誰、名與實相不相稱、自我評價、身分焦慮 | **II 自我與認同** |
| 亂世流離、亡國、失去依靠、老、病、死、身後事 | **X** 或 **IX** |
| 佛教因果、神鬼、形神、來世 | **XII 信仰·神聖·超越** |

**同時談家內與朝廷，兩個都標。只談其一，就只標其一。**

## 三篇特殊體例（預設 `[]`，但要逐段確認）

1. **書證第十七（47 段）**：考據。「詩云……爾雅云……說文云……」辯字形、字義、版本異文。這些是**關於文本本身而非關於世界**的陳述，預設 `[]`。`modes` 也多半判不出 → `[]`。**但**若某段離開考據去評論人（例如譏諷俗儒、談南北學風差異、談「學者何其蔽也」），那就照實判。
2. **音辭第十八（10 段）**：聲韻，南北方音差異。同上預設 `[]`。**但**談「南人北人相輕」「士庶口音之別」時，那是我群他群 → V。
3. **杂艺第十九（13 段）**：琴棋書畫射御卜筮。若只是品評技藝源流 → `[]`；若在講「該不該以此自名／精此有何害」→ VIII（有時 II）。

## Z-wisdom 陷阱（本書特大，勉学第八整篇）

**`Z-wisdom`（智慧·學習·好奇）不是領域，絕不可填進 `domains`。** 談「為什麼要求知」「怎麼讀書」「學問的方法」的段落，`domains` 照實判，多半是 `[]`。

**但勉学第八不是整篇判空。** 這篇裡大量內容不是方法論，是在談人：

- 「父兄不可常依，鄉國不可常保，一旦流離，無人庇蔭，當自求諸身」→ 講失去依靠與自立 → `["X", "VIII"]`
- 「梁朝全盛之時，貴遊子弟多無學術……及離亂之後，朝市遷革，求諸身而無所得」→ 講身分崩解後名實不符 → `["II", "VIII"]`
- 「有客難主人曰：吾見強弩長戟……學備古今，才兼文武，身無祿位，妻子飢寒者，不可勝數」→ 講才能與際遇不相稱 → `["VIII", "XI"]`
- 純粹講「讀書要先識字」「讀書次第如何」→ `[]`

所以請**逐段分辨哪一句在談方法、哪一句在談人**，不要整篇一刀切。人物志與潛夫論都在這裡踩過坑。

## 從前一部書帶過來的三分法（〈文章〉〈省事〉會用到）

鹽鐵論標完後立的規則，本書照用：

- 講**說服／論辯的技術**（怎麼寫得好、怎麼引經據典）→ 屬 `Z-wisdom`，`domains` 填 `[]`
- 講**言說的倫理**（該不該譏刺、文人相輕該不該）→ **VII**
- 講**進言不被聽見、被誤解、才華不被看見**→ **III**（溝通與被理解），必要時加 **VIII**

三者原文外觀相近，沒有這條三分法會全部標空或全部標滿。

## XIII 是本次要特別驗的一格

本庫已立的假設是：**XIII（安頓·修復·平安）的有無，取決於文本裡有沒有人替自己的處境說話。** 顏之推歷仕四朝、三為亡國之人，〈序致〉與〈终制〉是第一人稱交代一生，〈止足〉講知足自限，〈養生〉講亂世中如何自保。

若有段落是他對自身遭遇的自處、或教子孫在無法改變的處境裡如何安身 → 標 **XIII**，並在 `reason` 明說是誰替誰的處境說話。**這一格請不要漏，它是本次發包的檢驗重點。**

注意分辨：講「該怎麼改變處境」是 XI（自由·命運·改變）或 V；講「處境改不了，人可以怎麼與它相處」才是 XIII。

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法或制度 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書幾乎不會用到** |

本書預期以 `observation`／`proposition`／`prescription`／`narrative` 為主。〈風操〉大量談避諱、稱謂、弔喪、婚嫁的具體規矩 → 常是 `ritual`（有時 `ritual` + `prescription`）。〈序致〉〈终制〉第一人稱 → `expression`。

**一段可多標 `modes`**（常見 `proposition` + `prescription`）。判不出來填 `[]`。

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。不要為了讓每段都有東西而硬填——負面結果本身是資料。
2. **一段可多標領域，但不要濫用。**真正同時觸及兩個領域才多標，不要把一段的每個名詞都對映成一格。
3. **不要更動 `chapter` 與 `para_index`**。它們是錨點，錯一個就整批對不上。`para_index` 在每一章內從 1 重新編號，所以**回報時章名與 para_index 兩者都要給**。
4. **`Z-wisdom`、`X-modern`、`Y-nature` 不是領域**，絕不可出現在 `domains`。
5. **敘事段也要判領域**：〈教子〉裡王大司馬母捶撻其子的故事，`modes` 是 `narrative`，但 `domains` 仍是 `["IV"]`——故事是載體，它承載的內容照判。

## 試點（b01）校準後補的兩條

b01 已判完並通過檢查，以下兩點是從它修出來的：

1. **`modes` 不要疊到三個以上**，除非每一個都真的承重。一段同時是描述、命題、規範、故事時，挑**主導的一到兩個**。姿態欄的用處是區辨，全都標等於沒標。
2. **「吾家如何如何／汝曹勿為」這類自述家規，領域要含 `IV`**，即使該段主題是別的。例如「吾家巫覡禱請，絕於言議……勿為妖妄之費」除了 `XII` 之外也是 `IV`——它是在立家風傳給子孫。

## 輸出格式

寫到 `delegation/yanshi-jiaxun/out/<bNN>.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "序致第一", "para_index": 1, "domains": ["IV"], "modes": ["proposition", "expression"],
     "reason": "自述作此書之由：家訓要靠親近之人的話才聽得進去，講的是教養在家內如何生效"},
    {"chapter": "教子第二", "para_index": 3, "domains": ["IV"], "modes": ["narrative"],
     "reason": "王大司馬母嚴教成子勳業、梁元帝時學士為父所寵而敗，兩故事對舉論嚴慈之效"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。** 這是回填時的雙向檢查條件，缺漏會整批退回。
