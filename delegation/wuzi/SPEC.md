# 發包 spec：吳子 段落級標註

## 你要做什麼

讀 `delegation/wuzi/b01.md`，逐段判兩件事：

1. `domains`：這一段觸及哪些人生問題領域（下表 13 個 id，可以是空陣列）
2. `modes`：這一段用什麼方式說話（下表 8 個 id，可以是空陣列）

輸出寫成 `delegation/wuzi/out/b01.json`，格式見文末。

## 這部書是什麼

《吳子》託名吳起，今存六篇 43 段：**圖國第一（10 段）、料敵第二（5 段）、治兵第三（8 段）、論將第四（5 段）、應變第五（10 段）、勵士第六（5 段）**。

主要外殼是「吳子曰：……」與「武侯問曰：『……』起對曰：『……』」。**這個外殼本身不承載任何判讀訊息**——不要因為它是問答就給 `expression`。

**三段分佈**：

- 〈圖國〉〈勵士〉：論治國、論何以能使人赴戰——**命中密集區**
- 〈料敵〉〈論將〉：辨敵情與辨將材——**半數命中，要逐段分**
- 〈治兵〉〈應變〉：訓練規格、行軍宿營、遇某地形某敵情該怎麼辦——**多數判空**

## 通則性閘門

兵書整部在講怎麼打仗、用什麼打、怎麼傳令，內容表面上全與人有關。所以問：

> **這一段除了「怎麼打／用什麼打／怎麼傳令／怎麼看出勝負」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指**人可以怎麼活、人有哪些品性、人與人之間如何、什麼樣的人該被託付什麼**。

**不是**指段落裡出現了人、出現了「仁義」兩個字（兵書拿仁義當致勝條件時，那是工具不是主張），也不是指那件戰法的對象是人。

兩個對稱的錯法都要防：

- **判空太快**：看到「這是兵書」就整批判空。〈圖國〉〈勵士〉大半在論政論人
- **硬撈太多**：看到「不和於國，不可以出軍」就填 V。要看它接下來做了什麼

正解只有一個：**逐段真的讀懂它在做什麼，然後照實記。**

## 六韜校準基準（同體裁前一部，**本書有兩處逐字對應，務必判得一致**）

《六韜》60 段已標完並驗收，判空 38 段。四條已驗收的判準沿用：

- **原文自己去解釋「人為何如此」，就命中。**〈勵軍〉「士非好死而樂傷也，為其將知寒暑饑飽之審」→ V
- **談賞罰施用的階層與正當性算 V；只規定號令怎麼下、鼓鐸怎麼響不算。**〈將威〉→ V
- **占候術數不進 XII。**〈五音〉律管候敵、〈兵徵〉望氣 → `[]`
- **器物對照／清單判空，但同一段末尾若轉成治國與生計的主張，仍照該主張命中。**〈農器〉→ V+VIII

**本書兩處與六韜逐字或逐結構重合，必須跟六韜判一樣：**

1. **〈治兵〉「用兵之害，猶豫最大，三軍之災，生於狐疑」——六韜〈軍勢〉同一句已判 `[]`。**看起來在談猶豫與恐懼（像 VI），實際是把猶豫當成決斷的技術缺陷在講 → **這一段的這一句不構成命中理由。**（該段其餘內容照樣獨立判。）
2. **〈圖國〉[8]「民有膽勇氣力者，聚為一卒；樂以進戰效力，以顯其忠勇者，聚為一卒；能踰高超遠、輕足善走者，聚為一卒；王臣失位而欲見功於上者，聚為一卒；嘗亡失城而欲除其醜者，聚為一卒」——六韜〈練士第五十三〉同一結構（按「人為什麼肯拼命」分類編伍）已判 II+VIII。**這一段預期照樣命中。**判準是「按人想要什麼分類」命中，「按人能做到什麼分類」判空——本段兩者都有（輕足善走 vs 欲見功、欲除其醜），以承重的那一半為準。

**一段最多兩個領域。六韜 60 段沒有任何一段疊到三個。**

## 本書的命中區

### 〈圖國〉——治國與用兵之本

- [1] 吳起以儒服見魏文侯、論「不修德」則有覆軍殺將之禍，並舉承桑氏修德廢武而滅、有扈氏恃眾好勇而亡——**在論一種治國姿態的代價** → **V**（有人物有情節，`narrative`）
- [4]「昔之圖國家者，必先教百姓而親萬民……不和於國，不可以出軍」＋「是以有道之主，將用其民，先和而造大事……民知君之愛其命、惜其死，若此之至，而與之臨戰，則士以進死為榮，退生為辱矣」——**明說人為何肯赴死**，同六韜〈勵軍〉判準 → **V**。段中「啟於元龜」「三讓」是儀節，**不進 XII**
- [6]「民安其田宅，親其有司……使民有恥」與四德（道義禮仁）——若重心在德性本身 → **VII**；若在治理效果 → **V**；兩者都寫得出就併，但不超過兩個
- [7] 兵之所起者五（爭名、爭利、積惡、內亂、因饑）、兵有五名（義兵、強兵、剛兵、暴兵、逆兵）——**在給戰爭的動機分類並命名**。要單獨想過：可考慮 **V**（把戰爭歸因於人的什麼）；若你判定它只是分類表，就判空＋`formalization` 並說明
- [8] 分卒編伍——見上節，預期命中
- [10] 武侯謀事群臣莫能及而有喜色，吳起引楚莊王「不穀不德，而群臣莫及者，國其幾於亡矣」而使武侯有慚色——**在論人在得意時該怎麼看自己** → **II** 或 **VII**（`narrative`）
- [9] 武侯問嚴刑明賞是否足以取勝，吳起答「舉有功而進饗之，無功而勵之」——若整段落在賞罰程序 → 判空；若在解釋人被什麼驅動 → V。**照原文實際說了哪一半判**

### 〈料敵〉——多數判空，一段例外

- [2] 論六國之俗：「齊性剛，其國富，君臣驕奢而簡於細民……秦性強，其地險，其政嚴……楚性弱，其地廣，其政騷……燕性愨，其民慎，好勇義……三晉……其性和，其政平」——**在斷言不同群體的集體性情，並據此推導其行為** → **V**（我群他群）。這是本書少見的群體性格論述
- [1][3][4][5]：敵情判斷、可擊八條與不可擊六條、擊之勿疑的時機 → `[]`＋`prescription`／`formalization`

### 〈治兵〉——多數判空，注意兩個陷阱

- [1][2][3][5][6] 行軍宿營、進止節度、四輕二重一信、教戰之令（一人學戰教成十人……萬人學戰教成三軍）→ `[]`＋`formalization`／`prescription`
- **[4] 陷阱一**：整段講三軍之災生於狐疑——**照六韜先例不進 VI**，見上節
- **[7] 陷阱二**：「必左青龍，右白虎，前朱雀，後玄武，招搖在上，從事於下」——**這是行軍布陣的方位術語，同六韜〈五音〉的五行青龍白虎朱雀玄武，一律不給 XII** → `[]`
- **[8] 陷阱三**：整段講養馬（「夫馬，必安其處所，適其水草，節其飢飽……寧勞於人，慎無勞馬」）——**這是牲口照料規格，不是照顧與被照顧（IX）** → `[]`。末句「人馬相親，然後可使」也不構成 III

### 〈論將〉——辨將材，半數命中

- [1] 總文武者為將、五慎（理、備、果、戒、約）、「將之所慎者五」→ **在定義將領該具備什麼**。可考慮 **VIII**（能不能勝任）＋ **VII**（品性）；同六韜〈論將〉五材十過的判法
- [4] 觀敵將之能否（「輕而易動」「賢而輕之」「愎而自用」）——**逐項寫人的性格弱點如何被利用** → 可考慮 **VII**；若你判定它整條是敵情偵察程序，就判空並說明。**兩種都可以，`reason` 要說清楚**
- [2][3][5] 鼓鼙金鐸旌旗之用、「不佔而知吉凶」的臨敵判斷、以下等馬試敵——若只是操作規格 → `[]`。**「不佔而知」出現時不要反射給 XII**

### 〈勵士〉——本書最實的一篇

- [1] 武侯問「嚴刑明賞足以勝乎」，吳起答「發號布令而人樂聞，興師動眾而人樂戰，交兵接刃而人樂死」——**在問人怎麼會樂於做這三件事** → **V**
- [3] 饗士三行（有功者上牢、次功中牢、無功下牢）＋「又頒賜有功者父母妻子於廟門外」＋「有死事之家，歲使使者勞賜其父母，著不忘於心」——**賞及於死者的家人**，不只是賞罰程序 → **V**（可考慮併 **IV**，若你認為「其父母妻子」承重；寫得出理由才給）
- [4]「一人投命，足懼千夫」＋以死賊伏於曠野千人追之為喻——**在斷言人在什麼狀態下有何等力量** → 可考慮 **V** 或 **VII**
- [5] 五萬人得車騎之助而破秦五十萬眾 → 若只是戰績陳述 → `[]`＋`observation`

### 〈應變〉——預期幾乎整篇判空

10 段全是遇強敵、遇眾我寡、陷谷、遇水、暴寇、圍城該怎麼處置 → `[]`＋`prescription`。

**唯一要看的是 [10] 末尾**：「示民無殘心。其有請降，許而安之」——**這是對降者與百姓的處置規範**，同司馬法〈仁本〉的交戰規範。可考慮 **V**；若你判定它只是攻城的操作手段（安民以利取城），就判空並在 `reason` 說明。

**本書特別提醒的四格**：

- **XII（神聖）**：〈圖國〉「啟於元龜」「祭於廟」、〈治兵〉青龍白虎朱雀玄武、〈論將〉「不佔而知吉凶」——**一律不給**。六韜 60 段 XII 掛零就是這條的先例
- **VI（情緒）**：「三軍震恐」「人樂死」是戰場狀態與行為傾向，不是在寫情緒如何住在人身上。〈治兵〉的猶豫狐疑照六韜先例不給
- **X（死亡）**：全書滿篇死。「士以進死為榮」「一人投命」列的是赴死的動機不是死亡本身。要給 X，得是這一段真的在談死亡
- **IX（苦難身體）**：〈治兵〉養馬那段不是。六韜 IX 掛零

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、編制表、器械規格、數量比例、綱目分類表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

要點：

- **主導 mode 是 `proposition` 與 `prescription`**
- **`formalization` 用在**：可擊八條不可擊六條、教戰之令的倍數推演、饗士三牢的等級、車騎步兵的數量配比、五名五慎的綱目表
- **`narrative` 本書比六韜多**：〈圖國〉[1] 吳起以儒服見魏文侯、[10] 楚莊王與武侯慚色、〈勵士〉[4] 死賊伏於曠野的譬喻、[5] 五萬破五十萬。**「武侯問曰」本身不是敘事**，要有具體事件與人物動作
- **`ritual` 只給真的在規定儀節的**：〈圖國〉[4]「啟於元龜，參之天時」「三讓」的出師儀節、〈勵士〉[3] 廟門外頒賜
- **不要給 `expression`。**問對框架不是自道
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **`reason` 裡寫的話必須在原文找得到。**不可以替原文補上它沒說的東西，也不可以用你對《吳子》或吳起（殺妻求將、吮疽等傳說）的既有知識去補。判斷依據只有你眼前這一段的文字。
4. **不要更動 `chapter` 與 `para_index`**。章名逐字照抄（「圖國第一」「勵士第六」，含中文數字序號），`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。
5. **不要判斷書中的軍事主張對不對，也不要評價它的道德立場。**你的工作是記錄這一段在做什麼。
6. 原文有異體字、夾注與引號不對稱，那是來源格式，不影響判讀。

## 輸出格式

寫到 `delegation/wuzi/out/b01.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "勵士第六", "para_index": 3, "domains": ["V"], "modes": ["prescription", "ritual"],
     "reason": "饗士按功分三牢並頒賜有功者父母妻子、歲勞死事之家，賞罰穿過戰場延伸到家人，是賞施用範圍的正當性"},
    {"chapter": "治兵第三", "para_index": 8, "domains": [], "modes": ["prescription"],
     "reason": "全段是馬的處所水草飢飽鞍勒銜轡的照料規格，屬牲口養護不觸及人"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。**共 43 段：圖國第一 10、料敵第二 5、治兵第三 8、論將第四 5、應變第五 10、勵士第六 5。這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，**判 `[]` 的段落也要寫 `reason`**，至少要指出它在做的是戰法處置、訓練規格、敵情判斷，還是別的。
