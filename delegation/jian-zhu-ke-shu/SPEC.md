## 這部書是什麼

《諫逐客書》，秦李斯作，**全篇只有 4 段、一千餘字**，是一封上秦王的奏書。

背景是韓國水工鄭國以修渠為名間秦，事發後秦宗室大臣請求「一切逐客」（把所有外國來的人趕走），李斯本人也在被逐之列，因此上書力爭。

**這是一篇論辯文，不是一部書。**它的目的是說服秦王收回一道命令，通篇是舉例、對比、歸謬。

> **不要把同組其他法家書的判空比例搬過來當預期值。**體裁差異不是判準差異——判準完全一致，只是每部書的內容落在判準的哪一側本來就不同。**這一篇只有 4 段，比例本身不承載訊息，逐段照閘門判即可。**

## 通則性閘門

法家整部在講怎麼立法、怎麼用人、怎麼富國強兵，**每一段都在談人**——所以「有沒有提到人、客、民」完全不是判準。問：

> **這一段除了「該不該逐客／該怎麼用人／秦國該怎麼強大」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指**人是什麼樣的、人可以怎麼活、人有哪些品性、人與人之間如何、什麼樣的人該被怎麼對待**。

操作上最好用的一條分界：

> **文本有沒有自己把「人是什麼樣的／人該被怎麼看待」當成依據說出來？**
> 說了 → 命中。
> 只陳述事件經過或政策利弊，不觸及人本身 → 判空。

## 逐段提示

本篇只有 4 段，四段各有明確的性質，逐段說明如下。

### [1]——背景敘事

「會韓人鄭國來間秦，以作注溉渠，已而覺。秦宗室大臣皆言秦王曰：『諸侯人來事秦者，大抵為其主游間於秦耳。請一切逐客！』李斯議亦在逐中。」

**這一段是編者交代的事件背景**：誰做了什麼、於是誰提議什麼、李斯也在名單裡。

用敘事體的閘門問：**把這一則刪掉，讀者少知道了什麼？**

- 少的是**史料事實**（哪一年誰間秦、誰提議逐客）→ `[]`
- 少的是**對人的看法** → 給領域

**這一段預期判 `[]`，mode 走 `narrative`。**

**但有一句要單獨想過**：「諸侯人來事秦者，**大抵為其主游間於秦耳**」——這是宗室大臣對「外來的人」下的整體判斷，**是一句明確的群體歸因**。若你判定這句承重（文本記下了一種以出身斷定動機的看法），可以命中 **V**（我群他群與偏見）。**兩種判法都可以接受，`reason` 要說清楚你依據原文哪一句。**

### [2]——四君用客的史例

穆公西取由余於戎、東得百里奚於宛、迎蹇叔於宋、求丕豹公孫支於晉，「此五子者，**不產于秦**，而穆公用之，并國二十」；孝公用商鞅、惠王用張儀、昭王得范雎；「此四君者，皆以客之功。由此觀之，**客何負於秦哉**？」

**這一段在論證「一個人的出身與他的用處無關」**，並且反問「客何負於秦哉」。

→ **V**（我群他群與偏見）或 **VIII**（才能發揮與任用），可併。mode 兼有 `narrative`（大量具體人名與事件）與 `proposition`。

### [3]——器物與人的對比，全篇最尖銳的一段

崑山之玉、隨和之寶、明月之珠、太阿之劍、纖離之馬、翠鳳之旗、靈鼉之鼓「此數寶者，秦不生一焉，而陛下說之」；鄭衛之女不充後宮、趙女不立於側；擊甕叩缶彈箏搏髀「真秦之聲也」，鄭衛桑間韶虞武象「異國之樂也」，而秦王取異國之樂棄秦聲。

然後歸結：

> 「今取人則不然：不問可否，不論曲直，非秦者去，為客者逐。然則是所重者，**在乎色、樂、珠、玉，而所輕者在乎人民也**。」

**這是全篇最明確的命中段**：它指出同一個人對物與對人用了兩套標準，明說輕重顛倒。

→ **V**（我群他群與偏見、公義），**必須命中**。可併 **VIII**（若你判定「不問可否，不論曲直」的任用標準那一半承重）。

**注意兩件事**：

- **前半的珍寶、女子、音樂清單很長，但那不是 `formalization`。**它是排比舉例，不是可執行的程序或編制表。**不要因為它排成一長串就給 `formalization`。**
- **「鄭衛之女」「趙女不立於側」不要反射填 III。**這裡的女子與珠玉、駿馬並列，是被當成器物在論；文本沒有在談愛或親密。

### [4]——泰山不讓土壤

「臣聞地廣者粟多，國大者人衆，兵疆者則士勇；是以**泰山不讓土壤，故能成其大；河海不擇細流，故能就其深；王者不卻衆庶，故能明其德**；是以**地無四方，民無異國**，四時充美，鬼神降福，此五帝三王之所以無敵也。」

＋「今乃棄黔首以資敵國，卻賓客以業諸侯，使天下之士，退而不敢西向，裹足不入秦，此所謂**藉寇兵而齎盜糧**者也」＋「夫物不產於秦，可寶者多；士不產於秦，而願忠者衆」。

**「地無四方，民無異國」是把「不分內外」立成一條原則**，不只是說逐客划不來。

→ **V**（我群他群與偏見、歸屬），**必須命中**。可併 **VII**（若你判定「明其德」那一句在論德性本身）。

**「鬼神降福」不要給 XII。**那是論政修辭裡的一個成語式子句，本篇沒有在處理人與神聖的關係。

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、編制表、器械規格、數量比例、綱目分類表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本篇不會用到** |

要點：

- **[1] 走 `narrative`**（有人物有事件經過）
- **[2] 兼有 `narrative` 與 `proposition`**（大量具體人名事件，但用來支撐一個論斷）
- **[3][4] 主導是 `proposition`**
- **`expression` 要單獨想過。**[2][4] 開頭作「臣聞……」，是李斯以第一人稱上書。**若你判定全篇是奏書體而具第一人稱立場，可給 `expression`；但本篇主體是替國家利害立論而非抒發自身處境，預設不給。**給了要在 `reason` 說明
- **`formalization` 預期為零。**[3] 的珍寶清單是排比舉例，不是編制表或程序
- **`ritual` 預期為零**
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **`reason` 裡寫的話必須在原文找得到。**不可以替原文補上它沒說的東西，也不可以用你對李斯、秦始皇、鄭國渠或後來李斯下場的既有知識去補。判斷依據只有你眼前這一段的文字。
4. **不要更動 `chapter` 與 `para_index`**。本篇只有一章，章名逐字照抄為「諫逐客書」，`para_index` 為 1–4。**回報時章名與 para_index 兩者都要給。**
5. **不要判斷這篇奏書的主張對不對，也不要評價它的說服技巧。**你的工作是記錄這一段在做什麼。
6. **不要因為只有 4 段就草率。**段數少不代表判讀可以粗，每一段都照閘門走一次。
7. 原文有異體字（「疆」作「強」、「內」作「納」）與費解處，那是傳世本實況。**看不懂的句子不要硬掰內容，判空並在 `reason` 說明文意不明。**

## 輸出格式

寫到 `delegation/jian-zhu-ke-shu/out/b01.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "諫逐客書", "para_index": 3, "domains": ["V"], "modes": ["proposition"],
     "reason": "明說所重者在乎色樂珠玉而所輕者在乎人民，指出對物與對人用了兩套標準"},
    {"chapter": "諫逐客書", "para_index": 1, "domains": [], "modes": ["narrative"],
     "reason": "只交代鄭國間秦事發、宗室請逐客、李斯在逐中的事件經過"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。**共 4 段，全部在「諫逐客書」一章內，`para_index` 1 到 4。這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，**判 `[]` 的段落也要寫 `reason`**。
