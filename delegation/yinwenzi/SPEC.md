### 反錨定（先讀這一句再往下讀）

> **不要把其他書的判空比例搬過來當預期值。**管子 24%、九章算術 99.9%、列女傳 4%，**體裁差異不是判準差異**。這一部該是多少，讀完再說。也不要用〈大道上〉的比例推〈大道下〉——這兩篇的內容重心完全不同。

### 關於注文

**本書無系統性注文層**（全書僅 17 個 `〈 〉` 標記，集中在〈佚文〉的出處註記）。判讀就是讀正文，不必做正文／注文分層。同批發包的公孫龍子（謝希深注）與鬻子（逢行珪注）有這一層，本書沒有，**不要把那兩部的兩層讀法搬過來**。

## 一、通則性閘門：§2.6「怎麼治之外」

本書大半在講怎麼定名分、怎麼用法術權勢、怎麼賞罰。**每一段都在談人**——「有沒有提到民、君、賞罰」不是判準。問：

> **這一段除了「該立什麼法／怎麼賞罰／官怎麼設、令怎麼下／名分怎麼定」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

操作判準只有一句：

> **文本有沒有自己把「人是什麼樣的」當成依據說出來？**
> 說了 → 命中。
> 只給「做 A 則得 B」的政策鏈、名法分類綱目、制度條文，不解釋人為何如此 → 判空。

**工具性動機不能拿來當判空理由**：段落的用意百分之百是要君主拿去用，只要它確實斷言了人是什麼樣的，就命中。〈大道下〉[13]「凡人富，則不羨爵祿；貧，則不畏刑罰」整句是為了推出「貧富皆由於君」這個政策，但它先斷言了人在貧富兩端的反應機制——命中。

### §2.6 第④點（本書用得上，強制動作）

> **主體判空的段落若有一句說出人的樣態，就照那一句判。**

**凡條列體、綱目體、問答體或名法術語密集的段落，判空之前先逐句掃一次**，找有沒有「某種條件 → 人的品行／知覺／好惡」這一型的斷言句。有就照那一句給領域，不管整段其餘部分有多少名法術語。

## 二、本書最大的硬撈風險：形名之辨不是領域 II

領域 II 的定義寫著「自我與認同（**含名與實**）」。〈大道上〉前半整片在講「名以檢形」「形以定名」，看到就會很想填 II。**那是錯的。**

> **II 的「名與實」指的是「一個人的名聲 vs 他實際的品格」。純形名理論講的是語言指稱——一個詞怎麼指到一個東西。**

套 §2.1 中性物件替換測試：〈大道上〉[11]「好牛／好馬／好人」把「牛」換成任何東西，論證一字不改照樣成立 → **場景不承重 → 判 `[]` ＋ `proposition`。**

### 但本書大量出現「名實掛到人身上」——那一線要切準

**唯一命中的情況是名實被掛到人身上**：名聲、賢愚評價、賞罰依據、人君用人。**「名以檢形」若落到「以名責實、循名課能」用在臣下身上，那是 V（群體·社會·公義）或 VII（善惡·良心·品格），不是純邏輯。**

## 三、敘事段照 §2.2 的刪除閘門判

本書有大量寓言與史事：狐假虎威、齊桓好紫、楚莊愛細腰、晉文以儉矯奢、越王軾怒蛙、宣王好射、黃公二女、楚人賣山雉與魏田父得寶玉、宋襄公泓之戰、齊桓公子糾之爭、晉文出亡、孔丘誅少正卯、莊里丈人字子曰盜、鄭人謂玉未理者為璞、田子彭蒙宋子論聖人與聖法。

**這些不適用中性物件替換測試**，改問：

> **把這一則刪掉，讀者少知道了什麼？**
> 少的是史料事實（誰在哪年做了什麼）→ `[]`。
> 少的是對人的看法（人可以怎麼活、該怎麼被評價）→ 給領域。

**不要因為整部書偏名法就把敘事段一併判空。**〈大道上〉[26][27] 齊桓好紫與越王軾怒蛙少掉的是「上之所好會把整國人的行為帶著走」這個對人的判斷，不是史料。〈大道上〉[39][40][41] 宋襄公、公子糾、晉文公三則連著 [42] 一起讀——[42]「己是而舉世非之，則不知己之是」才是那三則的收束。

敘事段 `modes` 必含 `narrative`。

## 四、〈佚文〉17 段：斷片，逐段判，不要因為短就判空也不要因為短就湊

每段末尾 `〈 〉` 內是輯佚出處（《意林二》《太平御覽四〇二》等）。**出處標記不承載任何東西，不影響判讀。**

- **預期判空側**：[5][6] 感官比較、[7] 數名十百千萬億、[8]「千人曰俊，萬人曰傑」名目定義、[15]「四方上下曰宇」定義、[16] 將戰讀誥誓三令五申（軍禮程序，`ritual`／`formalization`）
- **預期命中側**：[3]「聞譽則悅，聞毀則戚，此眾人之大情；同己則喜，異己則怒」直說人的大情、[4] 田子「人皆自為，而不能為人」是把人性當使人的依據、[17] 鐘鼓之聲隨擊者之意而變「意誠，感之達於金石，而況於人乎」
- **[11][12] 堯衣不重帛、堯德化布於四海**：走刪除閘門。若只是登錄一件史事 → `[]`；若那一句本身在立一種人該怎麼活的標準 → 給領域。**判不出來就判空並在 `reason` 說明。**

## 五、〈大道下〉是本書社會觀察最密的一區

[15]–[19] 五段連著談貧賤與富貴：「貧則怨人，賤則怨時，而莫有自怨者，此人情之大趣也」「人貧則怨人，富則驕人……驕人者……弗可恕矣」「眾人見貧賤，則慢而疏之；見富貴，則敬而親之……故謂之大惑焉」「窮獨貧賤，治世之所共矜，亂世之所共侮」「萬民之望人君，亦如貧賤之望富貴」。

**這一區是全書把「人是什麼樣的」說得最直白的地方，預期高命中。**不要因為它結在「為人君不可弗與民同勞逸」這個治術結論上就整段判空——那正是第①點說的「工具性動機不能拿來當判空理由」。

同區的判空側：[1] 仁義禮樂名法刑賞八術對照表（`formalization`）、[2] 國之六徵條列（`formalization`）、[3] 先誅者非盜非姦（治術）、[7] 以名法治國以權術用兵（治術）。

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、制度表、數量比例、綱目分類表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | **本書不會用到** |

要點：

- **`formalization` 給名有三科法有四呈、國之六徵、八術對照表這一型的綱目**，不要迴避
- **`narrative` 給寓言與史事段**（見第三節清單）
- **`expression` 只給引號內的第一人稱話語**（〈序〉「余黃初本始到京師……意甚玩之」），第三人稱論述一律不算
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**。負面結果本身是資料。
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **`reason` 裡寫的話必須在原文找得到。**不可以用你對尹文、稷下學派、名家的既有知識去補。判斷依據只有你眼前這一段的文字。
4. **不要更動 `chapter` 與 `para_index`**。章名逐字照抄。`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。
5. **不要判斷書中的政治主張對不對，也不要評價它的道德立場。**
6. 原文有訛字、異體與費解處，那是傳世本實況。**看不懂的句子不要硬掰內容，判空並在 `reason` 說明文意不明。**
7. **判空之前先逐句掃一次**（§2.6 第④點）：條列體與名法術語密集的段落會蓋掉夾在中間的那一句人性斷言。
8. **直接執行，不要先提出計畫徵求確認。**這是非互動式呼叫，你回問就等於整批白做。
9. **本次交付物就是那個 .json 檔本身。**寫完後把該檔讀回來確認存在且 rows 數正確，然後停止。不要做任何 git 操作。
10. **你唯一可以建立或修改的檔案是 `delegation/yinwenzi/out/<本批>.json`**。

## 輸出格式

寫到 `delegation/yinwenzi/out/bNN.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "大道上", "para_index": 6, "domains": [], "modes": ["formalization"],
     "reason": "名有三科、法有四呈的分類綱目，只列名法的種類，未斷言人是什麼樣的"},
    {"chapter": "大道下", "para_index": 16, "domains": ["VII", "VI"], "modes": ["proposition"],
     "reason": "「人貧則怨人，富則驕人」直說兩種人情，並判怨可恕而驕不可恕，是對品格的明確主張"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。**每批的章與段數見該批 `.md` 檔開頭的標題行，以及 `delegation/yinwenzi/MANIFEST.json`。缺漏會整批退回。

`reason` 一句話即可，**判 `[]` 的段落也要寫 `reason`**。
