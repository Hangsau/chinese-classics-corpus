| 1 | 「孔子北遊於農山，子路子貢顏淵侍側。孔子四望，喟然而嘆曰：」；「於斯致思，無所不至矣。二三子各言爾志，吾將擇焉。」 |
| 2 | 「由願得白羽若月，赤羽若日；鐘鼓之音，上震於天；旍旗繽紛，下蟠於地。由當一隊而敵之，必也，攘地千里，搴旗執聝，唯由能之。使二子者從」；「子路進曰：」 |
| 3 | 「賜願使齊楚合戰於漭瀁之野，兩壘相望，塵埃相接，挺刃交兵；賜著縞衣白冠，陳說其間，推論利害，釋國之患，唯賜能之。使夫二子者從我焉。」；「子貢復進曰：」 |
| 4 | 「顏回退而不對。孔子曰：」；「回來，汝奚獨無願乎？」 |
| 5 | 「文武之事，則二子者，既言之矣。回何云焉？」；「顏回對曰：」 |
| 6 | 「雖然，各言爾誌也。小子言之。」；「孔子曰：」 |
| 7 | 「回聞燻蕕不同器而藏，堯桀不共國而治，以其類異也。回願得明王聖主輔相之，敷其五教。導之以禮樂，使民城郭不修，溝池不越。鑄劍戟以為農」；「對曰：」 |
| 8 | 「夫子凜然曰：」；「美哉！德也。」 |
| 9 | 「子路抗手而對曰：」；「夫子何選焉？」 |
| 10 | 「不傷財，不害民，不繁詞，則顏氏之子有矣。」；「孔子曰：」 |
| 11 | 「魯有儉嗇者，瓦鬲煮食，食之，自謂其美，盛之土型之器，以進孔子。孔子受之，歡然而悅，如受大牢之饋。」 |
| 12 | 「瓦甂，陋器也。煮食，薄膳也。夫子何喜之如此乎？」；「子路曰：」 |
| 13 | 「夫好諫者思其君，食美者念其親。吾非以饌具之為厚，以其食厚而我思焉。」；「子曰：」 |
| 14 | 「天暑市遠，無所鬻也，思慮棄之糞壤，不如獻之君子，故敢以進焉。」；「孔子之楚，而有漁者，而獻魚焉，孔子不受。漁者曰：」 |
| 15 | 「於是夫子再拜受之，使弟子掃地將以享祭。門人曰：」；「彼將棄之，而夫子以祭之。何也？」 |
| 16 | 「吾聞諸惜其腐餘，而欲以務施者，仁人之偶也。惡有受仁人之饋，而無祭者乎？」；「孔子曰：」 |
| 17 | 「季羔為衛之士師，刖人之足。俄而衛有蒯聵之亂，季羔逃之，走郭門。刖者守門焉，謂季羔曰：」；「彼有缺。」 |
| 18 | 「君子不隧。」；「季羔曰：」 |
| 19 | 「吾不能虧主之法，而親刖子之足矣。今吾在難，此正子之報怨之時，而逃我者三。何故哉？」；「季羔乃入焉。既而追者罷，季羔將去，謂刖者：」 |
| 20 | 「斷足固我之罪，無可奈何。曩者君治臣以法令，先人後臣，欲臣之免也。臣知獄決罪定，臨當論刑，君愀然不樂，見君顏色，臣又知之，君豈私臣」；「刖者曰：」 |
| 21 | 「善哉，為吏，其用法一也。思仁恕則樹德，加嚴暴則樹怨。公以行之，其子羔乎？」；「孔子聞之曰：」 |
| 22 | 「季孫之賜我粟千鐘也，而交益親。自南宮敬叔之乘我車也，而道加行。故道雖貴，必有時而後重，有勢而後行。微夫二子之貺財，則丘之道，殆將」；「孔子曰：」 |
| 23 | 「王者有似乎春秋，文王以王季為父，以太任為母，以太姒為妃，以武王、周公為子，以太顛、閎天為臣，其本美矣。武王正其身以正其國，正其國」；「孔子曰：」 |
| 24 | 「入是國也：言信於群臣，而留可也；見忠於卿大夫，則仕可也；澤施於百姓，則富可也。」；「曾子曰：」 |
| 25 | 「參之言此可謂善安身矣。」；「孔子曰：」 |
| 26 | 「子路為蒲宰。為水備，與其民修溝瀆。以民之勞煩苦也，人與之一簞食、一壺漿。孔子聞之，使子貢止之。」 |
| 27 | 「由也以暴雨將至，恐有水災，故與民修溝洫以備之；而民多匱餓者，是以簞食壺漿而與之。夫子使賜止之，是夫子止由之行仁也。夫子以仁教而禁」；「子路忿不悅，見孔子，曰：」 |
| 28 | 「汝以民為餓也，何不白於君，發倉廩以賑之？而私以爾食饋之，是汝明君之無惠，而見己之德美矣。汝速已則可，不則汝之見罪必矣。」；「孔子曰：」 |
| 29 | 「子路問於孔子曰：」；「管仲之為人何如？」 |
| 30 | 「仁也。」；「子曰：」 |
| 31 | 「昔管仲說襄公，公不受，是不辯也；欲立公子糾而不能，是不智也；家殘於齊，而無憂色，是不慈也；桎梏而居檻車，無慚心，是無醜也；事所射」；「子路曰：」 |
| 32 | 「管仲說襄公，襄公不受，公之闇也；欲立子糾而不能，不遇時也；家殘於齊而無憂色，是知權命也；桎梏而無慚心，自裁審也；事所射之君，通於」；「孔子曰：」 |
| 33 | 「孔子適齊，中路聞哭者之聲，其音甚哀。孔子謂其僕曰：」；「此哭哀則哀矣，然非喪者之哀矣。」 |
| 34 | 「驅而前，少進，見有異人焉，擁鐮帶素，哭者不哀。孔子下車，追而問曰：」；「子何人也？」 |
| 35 | 「子今非喪之所，奚哭之悲也？」；「曰：」 |
| 36 | 「吾有三失，晚而自覺，悔之何及？」；「丘吾子曰：」 |
| 37 | 「三失可得聞乎？願子告吾，無隱也。」；「曰：」 |
| 38 | 「吾少時好學，周遍天下，後還喪吾親，是一失也；長事齊君，君驕奢失士，臣節不遂，是二失也；吾平生厚交，而今皆離絕，是三失也。夫樹欲靜」；「遂投水而死。」 |
| 39 | 「自是弟子辭歸養親者，十有三。」；「小子識之，斯足為戒矣。」 |
| 40 | 「鯉乎，吾聞可以與人終日不倦者，其唯學焉。其容體不足觀也，其勇力不足憚也，其先祖不足稱也，其族姓不足道也。終而有大名，以顯聞四方，」；「孔子謂伯魚曰：」 |
| 41 | 「負重涉遠，不擇地而休；家貧親老，不擇祿而仕。昔者由也，事二親之時，常食藜藿之實，為親負米百里之外。親歿之後，南遊於楚。從車百乘，」；「子路見於孔子曰：」 |
| 42 | 「由也事親，可謂生事盡力，死事盡思者也。」；「孔子曰：」 |
| 43 | 「孔子之郯。遭程子於塗，傾蓋而語。終日，甚相親。顧謂子路曰：」；「取束帛以贈先生。」 |
| 44 | 「由聞之：士不中間見，女嫁無媒，君子不以交禮也。」；「有間，又顧謂子路。子路又對如初。」 |
| 45 | 「今程子，天下賢士也。於斯不贈，則終身弗能見也。小子行之。」；「有美一人，清揚宛兮。邂逅相遇，適我願兮。」 |
| 46 | 「孔子自衛反魯，息駕於河梁而觀焉。有懸水三十仞，圜流九十里，魚鱉不能導，黿鼉不能居。有一丈夫方將厲之，孔子使人並涯止之曰：」；「此懸水三十仞，圜流九十里，魚鱉黿鼉不能居也，意者難可濟也。」 |
| 47 | 「丈夫不以措意，遂渡而出。」 |
| 48 | 「子乎有道術乎？所以能入而出者，何也？」；「孔子問之，曰：」 |
| 49 | 「始吾之入也，先以忠信；及吾之出也，又從以忠信。忠信措吾軀於波流，而吾不敢以用私，所以能入而復出也。」；「丈夫對曰：」 |
| 50 | 「二三子識之，水且猶可以忠信成身親之，而況於人乎？」；「孔子謂弟子曰：」 |
| 51 | 「孔子將行，雨而無蓋。門人曰：」；「商也有之。」 |
| 52 | 「商之為人也，甚恡於財，吾聞與人交，推其長者，違其短者，故能久也。」；「孔子曰：」 |
| 53 | 「楚王渡江，江中有物大如斗，圓而赤，直觸王舟。舟人取之，王大怪之，遍問群臣，莫之能識。王使使聘於魯，問於孔子。子曰：」；「此所謂萍實者也。可剖而食也，吉祥也。唯霸者為能獲焉。」 |
| 54 | 「使者反，王遂食之，大美。久之使來以告魯大夫，大夫因子遊問曰：」；「夫子何以知其然乎？」 |
| 55 | 「楚王渡江得萍實，大如斗，赤如日，剖而食之甜如蜜。」；「吾昔之鄭，過乎陳之野，聞童謠曰：」 |
| 56 | 「死者有知乎？將無知乎？」；「子貢問於孔子曰：」 |
| 57 | 「吾欲言死之有知，將恐孝子順孫妨生以送死；吾欲言死之無知，將恐不孝之子棄其親而不葬。賜不欲知死者有知與無知。非今之急，後自知之。」；「子曰：」 |
| 58 | 「子貢問治民於孔子。子曰：」；「懍懍焉若持腐索之扞馬。」 |
| 59 | 「夫通達禦皆人也。以道導之，則吾畜也；不以道導之，則吾讎也。如之何其無畏也。」；「孔子曰：」 |
| 60 | 「魯國之法，贖人臣妾於諸侯者，皆取金於府。子貢贖之，辭而不取金。」 |
| 61 | 「賜失之矣。夫聖人之舉事也，可以移風易俗，而教導可以施之於百姓，非獨適身之行也。今魯國富者寡而貧者眾，贖人受金則為不廉，則何以相贖」；「孔子聞之曰：」 |
| 62 | 「子路治蒲，請見於孔子曰：」；「由願受教於夫子。」 |
| 63 | 「邑多壯士，又難治也。」；「對曰：」 |
| 64 | 「然，吾語爾。恭而敬，可以攝勇；寬而正，可以懷強；愛而恕，可以容困；溫而斷，可以抑奸。如此而加之，則正不難矣。」；「子曰：」 |
| 65 | 「君子有三恕，有君不能事，有臣而求其使，非恕也；有親不能孝，有子而求其報，非恕也；有兄不能敬，有弟而求其順，非恕也。士能明於三恕之」；「君子有三思，不可不察也。少而不學，長無能也；老而不教，死莫之思也；有而不施，窮莫之救也。故君子少思其長則務學，老思其死則務教，有」 |
| 66 | 「善哉子之問也。自丘之聞，未有若吾子所問辯且說也。丘嘗聞君子之言道矣，聽者無察，則道不入，奇偉不稽，則道不信。又嘗聞君子之言事矣，」；「騫固周國之賤吏也，不自以不肖，將北面以事君子，敢問正道宜行，不容於世，隱道宜行，然亦不忍，今欲身亦不窮，道亦不隱，為之有道乎？」 |
| 67 | 「聰明睿智，守之以愚；功被天下，守之以讓；勇力振世，守之以怯；富有四海，守之以謙。此所謂損之又損之之道也。」；「吾聞宥坐之器，虛則欹，中則正，滿則覆，明君以為至誡，故常置之於坐側。」 |
| 68 | 「以其不息，且遍與諸生而不為也。夫水似乎德，其流也則卑下，倨邑必修，其理似義；浩浩乎無屈盡之期，此似道；流行赴百仞之嵠而不懼，此似」；「孔子觀於東流之水。子貢問曰：」 |
| 69 | 「向也賜觀於太廟之堂，未既輟，還瞻北蓋，皆斷焉，彼將有說耶？匠過之也。」；「太廟之堂宮，致良工之匠，匠致良材，盡其功巧，蓋貴久矣，尚有說也。」 |
| 70 | 「吾有所齒，有所鄙，有所殆。夫幼而不能強學，老而無以教，吾恥之；去其鄉事君而達，卒遇故人，曾無舊言，吾鄙之；與小人處而不能親賢，吾」；「孔子曰：」 |
| 71 | 「子路出，子貢入，問亦如之。子貢對曰：」；「子貢出，顏回入，問亦如之。對曰：」 |
| 72 | 「鄙哉賜，汝不識也。昔者明王萬乘之國，有爭臣七人，則主無過舉；千乘之國，有爭臣五人，則社稷不危也；百乘之家，有爭臣三人，則祿位不替」；「子從父命孝，臣從君命貞乎？奚疑焉。」 |
| 73 | 「由誌之，吾告汝，奮於言者華，奮於行者伐，夫色智而有能者，小人也。故君子知之曰智，言之要也，不能曰不能，行之至也。言要則智，行至則」；「由是倨倨者何也？夫江始出於岷山，其源可以濫觴，及其至於江津，不舫舟不避風則不可以涉，非唯下流水多耶？今爾衣服既盛，顏色充盈，天下」 |
| 74 | 「國無道，隱之可也；國有道，則袞冕而執玉。」；「有人於此，披褐而懷玉，何如？」 |
| 75 | 「舜之為君也，其政好生而惡殺，其任授賢而替不肖，德若天地而靜虛，化若四時而變物，是以四海承風，暢於異類，鳳翔麟至，鳥獸馴德，無他也」；「以君之問不先其大者，故方思所以為對。」 |
| 76 | 「賢哉楚王！輕千乘之國，而重一言之信，匪申叔之信，不能達其義，匪莊王之賢，不能受其訓。」；「孔子讀史至楚復陳，喟然嘆曰：」 |
| 77 | 「以其離耶！在周易，山下有火謂之賁，非正色之卦也。夫質也黑白宜正焉，今得賁，非吾兆也。吾聞丹漆不文，白玉不雕，何也？質有餘不受飾故」；「吾於《甘棠》，見宗廟之敬甚矣，思其人必愛其樹，尊其人必敬其位，道也。」 |
| 78 | 「古之君子忠以為質，仁以為衛，不出環堵之室，而知千里之外，有不善則以忠化之，侵暴則以仁固之，何持劍乎？」；「子路戎服見於孔子，拔劍而舞之，曰：」 |
| 79 | 「孔子聞之，惜乎其不大也，不曰人遺弓，人得之而已，何必楚也。」；「楚王出遊，亡弓，左右請求之。王曰：」 |
| 80 | 「孔子為魯司寇，斷獄訟皆進眾議者而問之，曰：」；「皆曰云云如是，然後夫子曰：」 |
| 81 | 「臧氏家有守龜焉，名曰蔡，文仲三年而為一兆，武仲三年而為二兆，孺子容三年而為三兆，憑從此之見，若問三人之賢與不賢，所未敢識也。」；「君子哉漆雕氏之子，其言人之美也，隱而顯；言人之過也，微而著。智而不能及，明而不能見，孰克如此。」 |
| 82 | 「夫祭者，孝子所以自盡於其親，將祭而亡其牲，則其餘所亡者多矣。若此而不亡者，未之有也。」；「昔公索氏亡其祭牲，而夫子曰，不及二年必亡，今過期而亡，夫子何以知其然？」 |
| 83 | 「入其境則耕者讓畔，行者讓路；入其朝士讓為大夫，大夫讓於卿。虛芮之君曰：」；「以此觀之，文王之道，其不可加焉，不令而從，不教而聽，至矣哉。」 |
| 84 | 「狎甚則相簡，莊甚則不親，是故君子之狎足以交歡，其莊足以成禮。」；「二三子誌之，孰謂參也不知禮乎！」 |
| 85 | 「君胡然焉，衰麻苴杖者，誌不存乎樂，非耳弗聞，服使然也；黼黻袞冕者，容不襲慢，非性矜莊，服使然也；介胃執戈者，無退懦之氣，非體純猛」；「見長者而不盡其辭，雖有風雨，吾不能入其門矣。故君子以其所能敬人，小人反是。」 |
| 86 | 「君子以心導耳目，立義以為勇；小人以耳目導心，不愻以為勇。故曰退之而不怨，先之斯可從已。」；「孔子謂子路曰：」 |
| 87 | 「君子三患，未之聞，患不得聞；既得聞之，患弗得學；既得學之，患弗能行。有其德而無其言，君子恥之；有其言而無其行，君子恥之；既得之，」；「孔子曰：」 |
| 88 | 「魯人有獨處室者，鄰之嫠婦，亦獨處一室。夜暴風雨至，嫠婦室壞，趨而托焉，魯人閉戶而不納，嫠婦自牖與之言：」；「善哉！欲學柳下惠者，未有似於此者，期於至善而不襲其為，可謂智乎！」 |
| 89 | 「小辯害義，小言破道，關睢興於鳥而君子美之，取其雄雌之有別；鹿鳴興於獸，而君子大之，取其得食而相呼。若以鳥獸之名嫌之，固不可行也。」；「孔子曰：」 |
| 90 | 「能治國家之如此，雖欲侮之，豈可得乎？周自后稷積行累功，以有爵土，公劉重之以仁，及至大王亶甫，敦以德讓，其樹根置本，備豫遠矣。初，」；「為此詩者，其知政乎！夫為組者，總紕於此，成文於彼，言其動於近，行於遠也。執此法以禦民，豈不化乎！竿旄之忠告至矣哉！」 |

| 1 | 「吾聞老聃博古知今，通禮樂之原，明道德之歸，則吾師也。今將往矣。」；「孔子謂南宮敬叔曰：」 |
| 2 | 「臣受先臣之命。云孔子，聖人之後也。滅於宋，其祖弗父何，始有國而授厲公，及正考父佐戴武宣，三命茲益恭。故其鼎銘曰：」；「一命而僂，再命而傴，三命而俯，循墻而走，亦莫余敢侮，饘於是，粥於是，以餬其口，其恭儉也，若此。」 |
| 3 | 「與孔子車一乘，馬二疋，堅其侍御。敬叔與俱至周，問禮於老聃，訪樂於萇弘。歷郊社之所，考明堂之則，察廟朝之度。於是喟然曰：」；「吾乃今知周公之聖，與周之所以王也。」 |
| 4 | 「吾聞富貴者送人以財，仁者送人以言。吾雖不能富貴，而竊仁者之號，請送子以言乎？凡當今之士，聰明深察而近於死者，好譏議人者也；博辯閎」；「及去周，老子送之曰：」 |
| 5 | 「自周反魯，道彌尊矣。遠方弟子之進，蓋三千焉。」 |
| 6 | 「孔子觀乎明堂。睹四門墉有堯舜之容，桀紂之象；而各有善惡之狀，興廢之誡焉。又有周公相成王，抱之負斧扆，南面以朝諸侯之圖焉。孔子徘徊」；「此周之所以盛也。夫明鏡所以察形，往古者所以知今。人主不務襲跡於其所以安存，而忽怠所以危亡。是猶未有以異於卻走而欲求及前人也，豈不」 |
| 7 | 「古之慎言人也，戒之哉。無多言，多言多敗。無多事，多事多患。安樂必戒，無所行悔。勿謂何傷，其禍將長。勿謂何害，其禍將大。勿喟不聞，」；「孔子觀周，遂入太祖后稷之廟。廟堂右階之前，有金人焉，三緘其口，而銘其背曰：」 |
| 8 | 「小人識之，此言實而中，情而信。詩曰：」；「戰戰兢兢，如臨深淵，如履薄冰。」 |
| 9 | 「甚矣，道之於今難行也。吾比執道，而今委質以求當世之君而弗受也。道於今難行也。」；「孔子見老聃而問焉，曰：」 |
| 10 | 「夫說者流於辯，聽者亂於辭。如此二者，則道不可以忘也。」；「老子曰：」 |
| 11 | 「吾聞孔子之施教也，先之以詩書，而道之以孝悌；說之以仁義，觀之以禮樂；然後成之以文德。蓋入室升堂者，七十有餘人。其孰為賢？」；「衛將軍文子，問於子貢曰：」 |
| 12 | 「以吾子常與學賢者也，」；「。文子曰：」 |
| 13 | 「賢人無妄，知賢即難。故君子之言曰：」；「智莫難於知人。」 |
| 14 | 「若夫知賢莫不難，今吾子親遊焉，是以敢問。」；「文子曰：」 |
| 15 | 「夫子之門人蓋有三千就焉。賜有逮及焉，未逮及焉，故不得遍知以告也。」；「子貢曰：」 |
| 16 | 「吾子所及者，請問其行。」；「文子曰：」 |
| 17 | 「夫能夙興夜寐，諷誦崇禮；行不貳過，稱言不茍，是顏回之行也。孔子說之以詩曰：」；「媚茲一人，應侯慎德。永言孝思，孝思惟則。」 |
| 18 | 「若逢有德之君，世受顯命，不失厥名，以禦於天子，則王者之相也。在貧如客，使其臣如借。不遷怒，不深怨，不錄舊罪，是冉雍之行也。孔子論」；「有土之君子也，有眾使也，有刑用也，然後稱怒焉。」 |
| 19 | 「不畏強禦，不侮矜寡。其言循性，其都以富。材任治戎，是仲由之行也。孔子和之以文，說之以詩曰：」；「受小拱大拱，而為下國駿龐，荷天子之龍。不戁不悚，敷奏其勇。強乎武哉，文不勝其質。」 |
| 20 | 「好學則智，恤孤則惠。恭則近禮，勤則有繼。堯舜篤恭，以王天下。其稱之也，曰宜為國老。」；「恭老恤幼，不忘賓旅。好學博藝，省物而勤也，是冉求之行也。孔子因而語之曰：」 |
| 21 | 「二三子之欲學賓客之禮者，其於赤也。滿而不盈，實而如虛，過之如不及，先王難之。」；「齊莊而能肅，誌通而好禮。擯相兩君之事，篤雅有節，是公西赤之行也。子曰：」 |
| 22 | 「博無不學。其貌恭，其德敦。其言於人也，無所不信。其驕於人也，常以浩浩。是以眉壽，是曾參之行也。孔子曰：」；「孝，德之始也；悌，德之序也；信，德之厚也；忠，德之正也。參中夫四德者也，以此稱之。」 |
| 23 | 「其不伐，則猶可能也。其不弊百姓，則仁也。詩云：愷悌君子，民之父母。」；「美功不伐，貴位不善。不侮不佚不傲無告，是顓孫師之行也。孔子言之曰：」 |
| 24 | 「送迎必敬，上交下接若截焉，是卜商之行也。孔子說之以詩曰：」；「式夷式已，無小人殆。若商也，其可謂不險矣。」 |
| 25 | 「貴之不喜，賤之不怒。茍利於民矣，廉於行己。其事上也，以佑其下，是淡臺滅明之行也。孔子曰：」；「獨貴獨富，君子助之，夫也中之矣。」 |
| 26 | 「欲能則學，欲知則問，欲善則詳，欲給則豫。當是而行，偃也得之矣。」；「先成其慮，及事而用之；故動則不妄，是言偃之行也。孔子曰：」 |
| 27 | 「獨居思仁，公言仁義。其於詩也，則一日三覆，白圭之玷。是宮絳之行也。孔子信其能仁，以為異士。」 |
| 28 | 「自見孔子，出入於戶，未嘗越禮。往來過之，足不履影。啟蟄不殺，方長不折。執親之喪，未嘗見齒，是高柴之行也。孔子曰：」；「柴於親喪，則難能也，啟蟄不殺，則順人道。方長不折，則恕仁也。成湯恭而以恕，是以日隮。」 |
| 29 | 「凡此諸子，賜之所親睹者也。吾子有命而訊賜，賜也固不足以知賢。」 |
| 30 | 「吾聞之也，國有道則賢人興焉，中人用焉，乃百姓歸之。若吾子之論，既富茂矣。壹諸侯之相也，抑世未有明君，所以不遇也。」；「文子曰：」 |
| 31 | 「衛將軍文子問二三子之於賜，不壹而三焉。賜也辭不獲命，以所見者對矣，未知中否？請以告。」；「子貢既與衛將軍文子言，適魯見孔子曰：」 |
| 32 | 「子貢以其辭狀告孔子。子聞而笑曰：」；「賜，汝次焉人矣。」 |
| 33 | 「賜也，何敢知人？此以賜之所睹也。」；「子貢對曰：」 |
| 34 | 「吾亦語汝耳之所未聞，目之所未見者。豈思之所不至，智之所未及哉？」；「孔子然：」 |
| 35 | 「賜願得聞之。」；「子貢曰：」 |
| 36 | 「不克不忌，不念舊怨。蓋伯夷、叔齊之行也。」；「孔子曰：」 |
| 37 | 「思天而敬人，服義而行信。孝於父母，恭於兄弟。從善而不教，蓋趙文子之行也。」 |
| 38 | 「其事君也，不敢愛其死，然亦不敢忘其身。謀其身不遺其友。君陳則進而用之，不陳則行而退，蓋隨武子之行也。」 |
| 39 | 「其為人之淵源也，多聞而難誕，內植足以沒其世。國家有道，其言足以治。無道，其默足以生。蓋銅鍉伯華之行也。」 |
| 40 | 「外寬而內正，自極於隱括之中。直己而不直人。汲汲於仁，以善自終。蓋蘧伯玉之行也。」 |
| 41 | 「孝恭慈仁，允德義圖。約貨去怨，輕財不匱。蓋柳下惠之行也。」 |
| 42 | 「是故君擇臣而任之，臣亦擇君而事之。有道順命，無道衡命，蓋晏平仲之行也。」；「君雖不量於其身，臣不可以不忠於其君。」 |
| 43 | 「蹈忠而行信，終日言不在尤之內。國無道，處賤不悶，貧而能樂。蓋老子之行也。」 |
| 44 | 「易行以俟天命，居下不援其上。其親觀於四方也，不忘其親，不盡其樂。以不能則學，不為己終身之憂。蓋介子山之行也。」 |
| 45 | 「敢問夫子之所知者，蓋盡於此而已乎？」；「子貢曰：」 |
| 46 | 「其少也恭而順，心有恥而不使其過宿；其為大夫，悉善而謙其端。其為輿尉也，信而好直其功，言其功直。至於其為容也，溫良而好禮。博聞而時」；「何謂其然？亦略舉耳目之所及而矣。昔晉平公問祁奚曰：」 |
| 47 | 「請退而記之。」；「子貢跪曰：」 |
| 48 | 「當今之君，孰為最賢？」；「哀公問於孔子曰：」 |
| 49 | 「丘未之見也。抑有衛靈公乎？」；「孔子對曰：」 |
| 50 | 「吾聞其閨門之內無別，而子次之賢。何也？」；「公曰：」 |
| 51 | 「臣語其朝廷行事，不論其私家之際也。」；「孔子曰：」 |
| 52 | 「靈公之弟曰，靈公弟子渠牟，其智足以治千乘，其信足以守之，靈公愛而任之。又有士林國者，見賢必進之，而退與分其祿；是以靈公無遊放之士」；「其事何如？」 |
| 53 | 「今之人臣，孰為賢？」；「子貢問於孔子曰：」 |
| 54 | 「吾未識也，往者齊有鮑叔，鄭有子皮，則賢者矣。」；「子曰：」 |
| 55 | 「賜，汝徒知其一，未知其二也。汝聞用力為賢乎？進賢為賢乎？」；「齊無管仲，鄭無子產。」 |
| 56 | 「然。吾聞鮑叔達管仲，子皮達子產。未聞二子之達賢己之才者也。」；「子曰：」 |
| 57 | 「寡人聞忘之甚者，徙而忘其妻。有諸？」；「哀公問於孔子曰：」 |
| 58 | 「此猶未甚者也。甚者乃忘其身。」；「孔子對曰：」 |
| 59 | 「昔者夏桀，貴為天子，富有四海。忘其聖祖之道，壞其典法，廢其世祀。荒於淫樂，耽湎於酒。佞臣諂諛，窺導其心；忠士折口，逃罪不言。天下」；「孔子曰：」 |
| 60 | 「顏淵將西遊於宋，問於孔子曰：」；「何以為身？」 |
| 61 | 「恭敬忠信而已矣。恭則遠於患，敬則人愛之，忠則和於眾，信則人任之。勤斯四者，可以政國，豈特一身者哉？故夫不比於數，而比於踈，不亦遠」；「子曰：」 |
| 62 | 「彼不達之君子，豈不殆哉？從上依世，則道廢；違上離俗，則身危。時不興善，己獨由之，則曰非妖即妄也。故賢也既不遇天，恐不終其命焉。桀」；「孔子讀《詩》於《正月》六章，惕焉如懼。曰：」 |
| 63 | 「賢君治國，所先者何？」；「子路問於孔子曰：」 |
| 64 | 「在於尊賢而賤不肖。」；「孔子曰：」 |
| 65 | 「由聞晉中行氏尊賢而賤不肖矣，其亡何也？」；「子路曰：」 |
| 66 | 「中行氏尊賢而不能用，賤不肖而不能去，賢者知其不用而怨之，不肖者知其必己賤而讎之。怨讎並存於國，鄰敵構兵於郊。中行氏雖欲無亡，豈可」；「孔子曰：」 |
| 67 | 「向使銅鞮伯華無死，則天下其有定矣。」；「孔子閑處，喟然而嘆曰：」 |
| 68 | 「由願聞其人也。」；「子路曰：」 |
| 69 | 「其幼也敏而好學，其壯也有勇而不屈，其老也有道而能下人。有此三者，以定天下也。何難乎哉？」；「子曰：」 |
| 70 | 「幼而好學，壯而有勇，則可也。若夫有道下人，又誰下哉？」；「子路曰：」 |
| 71 | 「由不知。吾聞以眾攻寡，無不克也。以貴下賤，無不得也。昔者周公居冢宰之尊，制天下之政，而猶下白屋之士。日見百七十人，斯豈以無道也？」；「子曰：」 |
| 72 | 「齊景公來適魯，舍於公館。使晏嬰迎孔子，孔子至。景公問政焉。」 |
| 73 | 「孔子答曰：」；「政在節財。」 |
| 74 | 「秦穆公國小處僻而霸，何也？」；「公悅，又問曰：」 |
| 75 | 「其國雖小其志大，處雖僻而政其中。其舉也果，其謀也和。法無私而令不愉。首拔五羖，爵之大夫，與語三日而授之以政。此取之雖王可，其霸少」；「孔子曰：」 |
| 76 | 「政之急者，莫大乎使民富且壽也。」；「哀公問政於孔子。孔子對曰：」 |
| 77 | 「省力役，薄賦斂；則民富矣。敦禮教，遠罪疾；則民壽矣。」；「孔子曰：」 |
| 78 | 「寡人欲行夫子之言，恐吾國貧矣。」；「公曰：」 |
| 79 | 「未有子富而父母貧者也。」；「愷悌君子，民之父母。」 |
| 80 | 「有語寡人有國家者，計之於廟堂之上，則政治矣。何如？」；「衛靈公問於孔子曰：」 |
| 81 | 「其可也。愛人者則人愛之，惡人者則人惡之，知得之己者則知得之。人所謂」；「不出環堵之室而知天下」 |
| 82 | 「吾欲使長有國，而列都得之。吾欲使民無惑，吾欲使士竭力，吾欲使日月當時，吾欲使聖人自來，吾欲使官府治理。為之奈何？」；「孔子見宋君，君問孔子曰：」 |
| 83 | 「千乘之君，問丘者多矣。而未有若主君之問，問之悉也。然主君所欲者，盡可得也。丘聞之，鄰國相親，則長有國；君惠臣忠，則列都得之；不殺」；「孔子對曰：」 |
| 84 | 「善哉！豈不然乎？寡人不佞，不足以致之也。」；「宋君曰：」 |
| 85 | 「此事非難，唯欲行之云耳。」；「孔子曰：」 |
| 86 | 「三者之問一也，而夫子應之不同，然政在異端乎？」；「昔者齊君問政於夫子，夫子曰：」 |
| 87 | 「各因其事也。齊君為國，奢乎臺榭，淫於苑囿；五官伎樂，不解於時。一旦而賜人以千乘之家者三。故曰」；「。魯君有臣三人。內比周，以愚其君；外距諸侯之賓，以蔽其明。故曰」 |
| 88 | 「忠臣之諫君，有五義焉。一曰譎諫，二曰戇諫，三曰降諫，四曰直諫，五曰風諫。唯度主而行之，吾從其風諫乎？」；「孔子曰：」 |
| 89 | 「夫道不可不貴也。中行文子倍道失義，以亡其國；而能禮賢，以活其身。聖人轉禍為福，此謂是與？」；「子曰：」 |
| 90 | 「楚王將遊荊臺，司馬子祺諫，王怒之。令尹子西賀於殿下，諫曰：」；「今荊臺之觀，不可失也。」 |
| 91 | 「王喜拊子西之背曰：」；「與子共樂之矣。」 |
| 92 | 「子西步馬十里，引轡而止，曰：」；「臣願言有道，王肯聽之乎？」 |
| 93 | 「臣聞為人臣而忠其君者，爵祿不足以賞也；諛其君者，刑罰不足以誅也。夫子祺者，忠臣也；而臣者，諛臣也。願王賞忠而誅諛焉。」；「子西曰：」 |
| 94 | 「我今聽司馬之諫，是獨能禁我耳。若後世遊之，何也？」；「王曰：」 |
| 95 | 「禁後世易耳。大王萬歲之後，起山陵於荊臺之上。則子孫必不忍遊於父祖之墓，以為歡樂也。」；「子西曰：」 |
| 96 | 「至哉，子西之諫也。入之於千里之上，抑之於百世之後者也。」；「孔子聞之曰：」 |
| 97 | 「夫子之於子產、晏子，可為至矣。敢問二大夫之所為，目夫子之所以與之者。」；「子貢聞於孔子曰：」 |
| 98 | 「夫子產於民為惠主，於學為博物。晏子於君為忠臣，而行為恭敏。故吾皆以兄事之，而加愛敬。」；「孔子曰：」 |
| 99 | 「齊有一足之鳥，飛集於宮朝，下止於殿前，舒翅而跳。齊侯大怪之，使使聘魯，問孔子。」 |
| 100 | 「此鳥名曰商羊，水祥也。昔童兒有屈其一腳，振訊兩眉，而跳且謠曰：」；「今齊有之，其應至矣。」 |
| 101 | 「急告民趨治溝渠，修堤防，將有大水為災。頃之大霖雨，水溢泛諸國，傷害民人。唯齊有備，不敗。」 |
| 102 | 「聖人之言，信而征矣。」；「景公曰：」 |
| 103 | 「子治單父眾悅，子何施而得之也？子語丘所以為之者。」；「孔子謂宓子賤曰：」 |
| 104 | 「不齊之治也，父恤其子，其子恤諸孤，而哀喪紀。」；「對曰：」 |
| 105 | 「善小節也，小民附矣，猶未足也。」；「孔子曰：」 |
| 106 | 「不齊所父事者三人，所兄事者五人，所友事者十一人。」；「曰：」 |
| 107 | 「父事三人，可以教孝矣；兄事五人，可以教悌矣；友事十一人，可以舉善矣。中節也，中人附矣，猶未足也。」；「孔子曰：」 |
| 108 | 「此地民有賢於不齊者五人，不齊事之而稟度焉，皆教不齊之道。」；「曰：」 |
| 109 | 「其大者，乃於此乎？有矣。昔堯、舜聽天下，務求賢以自輔。夫賢者，百福之宗也，神明之主也。惜乎，不齊之以所治者，小也。」；「孔子嘆曰：」 |
| 110 | 「子貢為信陽宰，將行，辭於孔子。」 |
| 111 | 「勤之慎之。奉天子之時，無奪無伐，無暴無盜。」；「孔子曰：」 |
| 112 | 「賜也，少而事君子，豈以盜為累哉？」；「子貢曰：」 |
| 113 | 「汝未之詳也。夫以賢代賢，是謂之奪；以不肖代賢，是謂之伐；緩令急誅，是謂之暴；取善自與，謂之盜。盜非竊財之謂也。吾聞之：知為吏者，」；「孔子曰：」 |
| 114 | 「子路治蒲三年，孔子過之。」 |
| 115 | 「善哉，由也。恭敬以信矣。」；「入其境，曰：」 |
| 116 | 「善哉，由也。忠信而寬矣。」；「入其邑，曰：」 |
| 117 | 「善哉，由也。明察以斷矣。」；「至其庭，曰：」 |
| 118 | 「夫子未見由之政，而三稱其善。其善可得聞乎？」；「子貢執轡而問曰：」 |
| 119 | 「吾見其政矣。入其境，田疇盡易，草萊甚辟，溝洫深治；此其恭敬以信，故其民盡力也。入其邑，墻屋完固，樹木甚茂；此其忠信以寬，故其民不」；「孔子曰：」 |
## 卷四

| 1 | 「行己有六本焉，然後為君子也。立身有義矣，而孝為本；喪紀有禮矣，而哀為本；戰陣有列矣，而勇為本；治政有理矣，而農為本；居國有道矣，」；「孔子曰：」 |
| 2 | 「良藥苦於口,而利於病；忠言逆於耳，而利於行。湯武以諤諤而昌，桀紂以唯唯而亡。君無爭臣，父無爭子，兄無爭弟，士無爭友；無其過者，未」；「君失之，臣得之。父失之，子得之。兄失之，弟得之。己失之，友得之。」 |
| 3 | 「吾聞君子賞功受賞。今吾言於齊君，君未之有行，而賜吾邑，其不知丘亦甚矣。」；「孔子見齊景公，公悅焉，請置廩丘之邑以為養。孔子辭而不受。入謂弟子曰：」 |
| 4 | 「孔子在齊，舍於外館，景公造焉。」 |
| 5 | 「賓主之辭既接，而左右白曰：」；「周使適至，言先王廟災。」 |
| 6 | 「此必釐王之廟。」；「孔子曰：」 |
| 7 | 「禍亦如之。夫釐王變文武之制，而作玄黃華麗之飾；宮室崇峻，輿馬奢侈；而弗可振也。故天殃所宜加其廟焉，以是占之為然。」；「皇皇上天，其命不忒。天之以善，必報其德。」 |
| 8 | 「天何不殃其身，而加罰其廟也？」；「公曰：」 |
| 9 | 「蓋以文、武故也。若殃其身，則文武之嗣，無乃殄平。故當殃其廟，以彰其過。」；「孔子曰：」 |
| 10 | 「所災者，釐王廟也。」；「俄頃，左右報曰：」 |
| 11 | 「善哉！聖人之智，過人遠矣。」；「景公驚起，再拜曰：」 |
| 12 | 「子夏三年之喪畢，見於孔子。」 |
| 13 | 「與之琴，使之弦。」；「子曰：」 |
| 14 | 「先王制禮，不敢不及。」；「侃侃而樂，作而曰：」 |
| 15 | 「閔子三年之喪畢，見於孔子。」 |
| 16 | 「與之琴，使之弦。」；「子曰：」 |
| 17 | 「先王制禮，弗敢過也。」；「切切而悲，作而曰：」 |
| 18 | 「閔子哀未盡，夫子曰：」；「。賜也惑，敢問之。」 |
| 19 | 「閔子哀未忘，能斷之以禮。子夏哀已盡，能引之及禮。雖均之君子，不亦可乎？」；「孔子曰：」 |
| 20 | 「無體之禮，敬也；無服之喪，哀也；無聲之樂，歡也。不言而信，不動而威，不施而仁。誌夫鐘之音：怒而擊之則武，憂而擊之則悲。其志變者，」；「孔子曰：」 |
| 21 | 「孔子見羅雀者所得，皆黃口小雀。」 |
| 22 | 「大雀獨不得，何也？」；「夫子問之曰：」 |
| 23 | 「大雀善驚而難得，黃口貪食而易得。黃口從大雀則不得，大雀從黃口亦不得。」；「羅者曰：」 |
| 24 | 「善驚以遠害，利食而忘患。自其心矣，而以所從為禍福。故君子慎其所從：以長者之慮，則有全身之階；隨小者之戇，而有危亡之敗也。」；「孔子顧謂弟子曰：」 |
| 25 | 「孔子讀《易》至於」；「，喟然而嘆。」 |
| 26 | 「子夏避席問曰：」；「夫子何嘆焉？」 |
| 27 | 「夫自損者，必有益之；自益者，必有決之。吾是以嘆也。」；「孔子曰：」 |
| 28 | 「然則學者不可以益乎？」；「子夏曰：」 |
| 29 | 「昔堯治天下之位，猶允恭以持之，克讓以接下。是以千歲而益盛，迄今而逾彰。夏桀昆吾，自滿而極，亢意而不節，斬刈黎民如草芥焉。天下討之」；「非道益之謂也。道彌益而身彌損。夫學者損其自多，以虛受人，故能成其滿博哉。天道成而必變。凡持滿而能久者，未嘗有也。故曰：」 |
| 30 | 「商請誌之，而終身奉行焉。」；「子夏曰：」 |
| 31 | 「請釋古之道，而行由之意可乎？」；「子路問於孔子曰：」 |
| 32 | 「不可。昔東夷之子，慕諸夏之禮，有女而寡，為內私婿，終身不嫁。嫁則不嫁矣，亦非貞節之義也。蒼梧嬈娶妻而美，讓與其兄。讓則讓矣，然非」；「子曰：」 |
| 33 | 「曾子耘瓜，誤斬其根。曾皙怒建大杖以擊其背，曾子仆地而不知人。」 |
| 34 | 「退而就房，援琴而歌，欲令曾皙而聞之，知其體康也。」；「向也，參得罪於大人。大人用力教，參得無疾乎？」 |
| 35 | 「孔子聞之而怒，告門弟子曰：」；「參來勿內。」 |
| 36 | 「曾參自以為無罪，使人請於孔子。」 |
| 37 | 「汝不聞乎？昔瞽瞍有子曰舜。舜之事瞽瞍：欲使之，未嘗不在於側；索而殺之，未嘗可得；小棰則待過，大杖則逃走。故瞽瞍不犯不父之罪，而舜」；「子曰：」 |
| 38 | 「遂造孔子而謝過。」；「曾參聞之曰：」 |
| 39 | 「荊公子行年十五，而攝荊相事。孔子聞之，使人往觀其為政焉。」 |
| 40 | 「視其朝清凈而少事。其堂上有五老焉，其廊下有二十壯士焉。」；「使者反曰：」 |
| 41 | 「合二十五人之智，以治天下，其固免矣。況荊乎？」；「孔子曰：」 |
| 42 | 「子夏問於孔子曰：」；「顏回之為人奚若？」 |
| 43 | 「回之信，賢於丘。」；「子曰：」 |
| 44 | 「子貢之為人奚若？」；「曰：」 |
| 45 | 「賜之敏，賢於丘。」；「子曰：」 |
| 46 | 「子路之為人奚若？」；「曰：」 |
| 47 | 「由之勇，賢於丘。」；「子曰：」 |
| 48 | 「子張之為人奚若？」；「曰：」 |
| 49 | 「師之莊，賢於丘。」；「子曰：」 |
| 50 | 「然則四子何為事先生？」；「子夏避席而問曰：」 |
| 51 | 「居，吾語汝。夫回能信，而不能反。賜能敏，而不能詘。由能勇，而不能怯。師能莊，而不能同。兼四子者之有以易，吾弗與也。此其所以事吾而」；「子曰：」 |
| 52 | 「孔子遊於泰山，見榮聲期。行乎郕之野，鹿裘帶索，瑟瑟而歌。」 |
| 53 | 「先生所以為樂者，何也？」；「孔子問曰：」 |
| 54 | 「吾樂甚多，而至者三。天生萬物，唯人為貴；吾既得為人，是一樂也。男女之別，男尊女卑，故人以男為貴；吾既得為男，是二樂也。人生有不見」；「期對曰：」 |
| 55 | 「善哉！能自寬者也。」；「孔子曰：」 |
| 56 | 「回有君子之道四焉：強於行義、弱於受諫、怵於待祿、慎於治身。史悵有男子之道三焉：不仕而敬上、不祀而敬鬼、直己而曲人。」；「孔子曰：」 |
| 57 | 「參昔常聞夫子三言，而未之能行也。夫子見人之一善，而忘其百非；是夫子之易事也。見人之有善，若己有之；是夫子之不爭也。聞善必躬行之，」；「曾子侍曰：」 |
| 58 | 「吾死之後，則商也日益，賜也日損。」；「孔子曰：」 |
| 59 | 「商也，好與賢己者處；賜也，好說不若己者。不知其子，視其父；不知其人，視其友；不知其君，視其所使；不知其地，視其草木。故曰：」；「與善人居，如入芝蘭之室，久而不聞其香；即與之化矣。與不善人居，如入鮑魚之肆，久而不聞其臭；亦與之化矣。」 |
| 60 | 「曾子從孔子之齊，齊景公以下卿之禮聘曾子，曾子固辭。」 |
| 61 | 「吾聞之君子遺人以財不若善言。今夫蘭本三年，湛之以鹿酳。既成噉之，則易之匹馬。非蘭之本性也，所以湛者美矣。願子詳其所湛者。夫君子居」；「將行，晏子送之曰：」 |
| 62 | 「晏子之言，君子哉。依賢者，固不困；依富者，固不窮。馬蚿斬足而復行，何也？以其輔之者眾。」；「孔子聞之曰：」 |
| 63 | 「與富貴而下人，何人不尊？以富貴而愛人，何人不親？發言不逆，可謂知言矣；言而眾向之，可謂知時矣。是故：以富而能富人者，欲貧不可得也」；「孔子曰：」 |
| 64 | 「中人之情也，有餘則侈，不足則儉，無禁則淫，無度則逸，從欲則敗。是故鞭樸之子，不從父之教；刑戮之民，不從君之令。此言疾之難忍，急之」；「孔子曰：」 |
| 65 | 「巧而好度，必攻；勇而好問，必勝；智而好謀，必成。以愚者反之。是以：非其人，告之弗聽；非其地，樹之弗生。得其人，如聚砂而雨之；非其」；「孔子曰：」 |
| 66 | 「舟非水，不行；水入舟，則沒。君非民，不治；民犯上，則傾。是故君子不可不嚴也，小人不可不整一也。」；「孔子曰：」 |
| 67 | 「庭不曠山，不直地。衣穰而提贄，精氣以問事君子之道，願夫子告之。」；「齊高庭問於孔子曰：」 |
| 68 | 「貞以幹之，敬以輔之；施仁無倦；見君子則舉之，見小人則退之。去汝惡心，而忠與之。效其行，修其禮；千里之外，親如兄弟。行不效，禮不修」；「孔子曰：」 |
| 69 | 「季桓子穿井，獲如玉缶，其中有羊焉。使使問孔子曰：」；「吾穿井於費，而於井中得一狗。何也？」 |
| 70 | 「丘之所聞者，羊也。丘聞之：木石之怪，夔蝄蜽；水之怪，龍罔象；土之怪，羵羊也。」；「孔子曰：」 |
| 71 | 「吳伐越，隳會稽，獲巨骨一節，專車焉。」 |
| 72 | 「吳子使來聘於魯，且問之孔子。命使者曰：」；「無以吾命也。」 |
| 73 | 「賓既將事，乃發幣於大夫及孔子。孔子爵之，既徹俎而燕客，執骨而問曰：」；「敢問骨何如為大？」 |
| 74 | 「丘聞之昔禹致群臣於會稽之山，防風後至。禹殺而戮之，其骨專車焉。此為大矣。」；「孔子曰：」 |
| 75 | 「敢問誰守為神？」；「客曰：」 |
| 76 | 「山川之靈，足以紀綱天下者，其守為神。諸侯社稷之守，為公侯。山川之祀者，為諸侯，皆屬於王。」；「孔子曰：」 |
| 77 | 「汪芒氏之君守封嵎山者，為添姓。在虞夏商為汪芒氏，於周為長瞿氏，今曰大人。」；「孔子曰：」 |
| 78 | 「人長之極，幾何？」；「有客曰：」 |
| 79 | 「焦僥氏長三尺，短之至也。長者不過十，數之極也。」；「孔子曰：」 |
| 80 | 「孔子在陳，陳惠公賓之於上館。時有隼，集陳侯之庭而死。楛矢貫之石砮，其長尺有咫。惠公使人持隼如孔子館而問焉。」 |
| 81 | 「隼之來遠矣，此肅慎氏之矢。昔武王克商，信道於九夷百蠻。使各以其方賄來貢，而無忘職業。於是肅慎氏貢楛矢石砮，其長尺有咫。先王欲昭其」；「以分大姬，配胡公而封諸陳。古者：分同姓以珍玉，所以展親親也；分異姓以遠方之職貢，所以無忘服也。故分陳以肅慎氏貢焉。君若使有司求諸」 |
| 82 | 「少昊氏以鳥名官，何也？」；「郯子朝魯，魯人問曰：」 |
| 83 | 「吾祖也，我知之。昔黃帝以雲紀官，故為雲師而雲名。炎帝以火，共工以水，大昊以龍；其義一也。我高祖，少昊摯之立也。鳳鳥適至，是以紀之」；「對曰：」 |
| 84 | 「孔子聞之，遂見郯子而學焉。既而告人曰：」；「吾聞之天子失官，學在四夷猶信。」 |
| 85 | 「邾隱公朝於魯，子貢觀焉。邾子執玉，高其容仰；定公受玉，卑其容俯。」 |
| 86 | 「以禮觀之，二君者將有死亡焉。夫禮，生死存亡之體。將左右周旋，進退俯仰，於是乎取之；朝祀喪戎，於是乎觀之。今正月相朝，而皆不度，心」；「子貢曰：」 |
| 87 | 「夏五月，公薨，又邾子出奔。」 |
| 88 | 「賜不幸而言中，是賜多言。」；「孔子曰：」 |
| 89 | 「孔子在陳，陳侯就之燕遊焉。行路之人云：」；「所及者，其桓僖之廟。」 |
| 90 | 「禮祖有功而宗有德，故不毀其廟焉。今桓僖之親盡矣，又功德不足以存其廟，而魯不毀，是以天災加之。」；「子曰：」 |
| 91 | 「三日，魯使至。問焉，則桓、僖也。陳侯謂子貢曰：」；「吾乃今知聖人之可貴。」 |
| 92 | 「君之知之可矣。未若專其道，而行其化之善也。」；「對曰：」 |
| 93 | 「陽虎既奔齊，自齊奔晉，適趙氏。孔子聞之，謂子路曰：」；「趙氏其世有亂乎？」 |
| 94 | 「權不在焉，豈不為亂？」；「子路曰：」 |
| 95 | 「非汝所知。夫陽虎親富而不親仁，有寵於季孫；又將殺之，不克而奔；求容於齊，齊人囚之，乃亡，歸晉。是齊魯二國，已去其疾。趙簡子好利而」；「孔子曰：」 |
| 96 | 「今周十二月，夏之十月，而猶有螽，何也？」；「季康子問於孔子曰：」 |
| 97 | 「丘聞之火伏而後蟄者畢。今火猶西流，司歷過也。」；「孔子對曰：」 |
| 98 | 「所失者，幾月也？」；「季康子曰：」 |
| 99 | 「於夏十月，火既沒矣。今火見再，失閏也。」；「孔子曰：」 |
| 100 | 「王合諸侯，則伯率侯牧以見於王。伯合諸侯，則侯率子男以見於伯。今諸侯會，而君與寡君見晉君，則晉成為伯也。且執事以伯召諸侯，而以侯終」；「吳王夫差將與哀公見晉侯。子服景伯對使者曰：」 |
| 101 | 「魯將以十月上辛，有事於上帝，先王季辛而畢。何也，世有職焉，自襄已來之改之。若其不會，則祝宗將曰吳實然。」；「吳人乃止，既而悔之，遂囚景伯。伯謂大宰嚭曰：」 |
| 102 | 「子服氏之子拙於說矣。以實獲囚，以詐得免。」；「子貢聞之，見於孔子曰：」 |
| 103 | 「吳子為夷，德可欺而不可以實；是聽者之蔽，非說者之拙也。」；「孔子曰：」 |
| 104 | 「叔孫氏之車士曰子鉏商，采薪於大野。獲麟焉，折其前左足，載以歸，叔孫以為不祥，棄之於郭外。使人告孔子曰：」；「有麏而角者，何也？」 |
| 105 | 「麟也。胡為來哉？胡為來哉？」；「反袂拭面，涕泣沾衿。」 |
| 106 | 「夫子何泣爾？」；「子貢問曰：」 |
| 107 | 「麟之至，為明王也。出非其時而害，吾是以傷焉。」；「孔子曰：」 |
| 108 | 「文武之政，布在方策。其人存，則其政舉；其人亡，則其政息。天道敏生，人道敏政，地道敏樹。夫政者，猶蒲盧也。待化以成。故為政在於得人」；「孔子對曰：」 |
| 109 | 「子之言美矣、至矣。寡人實固，不足以成之也。」；「公曰：」 |
| 110 | 「好學近乎智，力行近乎仁，知恥近乎勇。知斯三者，則知所以修身；知所以修身，則知所以治人；知所以治人，則能成天下國家者矣。」；「孔子曰：」 |
| 111 | 「政其盡此而已乎？」；「公曰：」 |
| 112 | 「凡為天下國家有九經。曰：修身也、尊賢也、親親也、敬大臣也、體群臣也、子庶民也、來百工也、柔遠人也、懷諸侯也。夫修身則道立，尊賢則」；「孔子曰：」 |
| 113 | 「齊潔盛服，非禮不動，所以修身也；去讒遠色，賤財而貴德，所以尊賢也；爵其能，重其祿，同其好惡，所以篤親親也；官盛任使，所以敬大臣也」；「孔子曰：」 |
| 114 | 「子之教寡人備矣，敢問行之所始。」；「公曰：」 |
| 115 | 「立愛自親始，教民睦也；立敬自長始，教民順也。教之慈睦，而民貴有親；教以敬，而民貴用命。民既孝於親，又順以聽命，措諸天下無所不可。」；「孔子曰：」 |
| 116 | 「寡人既得聞此言也，懼不能果行而獲罪咎。」；「公曰：」 |
| 117 | 「吾聞鬼神之名，而不知所謂。敢問焉。」；「宰我問於孔子曰：」 |
| 118 | 「人生有氣、有魂。氣者，人之盛也。夫生必死，死必歸土，此謂鬼。魂氣歸天，此謂神。合鬼與神而享之，教之至也。骨肉弊於下，化為野土。其」；「則文王之謂與？祭之明日，明發不寐，有懷二人，敬而致之，又從而思之。祭之日樂與哀半，饗之必樂，已至必哀。孝子之情也，文王為能得之矣」 |

| 120 | 「遂還息於鄒，作盤琴以哀之。」 |
| 121 | 「有人於此，夙興夜寐，耕蕓樹藝，手足胼胝，以養其親。然而名不稱孝，何也？」；「子路問於孔子曰：」 |

| 123 | 「由，汝誌之，吾語汝。雖有國士之力，而不能自舉其身；非力之少，勢不可矣。夫內行不修，身之罪也；行修而名不彰，友之罪也。行修而名自立」；「孔子曰：」 |
| 124 | 「孔子遭厄於陳蔡之間，絕糧七日，弟子餒病，孔子弦歌。」 |
| 125 | 「夫子之歌，禮乎？」；「子路入見曰：」 |
| 126 | 「由，來，吾語汝。君子好樂，為無驕也；小人好樂，為無懾也。其誰之子，不我知而從我者乎？」；「孔子弗應，曲終而曰：」 |
| 127 | 「子路悅，援戚而舞，三終而出，明日免於厄。」 |
| 128 | 「二三子從夫子而遭此難也，其弗忘矣。」；「子貢執轡曰：」 |
| 129 | 「善。惡何也？夫陳蔡之間，丘之幸也。二三子從丘者，皆幸也。吾聞之：君不困，不成王；烈士不困，行不彰。庸知其非激憤厲志之始，於是乎在」；「孔子曰：」 |
| 130 | 「惡有修仁義而不免世俗之惡者乎？夫詩書之不講，禮樂之不習，是丘之過也。若以述先王，好古法而為咎者，則非丘之罪也。命之夫。歌，予和汝」；「孔子之宋，匡人簡子以甲士圍之。子路怒，奮戟將與戰。孔子止之曰：」 |
| 131 | 「子路彈琴而歌，孔子和之。曲三終，匡人解甲而罷。」 |
| 132 | 「不觀高崖，何以知顛墜之患？不臨深泉，何以知沒溺之患？不觀巨海，何以知風波之患？失之者，其在此乎？士慎此三者，則無累於身矣。」；「孔子曰：」 |
| 133 | 「賜既為人下矣，而未知為人下之道。敢問之。」；「子貢問於孔子曰：」 |
| 134 | 「為人下者，其猶土乎？汨之之深，則出泉。樹其壤則百穀滋焉，草木植焉，禽獸育焉。生則出焉，死則入焉。多其功而不意，弘其志而無不容。為」；「子曰：」 |
| 135 | 「東門外有一人焉，其長九尺有六寸，河目隆顙。其頭似堯，其頸似臯繇，其肩似子產。然自腰已下，不及禹者三寸。累然如喪家之狗。」；「孔子適鄭，與弟子相失，獨立東郭門外。或人謂子貢曰：」 |

| 155 | 「請問帝顓頊。」；「宰我曰：」 |
| 156 | 「五帝用說，三王有度。汝欲一日遍聞遠古之說，躁哉，予也。」；「孔子曰：」 |
| 157 | 「昔予也聞諸夫子曰：」；「小子毋或宿。」 |

| 159 | 「玄枵之孫，喬極之子，曰高辛。生而神異，自言其名。博施厚利，不於其身；聰以知遠，明以察微。仁以威，惠而信；以順天地之義。知民所急，」；「孔子曰：」 |
| 160 | 「高辛氏之子，曰陶唐。其仁如天，其智如神。就之如日，望之如雲。富而不驕，貴而能降。伯夷典禮，夔龍典樂。舜時而仕，趨視四時，務元民始」；「孔子曰：」 |
| 161 | 「喬牛之孫，瞽瞍之子也，曰有虞。舜孝友聞於四方，陶漁事親。寬裕而溫良，敦敏而知時。畏天而愛民，恤遠而親近。承受大命，依於二女，叡明」；「孔子曰：」 |
| 162 | 「高陽之孫，鯀之子也，曰夏后。敏給克齊，其德不爽。其仁可親，其吾可信。聲為律，身為度。亹亹穆穆，為紀為綱。其功為百神之主，其惠為民」；「孔子曰：」 |
| 163 | 「予！ 大者如天，小者如言，民悅至矣。予也，非其人也。」；「孔子曰：」 |
| 164 | 「予也不足以戒，敬承矣。」；「宰我曰：」 |
| 165 | 「吾欲以顏狀取人也，則於滅明改矣。吾欲以言辭取人也，則於宰我改之矣。吾欲以容貌取人也，則於子張改之矣。」；「他日，宰我以語子貢，子貢以復孔子。子曰：」 |
| 166 | 「宰我聞之，懼。弗敢見焉。」 |

| 1 | 「舊聞五帝之名，而不知其實。請問何謂五帝？」；「季康子問於孔子曰：」 |

| 23 | 「先王制法，使刑不上於大夫，禮不下於庶人。然則大夫犯罪，不可以加刑；庶人之行事，不可以治於禮乎？」；「冉有問於孔子曰：」 |

| 31 | 「成獄成於吏，吏以獄成告於正。正既聽之，乃告大司寇聽之。乃奉於王，王命三公卿士參聽棘木之下。然後乃以獄之成疑於王，王三宥之以聽命；」；「孔子曰：」 |
| 32 | 「巧言破律，遁名改作，執左道與亂政者。作淫聲，造異服，設伎奇器，以蕩上心者殺。行偽而堅，言詐而辯；學非而博，順非而澤；以惑眾者殺。」；「孔子曰：」 |

| 74 | 「不祥有五，而東益不與焉。夫損人自益，身之不祥；棄老而取幼，家之不祥；擇賢而任不肖，國之不祥；老者不教，幼者不學，俗之不祥；聖人伏」；「寡人聞東益不祥。信有之乎？」 |
| 75 | 「吾聞之：君取於臣，謂之取；與於臣，謂之賜；臣取於君，謂之假；與於君，謂之獻。」；「自今已後，君有取之，一切不得復言假也。」 |

| 1 | 「晉文公實召天子而使諸侯朝焉。夫子作《春秋》，云：」；「以臣召君，不可以訓，亦書其率諸侯事天子而已。」 |
| 2 | 「既死而議謚，謚定而卜葬，既葬而立廟。皆臣子之事，非所豫屬也。況自為之哉？」；「孔子在宋，見桓魋自為石槨，三年而不成，工匠皆病。夫子愀然曰：」 |
| 3 | 「南宮敬叔以富得罪於定公，奔衛。衛侯請復之，載其寶以朝。夫子聞之曰：」；「富而不好禮，殃也。敬叔以富喪矣，而又弗改，吾懼其將有後患也。」 |
| 4 | 「凶年則乘駑馬，力役不興，馳道不修。祈以幣玉，祭祀不懸，祀以下牲。此賢君自貶以救民之禮也。」；「孔子在齊，齊大旱，春饑。景公問於孔子曰：」 |
| 5 | 「夫禮，君子不有大故，則不宿於外。非致齊也，非疾也，則不晝處於內。是故夜居外，雖吊之，可也。晝居於內，雖問其疾，可也。」；「孔子適季氏，康子晝居內寢。孔子問其所疾。康子出見之。言終，孔子退。子貢問曰：」 |
| 6 | 「孔子為大司寇，國廄焚。子退朝而之火所，鄉人有自為火來者，則拜之，士一，大夫再。子貢曰：」；「其來者亦相吊之道也。吾為有司，故拜之。」 |
| 7 | 「管仲鏤簋而朱紘，旅樹而反坫，山節藻梲，賢大夫也，而難為上。晏平仲祀其先祖，而豚肩不揜豆，一狐裘三十年，賢大夫也，而難為下。君子上」；「管仲失於奢，晏子失於儉，與其俱失矣，二者孰賢？」 |
| 8 | 「昔臧文仲安知禮？夏父弗綦逆祀而不止，燔柴於竈以祀焉。夫竈者，老婦之所祭。盛於甕，尊於瓶，非所柴也。故曰禮也者，由體也。體不備，謂」；「昔文仲知魯國之政，立言垂法。於今不亡，可謂知禮矣？」 |
| 9 | 「凡謀人之軍，師敗則死之；謀人之國，邑危則亡之；古之正也。其君在焉者，有詔則無討。」；「臧武仲率師與邾人戰於狐鮐，遇敗焉，師人多喪而無罰。古之道然與？」 |
| 10 | 「晉將伐宋，使人覘之，宋陽門之介夫死，司城子罕哭之哀。覘之反言於晉侯曰：」；「子罕有焉。雖非晉國，其天下孰能當之？是以周任有言曰：」 |
| 11 | 「射之，斃一人，韔其弓。又及，棄疾謂之。又及，棄疾復謂之。斃二人。每斃一人，輒掩其目，止其御曰：」；「人臣之節，當君大事，唯力所及，死而後已。夫子何善此？」 |
| 12 | 「孔子許之，掘中溜而浴，毀竈而綴足，襲於床。及葬，毀宗而行也，出於大門，及墓，男子西面，婦人東面，既封而歸，殷道也。孔子行之。子遊」；「孔子在衛，司徒敬之卒，夫子弔焉。主人不哀，夫子哭不盡聲而退。璩伯玉請曰：」 |
| 13 | 「宣公八年六月辛巳，有事於太廟，而東門襄仲卒，壬午猶繹，子遊見其故，以問孔子曰：」；「非禮也，卿卒不繹。」 |
| 14 | 「季桓子喪，康子練而無衰。子遊問於孔子曰：」；「無衰衣者，不以見賓，何以除焉？」 |
| 15 | 「繼父同居者，則異父昆弟，從為之服；不同居，繼父且猶不服，況其子乎？」；「邾人以同母異父之昆弟死，將為之服，因顏克而問禮於孔子。子曰：」 |
| 16 | 「使之雖病，任之雖重，君子弗能謀，士弗能死，不可也。我則既言之矣，敢不勉乎？」；「與其鄰嬖童汪錡，乘？奔敵死焉。皆殯，魯人欲勿殤童汪錡，問於孔子曰：」 |
| 17 | 「魯昭公夫人吳孟子卒，不赴於諸侯。孔子既致仕，而吊焉。適於季氏，季氏不絰，孔子投絰而不拜。子遊問曰：」；「主人未成服，則吊者不絰焉，禮也。」 |
| 18 | 「公父穆伯之喪，敬姜晝哭；文伯之喪，晝夜哭。孔子曰：」；「季氏之婦，可謂知禮矣。愛而無上下有章。」 |
| 19 | 「南宮絳之妻，孔子兄之女，喪其姑而誨之髽曰：」；「蓋榛以為笄，長尺而總八寸。」 |
| 20 | 「拜而後啟顙，頹乎其順；啟顙而後拜，頎乎其至也。三年之喪，吾從其至也。」；「子張有父之喪，公明儀相焉，問啟顙於孔子。孔子曰：」 |
| 21 | 「夫子何善爾？其往也，如慕；其返也，如疑。」；「孔子在衛，衛之人有送葬者，而夫子觀之曰：」 |
| 22 | 「哀則哀矣，而難繼也。夫禮為可傳也，為可繼也。故哭踴有節，而變除有期。」；「卞人有母死而孺子之泣者，孔子曰：」 |
| 23 | 「孟獻子禫懸而不樂，可御而處內。子遊問於孔子曰：」；「獻子可謂加於人一等矣。」 |
| 24 | 「由，爾責於人終無已，夫三年之喪，亦以久矣。」；「魯人有朝祥而暮歌者，子路笑之。孔子曰：」 |
| 25 | 「啜菽飲水，盡其歡也，斯為之孝乎？斂手足形，旋葬而無槨，稱其財，為之禮，貧何傷乎？」；「傷哉，貧也。生而無以供養，死則無以為禮也。」 |
| 26 | 「其歛，以時服而已；其壙，掩坎深不至於泉；其葬，無盟器之贈。既葬，其封廣輪揜坎，其高可時隱也；既封，則季子乃左袒右還其封，且號者三」；「吳延陵季子聘於上國，適齊，於其返也，其長子死於嬴博之間。孔子聞之曰：」 |
| 27 | 「有也，則無過禮。茍亡矣，則歛手足形，還葬懸棺而封，人豈有非之者哉。故夫喪亡，與其哀不足而禮有餘，不若禮不足而哀有餘也；祭祀，與其」；「子遊問喪之具。孔子曰：」 |
| 28 | 「吾惡乎哭諸，兄弟吾哭諸廟，父之友吾哭諸廟門之外，師吾哭之寢，朋友吾哭之寢門之外，所知吾哭之諸野，今於野則已疏，於寖則已重，夫由賜」；「既哭，使子張往吊焉，未至，冉求在衛，攝束帛乘馬而以將之。孔子聞之曰：」 |
| 29 | 「行道之人皆弗忍，先王制禮，過之者俯而就之，不至者企而及之。」；「子路有姊之喪，可以除之矣，而弗除。孔子曰：」 |
| 30 | 「伯魚之喪母也，期而猶哭。夫子聞之曰：」；「嘻其甚也，非禮也。」 |
| 31 | 「固非禮也，夫上治祖禰以尊尊之，下治子孫以親親之，旁治昆弟所以教睦也，此先王不易之教也。」；「同姓為宗，有合族之義，故系之以姓而弗別，綴之以食而弗殊，雖百世婚姻不得通，周道然也。」 |
| 32 | 「皆有宗道焉，故雖國君之尊，猶百姓不廢其親，所以崇愛也。雖以族人之親，而不敢戚君，所以謙也。」；「國君之於百姓，如之何？」 |
| 33 | 「寢苫枕幹，不仕弗與共天下也。遇於朝市，不返兵而鬥。」；「仕，弗與同國，銜君命而使，雖遇之不鬥。」 |
| 34 | 「夏後氏之喪，三年既殯，而致仕，殷人既葬而致事，周人既卒哭而致事。記曰：」；「三年之喪既卒哭，金革之事無避，禮與，初有司為之乎？」 |
| 35 | 「昔者成王嗣立，幼未能蒞阼，周公攝政而治，抗世子之法於伯禽，欲王之知父子君臣之道，所以善成王也。夫知為人子者，然後可以為人父；知為」；「故父在斯為子，君在斯為臣，君子與臣之位，所以尊君而親親也。在學，學之為父子焉，學之為君臣焉，學之為長幼焉，父子君臣長幼之道得，而」 |
| 36 | 「伯母叔母，疏衰期而踴不絕地，姑姊妹之大功踴絕於地，若知此者，由文矣哉。」；「居處言語飲食衎爾於喪所，則稱其服而已。」 |
| 37 | 「豈徒祭而已哉。三年之喪，身有瘍則浴，首有瘡則沐，病則飲酒食肉，毀瘠而病，君子不為也，毀則死者，君子為之，無子則祭之，沐浴為齊潔也」；「凡喪小功已上，虞祔練祥之祭皆沐浴。於三年之喪，子則盡其情矣。」 |
| 38 | 「夫仁者制禮者也，故禮者不可不省也，禮不同不異，不豐不殺，稱其義以為之宜，故曰我戰則克，祭則受福，蓋得其道矣。」；「夫子曰，於我乎殯，敢問禮與？仁者之心與？」 |
| 39 | 「非禮也，從主人也。吾食於少施氏而飽，少施氏食我以禮，吾食祭，作而辭曰：」；「孔子食於季氏，食祭，主人不辭不食，亦不飲而餐，子夏問曰：」 |
| 40 | 「公許，管仲卒，桓公使為之官於大夫者為之服，自管仲始也，有君命焉。」；「官於大夫，既升於公，而反為之服，禮與？」 |
| 41 | 「敬為上，哀次之，瘠為下，顏色稱情，戚容稱服。」；「子貢問居父母喪。孔子曰：」 |
| 42 | 「反哭之吊也，喪之至也，反而亡矣，失之矣，於斯為甚，故吊之，死，人卒事也，殷以愨，吾從周。殷人既練之，明日，而祔於祖，周人既卒哭之」；「殷人既定而吊於壙，周人反哭而吊於家，如之何？」 |
| 43 | 「父母之喪，三日不怠，三月不解，期悲哀，三年憂，東夷之子，達於禮者也。」；「聞諸晏子，少連大連善居喪，其有異稱乎？」 |
| 44 | 「非禮也。古者男子外有傅父，內有慈母，君命所使教子者也，何服之有。昔魯孝公少喪其母，其慈母良，及其死也，公弗忍，欲喪之。有司曰：」；「禮，國君慈母無服，今也君為之服，是逆古之禮，而亂國法也。若終行之，則有司將書之，以示後世，無乃不可乎。」 |
| 45 | 「孔子適衛，遇舊館人之喪，入而哭之哀。出使子貢脫驂以贈之。子貢曰：」；「吾向入哭之，遇一哀而出涕，吾惡夫涕而無以將之，小子行焉。」 |
| 46 | 「子謂夫子而弗知之乎，夫子徒無所不知也，子問，非也，禮，居是邦則不非其大夫。」；「吾以為夫子無所不知，夫子亦徒有所不知也。」 |
| 47 | 「叔孫母叔之母死，既小歛，舉屍者出戶，武孫從之出戶，乃袒投其冠而括發。子路嘆之，孔子曰：」；「齊晏桓子卒，平仲麤衰斬苴絰帶，杖以菅屨，食粥居傍廬，寢苫枕草，其老曰：」 |
| 48 | 「送而以寶玉，是猶曝屍於中原也，其示民以奸利之端，而有害於死者，安用之。且孝子不順情以危親，忠臣不兆奸以陷君。」；「季平子卒，將以君之璵璠歛，贈以珠玉。孔子初為中都宰，聞之歷級而救焉，曰：」 |
| 49 | 「齊豹之盜，孟縶之賊也，汝何吊焉？君不食奸，不受亂，不為利病於回，不以回事人，不蓋非義，不犯非禮，汝何吊焉？」；「孔子之弟子琴張與宗友衛齊豹，見宗魯於公子孟縶，孟縶以為參乘焉，及齊豹將殺孟縶，告宗魯，使行。宗魯曰：」 |
| 50 | 「若是哭也，其野哉。孔子惡野哭者。」；「郕人子革卒，哭之呼滅。子遊曰：」 |
| 51 | 「吾聞好外者士死之，好內者女死之，今吾子早殀，吾惡其以好內聞也，二三婦人之欲供先祀者，請無瘠色，無揮涕，無拊膺，無哀容，無加服，有」；「女智無若婦，男智莫若夫，公文氏之婦智矣，剖情損禮，欲以明其子為令德也。」 |
| 52 | 「夫子哭之於中庭，有人吊者，而夫子拜之，已哭，進使者而問故，使者曰：」；「子路與子羔仕於衛，衛有蒯聵之難。孔子在魯，聞之曰：」 |
| 53 | 「今丘也，東西南北之人，不可以弗識也，吾見封之若堂者矣，又見若坊者矣，又見履夏屋者矣，又見若斧形者矣，吾從斧者焉。」；「於是封之，崇四尺。孔子先反虞，門人後。雨甚，至墓崩，修之而歸。孔子問焉，曰：」 |
| 54 | 「孔子有母之喪，既練，陽虎吊焉，私於孔子曰：」；「丘弗聞也。若聞之，雖在衰絰，亦欲與？。」 |
| 55 | 「凡在封內，皆臣子也，禮，君吊其臣，升自東階，向屍而哭，其恩賜之，施不有？也。」；「顏回死，魯定公吊焉，使人訪於孔子。孔子對曰：」 |
| 56 | 「之死而致死乎，不仁，不可為也；之死而致生乎，不智，不可為也。凡為盟器者，知喪道也。夫子始死則矣，羔裘玄冠者，易之而已，汝何疑焉。」；「夏後氏之送葬也，用盟器，示民無知也；殷人用祭器，示民有知也；周人兼而用之，示民疑也。」 |
| 57 | 「喪之朝也，順死者之孝心，故至於祖者，廟而後行。殷朝而後殯於祖，周朝而後遂葬。」；「重主道也，殷主綴重焉，周人徹重焉。請問喪朝。」 |
| 58 | 「路馬死，則藏之以帷，狗則藏之以蓋，汝？埋之。吾聞弊幃不棄，為埋馬也，弊蓋不棄，為埋狗也。今吾貧無蓋，於其封也與之席，無使其首陷於」；「孔子之守狗死，謂子貢曰：」 |
| 59 | 「大夫廢其事，終身不仕，死則葬之以士禮，老而政仕者，死則從其列。」；「大夫以罪免卒，其葬也如之何？」 |
| 60 | 「仲子亦猶行古人之道，昔者文王拾伯邑考，而立武王，微子舍其孫腯，立其弟衍。」；「公儀仲子嫡子死，而立其弟，檀弓問子服伯子曰：」 |
| 61 | 「吾聞之有備物而不可用也，是故竹不成用，而瓦不成膝，琴瑟張而不平，笙竽備而不和，有鐘磬而無簨？。其曰盟器，神明之也，哀哉，死者而用」；「自周公已來祔葬矣。故衛人之祔也，離之，有以聞焉；魯人之祔也，合之，美夫，吾從魯。」 |
| 62 | 「葬者塗車芻靈，自古有之，然今人或有偶，是無益於喪。」；「為芻靈者善矣，為偶者不仁，不殆於用人乎。」 |
| 63 | 「夫子之言祭也，濟濟漆漆焉，今夫子路為季氏宰，季氏祭逮昏而奠，終日不足，繼以燭，雖有強力之容，肅敬之心，皆倦怠矣。有司跛倚以臨，其」；「顏淵之喪既祥，顏路饋祥肉於孔子。孔子自出而受之，入彈琴以散情，而後乃食之。孔子嘗奉薦而進，其親也愨，其行也趨，趨以數。已祭，子貢」 |
