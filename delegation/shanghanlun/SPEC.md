# 發包 spec：傷寒論 段落級標註

## 你要做什麼

讀 `delegation/shanghanlun/bNN.md`，逐段判兩件事：

1. `domains`：這一段觸及哪些人生問題領域（下表 13 個 id，可以是空陣列）
2. `modes`：這一段用什麼方式說話（下表 8 個 id，可以是空陣列）

輸出寫成 `delegation/shanghanlun/out/bNN.json`，格式見文末。

## 這部書是什麼

《傷寒論》東漢張仲景撰、晉王叔和編次、宋林億校正。全書 22 篇，由四種東西混成：

| 體例 | 內容 | 預設 |
|---|---|---|
| 校序（林億校序 8 段） | 校書源流、進呈題名 | 多半 `[]` |
| **原序（張仲景原序 5 段）** | 作者自陳為何寫這部書 | **全書人的內容幾乎都在這裡，見下** |
| 辨脈法／平脈法／傷寒例 | 脈象與病候的分類定義 | 多半 `[]` |
| 各篇「辨某病脈證並治」 | 「某某之為病，脈某，某某者，某湯主之」＋方劑組成與服法 | **多半 `[]`，這是全書大宗** |

## 唯一的通則性閘門

> **這一段除了「這種病長什麼樣／該怎麼治」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

「說了關於人的什麼」指的是：人怎麼對待自己的身體與性命、人在病與死面前是什麼處境、人與人之間如何。**不是**指這一段提到了病、提到了死、提到了身體部位。

## 本書最大的硬撈風險：**「病」「死」「身」三個字遍布全書，但那不等於命中 IX 或 X**

「太陽之為病，脈浮，頭項強痛而惡寒」「傷寒六七日，結胸熱實，脈沉而緊，心下痛，按之石鞕者，大陷胸湯主之」「陽病見陰脈者死」——這一類是**病候辨識與治法指派**，全書數百段。它在做的事是把身體狀態編成可辨可治的類目，**病在這裡是技術的對象，不是人的處境**。一律 `[]`。

同理：

- 方劑組成（「桂枝三兩去皮、芍藥三兩、甘草二兩炙……」）→ `[]`
- 服法與禁忌（「右五味，㕮咀三味，以水七升，微火煮取三升，去滓，適寒溫，服一升」「禁生冷、黏滑、肉麵、五辛、酒酪、臭惡等物」）→ `[]`
- 預後判語（「期十七日當劇」「陰病見陽脈者生」）→ `[]`，那是判斷病程不是在談死亡
- 脈象比喻（「脈藹藹如車蓋者」「脈縈縈如蜘蛛絲者」）→ `[]`

**這是本批最容易整批做錯的方向。**

## 但反過來也要防：**不要因為「這是醫書」就整批判空**

本書有一小塊真的在講人，漏掉就等於沒讀。**張仲景原序是全書密度最高的地方**，五段裡幾乎每一段都有內容：

- 第 1 段指責當世之士「曾不留神醫藥……但競逐榮勢，企踵權豪，孜孜汲汲，惟名利是務」，直到「卒然遭邪風之氣，嬰非常之疾」才「降志屈節，欽望巫祝，告窮歸天，束手受敗」，末了說「不惜其命，若是輕生，彼何榮勢之云哉」——**這一段在講人怎麼對待自己的身體與性命，以及把一生押在名利上值不值得。**這不是病候
- 第 2 段「余宗族素多，向餘二百。建安紀年以來，猶未十稔，其死亡者，三分有二，傷寒十居其七。感往昔之淪喪，傷橫夭之莫救」——**這是一次大規模死亡的親歷者在說他為什麼要寫這部書。**
- 第 4 段批評當時的醫者「省病問疾，務在口給；相對斯須，便處湯藥……所謂窺管而已」——**這是對一種職業該怎麼做的責備。**
- 第 5 段「孔子云：生而知之者上，學則亞之。多聞博識，知之次也。余素尚方術，請事斯語」——作者替自己在這個階序裡定位。

**這幾段用「除了病與治法之外還說了什麼」這道閘門去讀，會很清楚地過關。**不要因為它們印在一部醫書裡就跟著判空。

其他可能命中的零星處：〈傷寒例〉開頭談四時之氣與人觸冒之的部分若真的在說人該如何自處（而不只是在說什麼季節生什麼病），可考慮給領域；判不出來就判空並在 `reason` 說明。

## IX 這一格要特別想清楚

IX 是「苦難·疾病·身體」。本庫已標十一部裡 IX 合計不到 20 段，這部書是它最有可能成群的地方——**也可能一段都不中，那同樣是有效結果。**

判準是同一道閘門：

- **病作為技術的對象** → `[]`。「太陽之為病，脈浮」是在定義一個病候，不是在寫痛苦
- **病作為人的處境** → IX。有人在病裡、在身體的限制裡，而文本在寫那件事

**不要為了讓 IX 有數字而硬撈，也不要因為「醫書判空聽起來很怪」而回頭補。**照實記。

## `Z-wisdom` 陷阱

本書絕大部分是「如何辨病、如何處方」的技藝與體系，那屬 `Z-wisdom`（方法與體系），**`domains` 判空**。`Z-wisdom` 絕不可寫進 `domains`。

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、方陣或制度表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | 算書題例專用，**本書不會用到** |

要點：

- 病候定義（「某某之為病，脈某」）是 `observation`
- 「某湯主之」的治法指派是 `prescription`；病候與治法同段時兩個都給
- **方劑組成與煎服法給 `formalization`**（可執行的程序：幾味、幾兩、水幾升、煮取幾升、日幾服）。這是本書 `formalization` 的主要來源，數量會很大，**不要因為它不像「制度表」就迴避**
- 「陰陽相摶」「寒虛相搏」這類講機理的推論給 `proposition`
- 張仲景原序是第一人稱自陳 → `expression`（多半再加 `proposition` 或 `prescription`）
- **`modes` 不要疊到三個以上**，挑主導的一到兩個

## 硬規則

1. **`[]` 是合法答案**，`domains` 與 `modes` 都是。負面結果本身是資料。
2. **一段可多標領域，但不要濫用。預設一到兩個。**要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。
3. **不要更動 `chapter` 與 `para_index`**。它們是錨點，錯一個就整批對不上。`para_index` 在每一章內從 1 重新編號，**回報時章名與 para_index 兩者都要給**。章名逐字照抄，不要改標點、不要把異體字或簡繁改掉（本書章名中「辨脉法第一」「平脉法第二」「伤寒例第三」用的就是這幾個字形，**照抄**）。
4. **`Z-wisdom`、`X-modern`、`Y-nature` 不是領域**，絕不可出現在 `domains`。
5. **不要用你對中醫、對張仲景、對六經辨證的既有知識去補文本沒說的東西。**只判這一段文字寫了什麼。也不要判斷醫理對不對——那不是本任務。
6. 〈辨可吐第十九〉之後直接跳到〈辨不可下病脈證並治第二十〉，來源就缺第十八篇，不是漏給你，照現有章節判即可。

## 輸出格式

寫到 `delegation/shanghanlun/out/bNN.json`，UTF-8、LF、不要 BOM：

```json
{
  "batch": "b01.md",
  "rows": [
    {"chapter": "辨脉法第一", "para_index": 4, "domains": [], "modes": ["observation"],
     "reason": "以陽脈浮陰脈弱推血虛筋急，是脈象與病機的定義，病在此是技術對象不是人的處境"},
    {"chapter": "張仲景原序", "para_index": 2, "domains": ["X", "VIII"], "modes": ["expression", "narrative"],
     "reason": "自陳宗族二百人十年內死去三分之二，因傷橫夭之莫救而勤求古訓著書，是親歷大規模死亡者說明自己為何投入這件事"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。** 這是回填時的雙向檢查條件，缺漏會整批退回。

`reason` 一句話即可，但**判 `[]` 的段落也要寫 `reason`**——寫出你認為它少了什麼。**判空段落佔本書大宗，那些 reason 是驗證判準的依據，不要寫成「醫方」兩個字了事**；至少要指出它在做的是辨病、處方還是服法。

## 不要做的事

- 不要改 `translations/` 底下任何檔案
- 不要跑 git 指令（commit、reset、pull、checkout、stash 一律禁止）
- 不要改 `delegation/shanghanlun/` 的輸入 `.md` 與 `MANIFEST.json`
- 只寫 `delegation/shanghanlun/out/` 底下你這一批的那個 `.json`
