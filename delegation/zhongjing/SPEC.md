## 這部書是什麼

> ### 章名有一個陷阱，這是硬規則
>
> **第十四章的章名是 `辨忠章十四`，沒有「第」字**——其餘十七章都是「章第N」，只有這一章是「章十四」。**這是來源實況，逐字照抄，絕對不要「順手補成」`辨忠章第十四`。**改了回填時錨點對不上，整批退回。

`para_index` 在每一章內從 1 重新編號，本書每章只有 1 段，所以十八段的 `para_index` **全部都是 1**，靠 `chapter` 區分。這不是錯誤，不要自己改成 1–18。

### 注文只有第一章有，其餘十七章沒有

`天地神明章第一` 正文中夾著 `〈 〉` 括起來的注文（「〈忠之為道，乃合於天……〉」等十餘處）。**其餘十七章一個注都沒有。**

- **注文算數**（本庫沿用世說新語劉孝標注、公孫龍子謝希深注的既有先例），可以作為判讀依據。
- 但 **`reason` 必須指明你引的是正文還是注文**，例如「注文『一則為忠，二則為僻』」。
- **本章多數注只是把正文換句話說**（比擬轉寫），這種不額外貢獻判斷；**只有注家自己下的斷言才算新內容**。
- **不要把第一章的兩層讀法搬到其餘十七章**——它們沒有這一層。

### 反錨定（先讀這一句再往下讀）

> **不要把其他書的判空比例搬過來當預期值。**九章算術判空 99.9%、列女傳 4%、管子 24%——**體裁差異不是判準差異**。這一部該是多少，讀完再說。
>
> 同時：**本書粒度極粗（一段＝一章，每段兩三百字的完整論述）**，一段裡混著數個主題是常態，**只要其中一處說出了人是什麼樣的、人該成為什麼樣的，這一段就命中**，不必整段都在講人。

## 一、通則性閘門

本書整部在講「臣民該怎麼事君、官該怎麼盡職、國該怎麼治」。**每一段都在談人**——「有沒有提到君、臣、民、賞罰」不是判準。問：

> **這一段除了「誰該對誰盡什麼職／該怎麼治／官怎麼設、令怎麼下」之外，還說了關於人的什麼？**
>
> 沒有 → `[]`。
> 有 → 給領域。

操作判準只有一句：

> **文本有沒有自己把「人是什麼樣的」或「人該成為什麼樣的」當成依據說出來？**
> 說了 → 命中。
> 只給「做 A 則得 B」的政策鏈、職掌清單、制度條文，不解釋人為何如此 → 判空。

**工具性動機不能拿來當判空理由。**本書的用意百分之百是要人拿去盡忠，只要它確實斷言了人的樣態或立了做人的標準，就命中。

> **注意這一格與兵書相反。**兵書拿仁義當致勝條件時判空（那是工具不是主張，如「將不仁則三軍不親」）；本書把忠當成做人的根本、把德性當成治理的依據時要命中——差別在於前者沒說人是什麼樣的，後者說了。

## 二、本書最大的硬撈風險：XII 這一格要逐章切開

這是全書唯一真正難判的一格，**兩個方向都會出事**，所以兩面都寫死。

### 必須給 XII 的兩章

- **`證應章第十六`**：「**惟天鑒人，善惡必應**……忠則福祿至焉，不忠則刑罰加焉」「作善降之百祥，作不善降之百殃」。整章的骨幹就是**天會鑒察人的善惡並降下禍福**——這是實質的超越性主張，不是修辭。**必須含 XII。**
- **`天地神明章第一`**：「以徵天休，忠之道也」「忠能固君臣、安社稷、**感天地、動神明**」「天無私，四時行；地無私，萬物生；人無私，大亨貞」。忠被說成能感通天地神明、人的德性與天地同構——**必須含 XII。**

### 不給 XII 的三處（出現了字，但不承重）

- **`聖君章第二`**「王者，**上事於天，下事於地，中事於宗廟**，以臨於人」：這是王者事奉對象的**序列列舉**，講的是君主的職分層級，不是在立信仰主張。本章重心在「祿賢官能，式敷大化」。**不給 XII。**
- **各章末尾的《詩》《書》引文**（「昭事上帝，聿懷多福」「作善降之百祥」等）：引經是收束修辭。**不要因為引文裡有「上帝」「天」就給 XII**——`證應章第十六` 給 XII 是因為它**正文**就在講天鑒善惡，不是因為它引了《書》。
- **`廣至理章第十二`**「端旒而自化」「無為，而天下自清」：黃老式的無為治術，講的是統治方法。**不給 XII**（同本庫既有結論：談道談天不等於 XII）。

## 三、另外三個詞面聯想陷阱

### 1. X（無常·老·死·失去）——預期 0 段

- `冢臣章第三`「奉君忘身，徇國忘家，正色直辭，**臨難死節**而已矣」、`忠諫章第十五`「始於順辭，中於抗義，**終於死節**」、`百工章第四`「苟利社稷，則不顧其身」。
  > **死節在本書是忠的極致表現，不是在談死亡本身。**沒有一處在寫人如何面對死、如何承受失去。**不給 X。**

### 2. IV（家庭與傳承）——只給一章

- **要給的**：`保孝行章第十`。整章在講孝與忠的關係、事親奉養——「忠不及之，而失其守，匪惟危身，**辱及親也**」「則養其親」。**必須含 IV。**
- **不要給的**：`天地神明章第一`「著于家」「**家一，則六親各**」、`兆人章第六`「**行孝悌於其家**」。前者的「家」只是身→家→國這個層級序列的中間項，後者是把孝悌列為百姓本分的一個項目——**兩處都沒有在寫家內事本身**。
  > 分工線：**家內事歸 IV、朝廷事歸 V。**出現「家」「六親」「孝悌」四個字不是命中訊號，**那一段有沒有在寫家內的人與人**才是。

### 3. IX（苦難·疾病·身體）——預期 0 段

- 「**匪惟危身**」「不顧其身」的「身」是指身家性命的風險，不是有人在自己的身體處境裡受苦。
  > **IX 不是「提到身體」，是「有人在自己身體裡，而文本在寫那件事」。**

## 四、一個最容易漏掉的必中格：XI 在〈政理章第七〉

`政理章第七`：「化之以德，理之上也，則**人日遷善而不知**；施之以政，理之中也，則**人不得不為善**；懲之以刑，理之下也，則**人畏而不敢為非**也。」

這是**對「人如何被改變、以哪三種不同機制被改變」的實質理論**，不是政策鏈套語——它說的不是「做 A 得 B」，而是三種手段各自在人身上造成什麼樣的內在狀態（不知不覺地遷善／不得不／畏而不敢）。

> **`政理章第七` 必須含 `XI`。**這一格若判空，代表你把它讀成了治術清單。

### 必須判空或不得出現的格（若出現，代表被硬撈了）

- **全書 `X`、`IX` 兩格為 0 段**（理由見第三節）
- **`IV` 只在 `保孝行章第十` 出現，其餘十七章不得有 IV**
- **`XII` 只在 `天地神明章第一` 與 `證應章第十六` 出現，其餘十六章不得有 XII**——尤其 `聖君章第二` 不得有
- **全書 `narrative`、`expression`、`worked_instance` 三值為 0 段**：`揚聖章第十三` 舉皋陶歌、周公頌、吉甫誦是**舉例不是情節**，不給 `narrative`；全書無第一人稱。
- **全書 `ritual` 為 0 段**：`聖君章第二` 的「上事於天，下事於地，中事於宗廟」只列事奉對象，**沒有規定任何動作、時序或器物**，不構成 `ritual`。

### 必須給 `formalization` 的兩章

- **`忠諫章第十五`**：「諫於未形者，上也；諫於已彰者，次也；諫于既行者，下也」——**三等分級表**
- **`報國章第十七`**：「報國之道有四：一曰貢賢，二曰獻猷，三曰立功，四曰興利」＋逐項定義——**綱目分類表**

## 8 個 discourse_mode（`modes` 只能填這些 id）

| id | 定義 | 判準 |
|---|---|---|
| `observation` | 陳述某物／某人實際如何 | 可被事實否證的描述句 |
| `proposition` | 主張某個因果或原理 | 有「A 故 B」的結構 |
| `prescription` | 規定應該如何 | 祈使或當為句 |
| `formalization` | 把規範化成可計算程序 | 有可執行的算法、制度表、數量比例、綱目分類表 |
| `narrative` | 用故事承載 | 有人物與情節 |
| `ritual` | 用儀節承載 | 規定動作、時序、器物 |
| `expression` | 第一人稱抒發而非第三人稱描述 | 說話者即當事人 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案 | **本書不會用到** |

預期分佈：`prescription` 與 `proposition` 為主幹，兩章有 `formalization`（見上），`observation` 用在 `辨忠章十四` 這種描述小人之言實況的地方。**`modes` 不要疊到三個以上**，挑主導的一到兩個。

## 硬規則

1. **`[]` 是合法答案**。負面結果本身是資料。
2. **一段可多標領域，但不要濫用。預設一到兩個。**本書粒度粗（一段＝一章），**允許到三個**，但要標第三個，`reason` 裡必須寫得出「拿掉它這一段就少講了什麼」——寫不出來就是湊的，刪掉。**四個以上一律不接受。**
3. **`reason` 裡寫的話必須在原文找得到。**不可以用你對馬融、鄭玄、《孝經》與《忠經》關係的既有知識去補。判斷依據只有你眼前這一段的文字。
4. **不要更動 `chapter` 與 `para_index`**。章名逐字照抄（**特別是 `辨忠章十四` 沒有「第」字**），十八段的 `para_index` 全部是 1。
5. **不要判斷書中的政治主張對不對，也不要評價它的道德立場。**本書通篇宣揚忠君，你的工作是記錄它說了什麼，不是評價它。
6. 原文有訛字與費解處，那是傳世本實況。`辨忠章十四` 正文中的「忠之為用一作「道」也」是**校勘夾注混進了正文**，照原樣讀、不要當內容也不要當錯誤處理。**看不懂的句子不要硬掰內容，判空並在 `reason` 說明文意不明。**
7. **判空之前先逐句掃一次**：本書一段就是一整章，職掌清單與德目排比會蓋掉夾在中間的那一句人性斷言（例如 `守宰章第五` 的「夫人莫不欲安……莫不欲富」就夾在為政條目中間）。
