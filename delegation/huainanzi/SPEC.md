# huainanzi（淮南子）段落級判讀規格

## 你要做什麼

替《淮南子》的一批段落做心理學領域標註。每一段回答兩件事：

1. `domains`：這一段承重地談到下表 13 個人生領域的哪幾個（可以是 `[]`）
2. `modes`：這一段用什麼方式在說（8 個 discourse_mode 挑一到兩個）

**`[]` 是合法且常見的答案。**負面結果本身是資料。你的工作是記錄這一段實際在做什麼，不是讓結果好看。

## 這部書是什麼

西漢淮南王劉安門客集體編撰，二十篇加〈要略〉（全書提要）與〈敘目〉（高誘序，劉安家世）。本庫底本是 Wikisource 通行本，共 620 段。**上游有 8 章原是整章一段，已用句讀切分器切開**（時則訓按月令切，其餘按句讀與論述起頭語切），所以部分段落的開頭或結尾可能不是作者自己的分段，**照你拿到的段落判，不要自己合併或重切**。

全書的體例差異極大，**所以按章分成六個體例群，每群一道閘門，不可互相借用**：

| 群 | 章 | 閘門 |
|---|---|---|
| G1 天地曆數 | 天文訓、墬形訓、時則訓 | 登錄之外 |
| G2 道論 | 原道訓、俶真訓、覽冥訓、精神訓、本經訓、詮言訓 | 中性物件替換 |
| G3 政論與兵論 | 主術訓、繆稱訓、齊俗訓、氾論訓、泰族訓、脩務訓、兵略訓 | 怎麼治／怎麼打之外 |
| G4 故事 | 道應訓、人間訓 | 刪掉這一則 |
| G5 格言串 | 說山訓、說林訓 | 逐條，一條承重即非空 |
| G6 書序 | 要略、敘目 | 提要與家世之外 |

## 閘門

### G1 天地曆數——登錄之外

> **這一段除了「天是怎麼運行的／地上有哪些山川物產方位／這個月天象物候如何、該行哪些政令與祭祀」之外，還說了關於人的什麼？**

- 宇宙生成（「道始于虛霩，虛霩生宇宙」）、星宿運行、歲星紀年、八紘九州、物產方位、音律數度：**判空**，`observation` 或 `formalization`
- **占驗表判空**：「大淵獻之歲：歲有大兵，大饑」這類歲星占辭是把年分對應到收成兵災的技術表，不是文本在主張天有意志。**不給 XII**
- 時則訓的月令：「天子衣青衣，乘蒼龍」、祭祀、禁令是逐月的制度條文，**預設判空**，`ritual` 或 `formalization`。只有文本停下來說明為什麼這樣做才對人好、或把失令的後果說成對人的懲罰時才給領域
- **命中側**：文本離開天象，直接說人該如何立身、人與天的關係是什麼（例如把人的情性對應到天地並據此提出主張）

### G2 道論——中性物件替換

> **把這一段裡的社會場景換成中性物件，它還成不成立？**成立 → 場景只是包裝，判空。不成立 → 給領域。

這一群是全書最承重的部分，**但不是每段都命中**：

- 純宇宙論、純道體描述（道「包裹天地，稟授無形」而沒有落到人）判空
- 落到人的，按它說了什麼給：意義與本末輕重（I）、情欲與心的虛靜（VI）、生死（X，精神訓大宗）、命與自由（XI）、處境中如何自處（XIII）、德性（VII）
- **XII 只給文本自己認證的神聖或超越**：覽冥訓「上天之誅也……其無所逃之亦明矣」是文本斷言天會降誅，給 XII；**「神」「神明」在本書多半指人的精神作用**（「夫靜漠者，神明之定也」），那不是 XII
- **生死是精神訓的主軸**：「生寄也，死歸也」「壺子之視死生亦齊矣」是對死亡態度的主張，給 X；若同段還寫出面對死亡如何安頓（「何足以滑和」），可加 XIII

### G3 政論與兵論——怎麼治／怎麼打之外

> **這一段除了「該立什麼法／怎麼賞罰／官怎麼設、令怎麼下／怎麼打仗、怎麼排陣」之外，還說了關於人的什麼？**

- 純治術與兵法條目判空，`prescription` 或 `formalization`
- **說出人的樣態就命中**：君主的品格與欲望（「人主之情，莫不欲總海內之智」）、民心向背、賢者如何被用或被棄、人性可不可教（脩務訓「學」的主張給 VIII）、風俗與人性（齊俗訓）
- 君臣、民心、公義、用人一律落 V；德性與品格落 VII；學習、才能、事功落 VIII
- **兵略訓**：「兵之所以強者，民也」這類把勝負歸到人心與德的段落給 V（有品格斷言再加 VII）；陣法、地形、器械判空

### G4 故事——刪掉這一則

> **把這一則刪掉，讀者少知道了什麼？**

道應訓的體例是「一則故事＋『故老子曰』收束」；人間訓是一串禍福相倚的史事。**判的是故事與收束句合起來承載了什麼主張**，不是故事裡出現了誰：

- 塞翁失馬這類「禍福無常、得失相倚」的主張給 XI（命運與改變）；若寫到如何面對得失，加 XIII
- 君臣進退、納諫、用人的故事給 V
- 人物的品格被拿來當教訓（貪、驕、謙、信）給 VII
- **故事裡有人死，不等於 X**：要文本停下來寫面對死亡這件事才給
- **「道」「無為」出現在老子引句裡，不等於 I**：要看這一則把它落到什麼人生問題上

### G5 格言串——逐條

說山訓、說林訓每段是一串互不相干的短語。**逐條讀，只要一條承重這一段就非空**。但大多數格言是物理或處事比喻（「以火能焦木」這類），比喻本身判空；要比喻明確指向人的某件事（「人莫鑑於流沫，而鑑於澄水」這類指向心的）才算承重。**一段最多三個領域**，寫不出每一格對應哪一條就刪。

### G6 書序——提要與家世之外

- **要略**：逐篇提要（「《原道》者，盧牟六合……」）判空，`observation`；只有要略在說明全書為什麼要這樣寫、要讀者得到什麼時才給領域
- **敘目**：高誘序，寫劉長、劉安的家世與結局。**照 §G4 的敘事閘門判**：劉長「恚而自殺」的母親、兄弟相殘、民歌「一尺繒，好童童；一升粟，飽蓬蓬」若是這一段在講的事，給 IV（家族）與 V；純著錄與官職判空

## 六條配套（每一條都有反面）

1. **天與神的五分**：文本自己斷言天有意志、會賞罰 → XII；把天象當技術表 → 判空；拿天當比喻 → 判空；批評迷信祈禳 → XI；「神」指人的精神 → 看它說了什麼，不給 XII
2. **「道」不是萬用桶**：只談道的形上性質判空；道被落到「人該怎麼活」才給領域
3. **欲望兩面**：「節欲」「反性」「去載則虛」是對內在的主張，給 VI；君主「窮耳目之欲」被當成反面教材，同時也是品格斷語，可加 VII
4. **比喻判空、比喻所指的人事才承重**：「渡水而無遊數，雖強必沉」本身是比喻，它所支撐的「得道則愚者有餘」才是主張
5. **禍福相倚**：人間訓、道應訓大量「禍兮福之所倚」；主張得失無常給 XI，不要反射給 X
6. **學習**：脩務訓反駁「學不如無為」，主張人要勤學、聖人亦勞，給 VIII；泰族訓論教化、移風易俗給 V（有明確人性主張加 VII）

## 13 個領域（`domains` 只能填這些 id）

| id | 名稱 | 涵蓋 |
|---|---|---|
| I | 存在與意義 | 人為何而活、意義從何而來、本末輕重、人在宇宙中的位置（**純宇宙生成不算**） |
| II | 自我與認同 | 我是誰、自知與自欺、名與實落在自己身上 |
| III | 愛與親密 | 愛與性、承諾、信任、被理解 |
| IV | 家庭與傳承 | 親子、兄弟、宗族、繼承、教養、喪葬 |
| V | 群體·社會·公義 | 歸屬、友誼、公義與權力、責任與領導、君臣、民心、用人、風俗 |
| VI | 情緒與內在生活 | 喜怒憂懼、情欲、心的虛靜與擾動 |
| VII | 善惡·良心·品格 | 德性、良心、品格養成（**德目排比不算，要拆成行為、下定義或連到後果**） |
| VIII | 工作·成就·召喚 | 勞動、才能、學與教、事功 |
| IX | 苦難·疾病·身體 | 有人在自己的身體處境裡而文本在寫那件事（**養生術語、病名不算**） |
| X | 無常·老·死·失去 | 死亡、衰老、失去 |
| XI | 自由·命運·改變 | 命定與自由、禍福無常、把成敗推回人力、時與遇 |
| XII | 信仰·神聖·超越 | **只給文本自己認證的神聖或超越**（見配套 1） |
| XIII | 安頓·修復·平安 | 受苦或失去之後如何自處 |

`Z-wisdom`、`X-modern`、`Y-nature` **不是領域**，絕不可出現。

## 8 個 discourse_mode（`modes` 只能填這些 id，挑一到兩個）

| id | 定義 |
|---|---|
| `observation` | 陳述某物／某人實際如何（天象、物產、提要多在這裡） |
| `proposition` | 主張某個因果或原理（道論、政論大宗） |
| `prescription` | 規定應該如何 |
| `formalization` | 把規範化成可計算的程序或表（歲星占表、月令條文、音律數度） |
| `narrative` | 用故事承載（道應訓、人間訓大宗） |
| `ritual` | 用儀節承載（時則訓的祭祀） |
| `expression` | 第一人稱抒發 |
| `worked_instance` | 以具體數字陳述一個問題實例及其答案（預期極少） |

## 硬規則

1. **`[]` 是合法答案**。G1 的預設答案就是 `[]`。
2. **一段預設一到兩個領域。**標第三個時，`reason` 必須寫得出「拿掉它這一段就少講了什麼」。**不得標到四個。**
3. **章名逐字照抄，`para_index` 照批次檔給的數字**，不要重新編號。
4. **異體字逐字照抄**，不要把 `爲` 改成 `為`、`墬` 改成 `地`。
5. **不要用你對淮南子或道家的既有知識去補文本沒說的東西。**
6. **不要把前一群的判空比例搬過來當預期值。**
7. **`reason` 必須逐字引到這一段自己的文字**，用「」括起來。規則：
   - 引句必須是這一段正文**連續的原字**，一字不改、不增、不刪
   - **原文裡有引號時，不准刪掉原文的引號再引**。例：原文是 `禹乃熙笑而稱曰：“我受命於天，竭力而勞萬民，生寄也，死歸也，何足以滑和？”`，要引就只引引號裡面的一截，例如「生寄也，死歸也」；**不可以寫成「禹乃熙笑而稱曰我受命於天」**（刪掉了冒號和引號，對不上原文）
   - 原文中間被別的字隔開時，拆成兩個「」分別引，**不要自己補省略號也不要把兩截接起來**
   - 判 `[]` 的段落也要寫 `reason`，並引一句說明它在做什麼（天象、物產、月令、治術條目、提要、比喻……）

## 輸出格式

寫到 `delegation/huainanzi/out/bNN.json`，UTF-8、不要 BOM：

```json
{
  "batch": "b05.md",
  "rows": [
    {"chapter": "精神訓", "para_index": 6, "domains": ["X", "XIII"], "modes": ["proposition", "narrative"],
     "reason": "「生寄也，死歸也，何足以滑和」主張生死不足以擾亂內心，「壺子之視死生亦齊矣」以死生為一，是對死亡的態度與安頓"},
    {"chapter": "天文訓", "para_index": 85, "domains": [], "modes": ["formalization"],
     "reason": "「大淵獻之歲：歲有大兵，大饑」是歲星紀年的占驗表，把年分對到兵災收成，文本沒有主張天有意志"}
  ]
}
```

**`rows` 必須涵蓋該批所有 (chapter, para_index)，一個都不能少、不能多。**每一列都要有非空 `reason`。
